## 1. td-input-field (`src/form/td-input-field.js`, 677 lines)

### 1.1 Public API

- Tag `td-input-field`, `TdInputField extends TdFormElement` (form-associated). The host submits and owns ALL
  constraint validation; the inner control has no `name`/`required`; `email|url|number` are rendered as
  `type="text"` + `inputmode` and re-validated on a detached probe input (:59-63, :86-95, :369-442).
- `observedAttributes` (:45-53) = `name, disabled, required` + `type, size, value, placeholder, readonly,
  max-length, limit-type, min, max, step, label, helper-text, error-text, field-id, rows, validate-on`;
  booleans `disabled, required, readonly`.

| attr | semantics / default |
|---|---|
| `type` | text\|password\|email\|tel\|number\|url\|search\|date\|textarea\|contenteditable (default text; unknown → text) |
| `size` | sm\|md\|lg (default md; unknown → md) |
| `value`, `placeholder` | escaped into the control |
| `readonly`, `disabled`, `required` | disabled also via ancestor `<fieldset disabled>`; `required` adds a red `*` to the label |
| `max-length` + `limit-type` (char\|word) | coerced to a positive int (:107-108); char → native `maxlength`; word → JS truncation (:513-548); shows counter "n/max ký tự\|từ" |
| `min`, `max`, `step` | number/date validity on the host; forwarded to the inner control only for `date` (:163-169) |
| `label` | `<label>` text; `for` is emitted **only when `field-id` is set** (:121) |
| `helper-text` / `error-text` | one shared note line: error wins, else helper (:192-196) |
| `field-id` | id forwarded to the inner control (and label `for`) |
| `rows` | textarea rows (default 4); also drives a CSSOM pixel height (:233-235) |
| `validate-on` | blur\|change\|input → `_showInlineValidity()` mirrors the constraint message into the note (:445-448) |

- JS properties: auto for every observed attribute (camelCase) + TdFormElement getters (`form, validity,
  validationMessage, willValidate, labels`).
- Methods: `getValue()`, `setValue(v)` (truncates to the limit), `setError(msg)`, `setHelper(msg)`,
  `setDisabled(b)`, `setReadOnly(b)` — **bound as instance properties inside `afterRender()` (:344-349)**, so they
  do not exist before the first connect, and the `setError` instance property **shadows** the new
  `TdFormElement.prototype.setError`. Base: `checkValidity/reportValidity/setCustomValidity/focus`.
- Error semantics today (:598-660): `_runtimeError` (`null` = use attribute) wins over `error-text`; a changed
  `error-text` attribute resets the runtime override (:600-603, then base re-render); `setError('')` brings back the
  helper; `_setHelper` mirrors that with `_runtimeHelper`. **Same precedence rules as the base contract** — the base
  was modelled on this. Form reset does **not** clear an error today (base contract does, :273-279).
- Events: custom `input` `{ value }` on every native input (:327-333) and custom `change` `{ value }` on **every
  blur, even if unchanged** (:309-324). The native `input` and `change` events from the inner control are **not
  stopped** → listeners get two `input` events per keystroke (one native `Event` without `detail`, one
  `CustomEvent`) and an extra native `change` on commit. `e.detail.value` throws on the native one.
- Form: `_syncForm()` (:358-362) → `setFormValue(getValue())` + validity anchored to the inner control;
  `_restoreDefaults` presence-aware (:452-465); `_restoreState` for bfcache/autofill (:467-472);
  `_focusTarget()` = `.td-input` (:474-476).
- Keyboard/a11y today: native input/textarea. contenteditable = `div[role=textbox][aria-multiline=false]`.

### 1.7 A11y / quality gaps

1. **Label not associated unless `field-id` is set** (:121): the common case `<td-input-field label="Họ tên">` gives
   an unlabelled textbox (placeholder at best). External `<label for=host>` only works through `focus()` delegation;
   the inner control gets no name from it.
2. **No `aria-required`**: `required` is removed from the inner control (host owns validity), so AT never hears
   "required"; the red `*` is not `aria-hidden` (read as "star").
3. Helper/error note not linked (`aria-describedby` absent); error has `aria-invalid` but no
   `aria-errormessage`/`aria-describedby`.
4. `outline:none` + JS box-shadow on focus: no `:focus-visible`, invisible in forced colours.
5. Contrast: border `rgba(0,0,0,.1)` ≈ 1.25:1 on white (WCAG 1.4.11 needs 3:1 for the boundary of an input with no
   fill contrast); placeholder `#9ca3af` 2.54:1 (text → 4.5:1); error `#ef4444` 3.76:1 (fails 4.5:1 as text).
6. contenteditable: placeholder is injected as **real text** (`innerText = placeholder`, :336-340) → read as the
   value; `aria-multiline="false"` although Enter inserts newlines; `label for` cannot target a `div` → no name;
   `readonly`/`disabled` only flip `contenteditable`, no `aria-readonly`/`aria-disabled`.
7. Any observed attribute change (`value`, `helper-text`, `error-text`, `placeholder`, `required`…) re-renders →
   focus and caret lost while typing if the page mirrors state into attributes.
8. Double `input`/`change` events (see 1.1); custom `change` fires on every blur.
9. Counter at exactly `max` shown as an error (red border) though valid.
10. Word-limit truncation moves the caret to `cursorPos - 1` (:544) — off by one for paste in the middle.
11. Touch: sm 32 px < 44 px.
12. Public methods missing before first connect (instance-bound, :344-349).

### 2.7 A11y / quality gaps

1. **No visible focus indicator at all**: the real control is `opacity-0`; nothing reacts to its `:focus-visible`.
2. **Hit target**: the input is `absolute inset-0` inside the **track container** (4–8 px tall) → pointer target is
   4–8 px high (WCAG 2.5.8 needs 24 px), thumb is `pointer-events:none`.
3. Thumb geometry mismatch: visual thumb centre = `pct%` of the track (overflows the ends by thumb/2), while the
   native (invisible) thumb travels `thumb/2 … width - thumb/2` with the UA default thumb width → pointer position
   and visual thumb disagree near the ends.
4. `role="slider"` + `aria-valuemin/max/now` duplicated on a native range (redundant; `aria-valuenow` is written by
   JS and can drift). No `aria-valuetext` (units/format, e.g. "60 %").
5. Name: visible `label` div is not programmatically linked (only duplicated into `aria-label`); external
   `<label for=host>` does not name the range; host `aria-label` not forwarded.
6. Value label coloured with `color` (#3b82f6 = 3.68:1) fails 4.5:1 text contrast; mark labels `text-gray-500`
   10 px.
7. `show-step-marks` renders `floor((max-min)/step)+1` nodes with **no cap** (`min=0 max=10000 step=1` → 10 001
   marks + labels) and float formatting (`0.1+0.2`-style labels).
8. Disabled = `opacity:.5` only; no `forced-colors` rules; spring transition not reduced-motion aware.

## 9. Open design decisions (recommended answers)

| # | Question | Recommendation | Why |
|---|---|---|---|
| **D1** | td-empty-state raw `<svg` string `icon` | Keep for 0.8 as **deprecated**: rendered only if it passes the registry validator (parse with `DOMParser('image/svg+xml')`, allow only the `registerIcons` tag/attr allowlist, rebuild with `createElementNS`), else inbox + one `console.warn`. Add a JS property `iconNode` (trusted `SVGElement`, like lightbox) as the supported escape hatch; remove the string path in 0.9/1.0. | Closes the stored-XSS hatch now without breaking decorative SVGs that are plain shapes; matches ADR 0010 + security.md ("accept an Element, not HTML"). Pure "keep verbatim + warn" leaves the hole open for another minor. |
| **D2** | One error-note vocabulary (td `.td-field-error` vs 135 `.td-field__note.td-field__error`) | Keep **`.td-field-error#{host}-error`** (already public since 0.7.0) for errors and `.td-field__note#{host}-note` for helper, both inside `.td-field__footer`. 135's PHP adapter emits the td contract (drop `is-invalid`, `td-field__hint`). | One contract across checkbox/switch/field; no alias (ADR 0008 §3). |
| **D3** | `aria-errormessage` alone vs + `aria-describedby` | Base contract adds the error id to `aria-describedby` too (merged with subclass ids), keeps `aria-errormessage`. Applies to checkbox/switch retroactively. | AT support for `aria-errormessage` is still patchy; 135 SSR already does both. |
| **D4** | Floating label (`label-mode="floating"`) and textarea autoresize | **Defer both** (not in batch 2). If 135 needs floating: additive attr later, CSS-only from 135. Autoresize later as `autoresize` attr using CSS `field-sizing: content` only (no JS). | Batch is already large; neither is needed for parity with the current API ("no over-engineering"). |
| **D5** | Field colours: 135 subtle border (1.32:1) + gray-400 placeholder (2.56:1) vs AA | td defaults AA: `--td-field-border: var(--td-control-border-strong)` (3.42:1), `--td-field-placeholder: var(--td-gray-600)` (5.28:1); 135 may override to its look (its responsibility). | Same stance as batch 1 D6 (checkbox/switch borders). |
| **D6** | Tabs activation: automatic vs manual | **Automatic** (Arrow moves focus + selects + fires `tab-change`), as dcms2 and APG recommend when panels switch without latency. No `activation` attr now. | Parity with dcms2 consumers; simplest. |
| **D7** | `aria-controls` / tabpanel | Additive optional `tab.panel` (element id). When present: `aria-controls` on the tab, and td-tabs sets `role="tabpanel"`, `aria-labelledby`, `tabindex="0"` on that element and toggles its `hidden`. Without `panel`: no panel management (today's behaviour). | APG-complete for consumers who opt in; zero change for existing consumers who switch panels themselves. |
| **D8** | Input-field `change` semantics (fires on every blur) | Keep "custom `change` on blur" but **only when the value changed since focus** (native semantics); stop the native `change`/`input` at the host (one event, batch-1 pattern). Document as behaviour change. | Double events + `detail` missing on the native one are real bugs; firing on unchanged blur is noise. |
| **D9** | Counter "limit" state | `data-state="limit"` at `count >= max` (colour only), **no red border**; red border only from a visible error. | At exactly `max` the value is valid. |
| **D10** | Pagination active default colour / style | Current page = solid pill `--td-pagination-active` (default `var(--td-accent)`) + auto-contrast fg (reuse `TdButton` contrast helper); `active-color` sets the pill colour. Change td-table's JS default from `#ef4444` to "unset" (token). | `#ef4444` text is 3.76:1; liquid-glass says current page = fill; token default lets sites theme. |
| **D11** | Slider fixed px widths (200/300/400) | Keep as defaults via `--td-slider-w` but add `max-width: 100%`; sites/containers can set the token. | Avoids a layout change for existing pages while fixing overflow on phones. |
| **D12** | Step marks explosion | Render marks only when `(max-min)/step <= 50` (else no marks + `console.warn`); format labels with `Number(v.toFixed(decimals(step)))`. | DoS-ish DOM growth; float labels. |
| **D13** | Empty-state `title` global attribute tooltip / fixed `<h3>` | Keep attribute names (public API).
