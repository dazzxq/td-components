## Decisions

Adopt inventory §9 **D1–D25 as recommended**:
D1 keep the wheel model (3 labelled `input[type=number]` date fields + hour/minute wheels as select-only listboxes with
scroll-snap; no grid calendar); D2 modal only (TdModal); D3 trigger `button[role=combobox][aria-haspopup=dialog]`
updated in place; D4 additive TdModal option `escapeCloses` (default `false`, picker passes `true`, never while busy)
+ ADR 0006 addendum; D5 `min`/`max` (display or ISO-local) validation-only with vi messages, default range 2000–2099 — **a date-only bound
(`YYYY-MM-DD` or `dd/mm/yyyy`) expands to `00:00` for `min` and `23:59` for `max`; explicit times are exact** (review
ISSUE-6, tested);
D6 pure parse/format helpers in `src/utils/datetime.js` with node tests, value contract unchanged, no locale/format
API; D7 `minute-step` snaps down (pending state written on open); D8 `getValue()`/`getDBValue()` → `''` when empty or
invalid; D9 date fields validate on `input`, clamp on `change`; D10 blocks `.td-dtp`, `.td-dtp-panel`,
`.td-dtp-wheel`; D11 table structural render + in-place updates (thead and paginations persist, tbody rebuilt);
D12 sorting: 3-state cycle, `aria-sort` on the active `th`, sort buttons, registry icons, `Intl.Collator('vi',
{numeric, sensitivity:'base'})`, additive `sort-change` event; D13 no row selection; D14 sticky header via
`max-height` (wrapper scrolls, opaque sticky `th`, local z-index 1); D15 `cellPaddingClass` whitelist `px-0…px-6` →
`td-table__cell--px-{n}` (+ one warn for unknown); D16 horizontal scroll only, wrapper focusable + named while
overflowing, `data-col`/`data-col-key` hooks — **name fallback (review ISSUE-4): when there is neither a title nor a host
`aria-label`, the table and the overflow region are both named "Bảng dữ liệu" (`TdTable.labels.table`)**; D17 additive `quiet` on td-pagination (top pagination quiet); D18
`empty-title`, `heading-level`, table named by the title (`aria-labelledby`) or host `aria-label`; D19 loading:
`aria-busy` + one `role=status`, deterministic skeleton, shimmer stopped under reduced motion; D20 keep `render(row,
rowIdxInPage)` trusted-HTML hatch (Node preferred, documented), stories/demo stop interpolating row data; D21 port
dcms `ellipsis` + auto fixed layout; D22 fix zebra tri-state, server-mode page kept on `data`, page clamp,
index-based columns, `update` guards, **and §2.8.9 (review ISSUE-5): in server mode `total-items` is required — without
it the rows render, both paginations stay hidden and one console warning explains the contract (documented; tested)**,
§2.8.10 docs default fixed; D23 delete `src/utils/adopt-styles.js` + its test (zero users; not a package
export), update td-base-element JSDoc, ADR 0005 superseded for components; D24 scope guard as listed; D25 the
Tailwind peer is dropped in the NEXT release (1.0.0), not in this one.

## Work

0. **Shared (lead, before agents):**
   - TdModal `escapeCloses` (D4): `onEscape` closes the instance when set and not busy; still consumed. Tests: Escape
     closes an `escapeCloses` modal, not a default one, not while an async action is busy; focus restore per D10.
     ADR 0006 addendum (docs/decisions): allowed only for dialogs whose close loses no user data.
   - td-pagination `quiet` (D17): info text without `aria-live`. Test + components.md row.
1. **td-datetime-picker** (agent; `components/datetime-picker.css`, inventory §1 + §7.1): D1–D10. Owns
   `src/utils/datetime.js` (+ node tests). Trigger + in-place updates + error contract (`error-text`, `setError`) +
   `label` naming like the batch-3 dropdown; panel inside TdModal with `escapeCloses: true`, focus into the first date
   field, "Chọn" commits pending state and focus returns to the trigger; wheels (**one normative model, review
   ISSUE-3**): each wheel is a `role=listbox` with `tabindex="0"` and an accessible name ("Giờ" / "Phút"); its options
   are non-focusable `role=option` children; `aria-activedescendant` on the listbox and `aria-selected="true"` on the
   same option are kept in sync (selection follows the active option); ↑↓ Home End PageUp PageDown, click, scroll-snap (reduced-motion: no smooth
   scroll); validity (`valueMissing`, `rangeUnderflow`, `rangeOverflow`, bad input) with vi messages; one `change`
   per commit. Fix every §1.8 bug with a test. Remove `adoptStyles` usage.
2. **td-table** (agent; `components/table.css`, inventory §2 + §7.2): D11–D22 using `.td-glass`-free solid surfaces
   (content layer, not floating — no glass except the opaque sticky header fill); remove `adoptStyles`
   (review round 2 ISSUE-7: **keep** `safeCssDimension`, the `align` whitelist and CSSOM `applyStyles` for the per-column
   scalars `width`/`widthType`/`minWidth`/`maxWidth`/`align`, with regression tests) and every Tailwind class from
   rendered markup/templates, stories (`td-table.stories.js`, `td-composition.stories.js`) and examples (token
   classes instead); `px-0…px-6` survive **only** as `cellPaddingClass` whitelist lookup keys (round 2 ISSUE-1). Fix every §2.8 bug with a test.
3. **Harness/tests/docs** (lead, §8): `_meta.tokenNative` += td-datetime-picker, td-table; `_meta.mixed` becomes
   empty (kept as a mechanism); recapture + new states (picker: closed, value, open, wheel-active, error,
   disabled; table: default, sorted, loading, empty, sticky, ellipsis, px-2); contracts
   `test/contracts/{datetime-picker,table}.html`; per-component batch-4 browser suites; update existing tests that
   depend on internals (§1.6, §2.6); token gate components page gains a table sticky-header opacity check and the
   picker wheel reduced-motion check; delete adopt-styles (D23); docs (components.md, class-map, CHANGELOG 0.10.0 incl.
   behaviour changes D3/D4/D8/D11/D22, security.md `render` hatch wording, roadmap, architecture dependency graph,
   ADR 0006 addendum, ADR 0005 status).
