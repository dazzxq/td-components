# v0.79.2: `td-media-field` `hide-alt` — ẩn ô alt, vẫn gửi alt

Trạng thái: Codex plan APPROVE r2 (terra/medium).

## Nguồn

dsuite K-A5-5 (2026-10-18): ô ảnh nhỏ (thumb 3:2, Facebook 1.91:1, avatar) dùng `usage croppable` nhưng không có chỗ cho ô
"Mô tả ảnh (alt)". Quyết định qua `/codex-think-about` (đồng thuận vòng 2, owner giao debate quyết): phương án **B + chỉ CSS**.

## Thay đổi

1. CSS (`src/styles/components/media-field.css`, cạnh luật `hide-hints`):
   `td-media-field[hide-alt] > .td-media-field__usage { display: none; }`. Không đổi DOM, JS `render()`, PHP render,
   marker `media-field@2`.
2. JS: thêm `hide-alt` vào JSDoc `@attr` (boolean) + danh sách attribute được biết. **Không** observe (CSS lo bật / tắt).
   Kiểm tra danh sách "tên component tự đọc" mà PHP `attrs` chặn — thêm `hide-alt` như đã làm với `hide-label` / `hide-hints`.
3. PHP `td_media_field(…, ['hide_alt' => true])` in attribute boolean `hide-alt` trên host (cùng cách `hide_hints`);
   `attrs['hide-alt']` bị chặn như hai attribute kia.
4. Form không đổi: usage vẫn gửi đủ `name[id]`, `name[alt]`, `name[crop]` (+ `name[focal]`). `name[alt]` = giá trị alt
   bên trong (từ attribute `alt` / property, hoặc `usage.altText` / `defaultAltText` khi chọn ảnh mới), y như khi ô hiện mà
   người dùng không sửa. `selection[0].usage.altText` = đúng chuỗi đã gửi. Không gửi thiếu `[alt]`: code server kiểu
   `$data['og']['alt'] ?? null` sẽ xoá alt đã lưu.
5. Không có JS (PHP): input `name[alt]` có sẵn bị `display: none` vẫn là control hợp lệ nên vẫn được gửi.
