# v0.105.0: avatar CSS-only `.td-avatar` + helper `td_avatar()` / `tdAvatar()`

Nguồn: roadmap "Component còn lại từ dwp/135"; khảo sát + quyết định owner ở
[v0.104.0-filled-icons.md](v0.104.0-filled-icons.md) §"Khảo sát avatar".

## Mục tiêu

1. Kit có `.td-avatar` CSS-only (không JS, không custom element) cho ảnh đại diện tròn và ô chữ cái đầu khi chưa có ảnh.
2. **Hình mặc định = 135** (owner chốt 08/11): 135 xoá khối `.td-avatar*` trong `public/assets/app/base.css:233-241`
   mà markup giữ nguyên, hình không đổi (cả cỡ chữ ô trống, QĐ6).
3. **Có helper** (owner chốt 08/11): PHP `td_avatar()` + JS `tdAvatar()`: có ảnh → `<img>`, không có → `span` chữ cái
   đầu viết hoa, `?` khi tên rỗng.
4. dwp dùng được với cỡ / vòng riêng qua token (`--td-avatar-ring: none`, `--td-avatar-size`), không sửa lõi.

## Ngoài phạm vi

- Không xử lý ảnh lỗi (`onerror` inline bị CSP chặn; site tự bắt `error` nếu cần). Không nhóm avatar chồng nhau
  (avatar group), không chấm trạng thái online, không hình người placeholder (dwp đang có: site đưa `td_icon` vào ô
  trống). Không avatar vuông. Thêm sau nếu có yêu cầu thật.
- Không đụng repo 135 / dwp (chỉ báo).

## Quyết định thiết kế

### QĐ1. Markup (giữ đúng markup 135)

```html
<img class="td-avatar td-avatar--sm" src="…" alt="" width="32" height="32" loading="lazy" decoding="async">
<span class="td-avatar td-avatar--sm td-avatar--empty" aria-hidden="true">A</span>
<span class="td-avatar td-avatar--lg td-avatar--empty" aria-hidden="true"><svg class="td-icon …">…</svg></span>
```

Lớp: `.td-avatar` (gốc, 40px) · cỡ `--xs` (22) / `--sm` (32) / `--lg` (96) · `--empty` (ô trống). Cỡ `m` là gốc,
không có lớp `--m`.

### QĐ2. File + layer

`src/styles/components/avatar.css`, thêm vào `manifest.json` ngay sau `components/badge.css`. Token trong
`@layer td.tokens`, luật trong `@layer td.component`. Không `:hover` (không tương tác) nên không dính luật touch;
không `@media` theo bề rộng.

### QĐ3. Token

Hình học trên `:root`, màu trên `:root, [data-td-theme]` (QĐ15 / ADR 0020, `checkThemeScope`):

| token | mặc định | ghi chú |
|---|---|---|
| `--td-avatar-size` | `40px` | cỡ gốc; site đổi cỡ một chỗ: `.x .td-avatar { --td-avatar-size: 34px }` |
| `--td-avatar-size-xs` / `-sm` / `-lg` | `22px` / `32px` / `96px` | lớp cỡ đặt `--td-avatar-size: var(--td-avatar-size-sm)` |
| `--td-avatar-ring-width` | `1px` | nét vòng ngoài |
| `--td-avatar-ring-gap-width` | `2px` | khe giữa ảnh và vòng (`--xs`: `1.5px`, như 135) |
| `--td-avatar-ring-gap` | `var(--td-color-surface)` | màu khe = nền quanh avatar; site đặt theo nền thật |
| `--td-avatar-ring-color` | `var(--td-color-border)` | màu vòng |
| `--td-avatar-ring` | *(không khai báo)* | ghi đè cả `box-shadow`; `none` = bỏ vòng (dwp) |
| `--td-avatar-bg` / `--td-avatar-fg` | `--td-color-fill` / `--td-color-text` | lúc làm: `text-label` không đạt 4.7 với mọi seed của bộ sinh theme → `text` |
| `--td-avatar-font-family` | `var(--td-font-sans)` | 135 đặt font display của nó |
| `--td-avatar-font-weight` | `800` | như 135 |
| `--td-avatar-font-size` / `-xs` / `-sm` / `-lg` | `1.375rem` / `11px` / `0.875rem` / `clamp(2.25rem, 4.5vw, 3.25rem)` | đúng giá trị 135 (`--t-lg` / 11px / `--t-sm` / `--t-2xl`); lớp cỡ đặt `--td-avatar-font-size: var(…-sm)`; cỡ tuỳ biến thì site đặt `--td-avatar-font-size` cùng `--td-avatar-size` |

**Vòng ghép trên phần tử, không trên `:root`.** `box-shadow: var(--td-avatar-ring, 0 0 0 var(--td-avatar-ring-gap-width)
var(--td-avatar-ring-gap), 0 0 0 calc(var(--td-avatar-ring-gap-width) + var(--td-avatar-ring-width))
var(--td-avatar-ring-color))`. Lý do: nếu `--td-avatar-ring` khai báo ở `:root` bằng `var(--…-gap-width)` thì giá trị
bị tính sẵn ở `:root`, lớp `--xs` đổi `--td-avatar-ring-gap-width` trên phần tử không còn tác dụng. Để `--td-avatar-ring`
không khai báo (fallback) thì `:root { --td-avatar-ring: none }` của site vẫn thắng ở mọi cỡ, và lớp cỡ chỉ đổi token
thành phần. Docs ghi rõ đây là token "ghi đè tuỳ chọn".

### QĐ4. Luật gốc

```css
.td-avatar {
  box-sizing: border-box; display: inline-grid; place-items: center;
  inline-size: var(--td-avatar-size); block-size: var(--td-avatar-size); aspect-ratio: 1;
  max-inline-size: none !important; flex: none; /* thắng img { max-width: 100% } không layer của site */
  border-radius: 50%; overflow: hidden; object-fit: cover; vertical-align: middle;
  box-shadow: <QĐ3>;
}
.td-avatar--empty {
  background: var(--td-avatar-bg); color: var(--td-avatar-fg);
  font: var(--td-avatar-font-weight) var(--td-avatar-font-size)/1 var(--td-avatar-font-family);
  user-select: none; white-space: nowrap;
}
.td-avatar--empty > .td-icon { inline-size: 50%; block-size: 50%; }
```

- **Lúc làm (08/11):** browser test cho thấy reset phổ biến `img { max-width: 100%; height: auto }` không layer còn đè `block-size` → ảnh trong hàng flex bị kéo cao (40×54). Nên `inline-size` + `block-size` cũng `!important` (cỡ chỉ đổi qua `--td-avatar-size`, nên không mất đường tuỳ biến nào).
- **`max-inline-size: none !important`** (Codex plan review #5): luật trong `@layer td.component` thua mọi luật
  không layer của site như `img { max-width: 100% }`, bất kể độ đặc hiệu; `!important` trong layer thắng khai báo
  thường không layer (tiền lệ `badge.css` dòng 120). Chỉ thuộc tính này, chỉ vì đây là reset có chủ đích (avatar
  luôn đúng cỡ token, đổi cỡ qua `--td-avatar-size` chứ không qua `max-width`). `flex: none` để thường (site có
  luật flex riêng thì tự chịu, docs ghi). Browser test nạp `img { max-width: 100% }` **không layer** trong ô bảng /
  flex hẹp.
- Căn giữa sẵn cho cả ảnh lẫn ô trống (bỏ 7 chỗ `display:grid; place-items:center` của 135).
- Nền chỉ ở `--empty` (giữ 135: ảnh PNG trong suốt không bị nền xám).
- `forced-colors: active`: `box-shadow` bị trình duyệt bỏ → `--empty` thêm `outline: 1px solid CanvasText` để ô còn
  thấy được. `prefers-contrast: more`: không đổi (vòng đã là đường kẻ).

### QĐ5. Helper PHP (đúng 3 tham số owner nói, Codex plan review #3)

```php
td_avatar(?string $src, string $name = '', string $size = 'm'): string
```

- Không có mảng tuỳ chọn (không `label` / `text` / `icon` / `class` / `attrs`). Site cần thêm (lớp riêng, icon trong
  ô trống như `_catalog-form.php` của 135) thì tự viết markup QĐ1: CSS hỗ trợ đủ. Mở rộng khi owner yêu cầu.
- Cỡ: `xs | sm | m | lg`; lạ → `m`.
- `$src` qua `td__media_url()` (cùng luật `td_card`: https, http, URL không scheme; `javascript:` / `data:` / mailto
  bị từ chối). Bị từ chối hoặc rỗng → ô trống (không warn).
- Ảnh: `<img class="td-avatar[ td-avatar--{size}]" src="…" alt="" width height loading="lazy" decoding="async">`;
  `width` / `height` = px của cỡ (22/32/40/96) chống nhảy layout; `alt=""` (trang trí: tên in cạnh, như 135).
- Ô trống: `<span class="td-avatar[ td-avatar--{size}] td-avatar--empty" aria-hidden="true">` + chữ cái đầu qua `Td::e`.
- **Chữ cái đầu** (`Td::avatarInitial()` @internal): tên không phải UTF-8 hợp lệ → `?`; `trim` khoảng trắng Unicode;
  rỗng → `?`; grapheme đầu bằng `preg_match('/^\X/u')` (PCRE lõi, không cần intl; giữ NFD "E\u0303" và emoji ghép
  nguyên cụm); viết hoa **không phụ thuộc mbstring** (kit chạy trên PHP ≥ 8 trần, Codex plan review #1):
  `mb_strtoupper` khi có → không thì `IntlChar::toupper` từng code point khi có intl → không thì `strtoupper` (ASCII)
  + bảng `đ→Đ` và nguyên âm tiếng Việt có dấu thường → hoa (hai chuỗi song song trong mã). Test ép nhánh trần qua cờ
  test như `hasIntl()` đang có.

### QĐ6. Cỡ chữ ô trống = đúng 135 (Codex plan review #2)

Mỗi cỡ một token (QĐ3), giá trị y 135. Đã bỏ hướng tỉ lệ `size × 0.4` vì làm lệch hình 135 mà owner yêu cầu giữ.
Cỡ tuỳ biến (dwp 48 / 72) đặt `--td-avatar-font-size` kèm `--td-avatar-size` (docs có công thức).

### QĐ7. Helper JS

`src/display/avatar.js` export `tdAvatar(src, name = '', size = 'm')` → `HTMLImageElement | HTMLSpanElement` (phần tử
DOM, không `innerHTML`, chữ qua `textContent`). Cùng luật PHP. URL qua `safeMediaUrl` (`src/utils/media-url.js`).
Chữ cái đầu: `Intl.Segmenter` khi có, không thì `Array.from(s)[0]`; `toUpperCase()`. Package export
`"./avatar": "./src/display/avatar.js"` + `index.js`.

**Chênh lệch PHP ↔ JS đã biết:** PHP `td__media_url` nhận `http:` ở mọi trang, JS chỉ nhận khi trang là http (giống
`td_card` / media picker hiện có). Không sửa trong bản này.
