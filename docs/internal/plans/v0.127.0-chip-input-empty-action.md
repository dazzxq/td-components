# v0.127.0 — chip-input empty action row + menu href base (dcms2)

## Mục tiêu
1. **td-chip-input `create-empty-label`** (dcms2-f1, ô "Bút danh"): ô ở chế độ thường (không `selection-only`), khi danh sách mở với query rỗng (vd `show-on-focus`), có một dòng hành động cố định ở CUỐI danh sách, vd "Tạo bút danh mới". Chọn dòng → event `create` `{ query: '' }` (cùng event + detail với dòng create của selection-only 0.87.0 và dòng external 0.117.0), đóng popup, không thêm chip, không `change`. Host tự mở form. Khi đã gõ → hành vi y nguyên (dòng "Thêm …" / dòng external của `create-label`).
2. **Bundle không chứa URL tuyệt đối giả**: `safeMenuHref` (src/feedback/td-menu.js:150) dùng base `'https://localhost/'` khi không có `location`; chuỗi này lọt vào bundle (vd piece-lightbox.js) → validator ZIP eMagazine của dcms2 báo "địa chỉ mạng ngoài". Bỏ base giả, giữ nguyên ngữ nghĩa.

## Quyết định
- Tên: attribute `create-empty-label` + property `createEmptyLabel` (mirror, '' / null → gỡ attribute), theo tên dcms2 đề xuất, cùng họ `create-label`.
- Không đòi `allow-create` (dòng chỉ phát event; host quyết làm gì). Bỏ qua ở `selection-only` (ở đó `create-label` đã có dòng khi rỗng) — không cảnh báo.
- Entry nav mới `{ act: true }` (KHÔNG dùng `ext` để không dính `_createRowValid` vốn đòi text khác rỗng + allow-create). Markup = dòng external 0.117.0: `div.td-chip-input__option.td-chip-input__option--create.td-chip-input__option--external`, role=option, id `{host}-opt-external` (không bao giờ cùng lúc với dòng external vì dòng đó cần text ≠ ''), icon plus + nhãn qua textContent (không HTML, không `{text}`).
- Hiện khi: `_applyResults` với `cleanText(q)` rỗng, attribute khác rỗng, không disabled, chưa full (đã return sớm khi full). Có cả khi không có gợi ý nào (popup chỉ còn dòng này, không "Không có kết quả"). Không hiện ở trạng thái loading / error.
- Commit: chỉ chạy khi vẫn hợp lệ (không disabled, không full, input đã clean vẫn rỗng, attribute còn) → `_createAction()`.
- Dòng ghim cuối: `_renderOptions` đặt `data-create-row` trên list khi `_nav` có `ext` HOẶC `act` (CSS sticky `.td-chip-input__options[data-create-row] .td-chip-input__option--external` áp cho dòng mới); `_dropCreateRows` và check ở case `allow-create` / attribute mới cũng tính `act`.
- Đổi attribute khi dòng đang hiện → đóng popup (như case `allow-create` 0.117.0). `_dropCreateRows` gỡ cả dòng này.
- Bàn phím / aria / hover / active giống các dòng option khác (đi qua `_nav` + `_rowEls`).
- Thiếu attribute → DOM, snapshot, CSP baseline y nguyên.
- `safeMenuHref`: khi có `page` giữ nguyên. Khi `page` null: `new URL(norm)` (không base); nếu throw và `norm` không có scheme (`/^[a-z][a-z0-9+.-]*:/i` không khớp) → coi là URL tương đối, xử lý như trước (trước đây base https → chấp nhận) ; có scheme mà parse lỗi → null. Không ghép chuỗi kiểu `'https:' + '//…'` để lách validator.
- Câu hỏi phụ của dcms2 (cỡ avatar trong option): kit KHÔNG có token cỡ avatar cho option; option tuỳ biến qua `renderOption` → host tự CSS. Không thêm token ở bản này.
