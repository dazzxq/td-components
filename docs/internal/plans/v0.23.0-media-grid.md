## Kiến trúc

**Lựa chọn nằm ở lưới, không ở từng ô** (chọn dải bằng Shift, Esc bỏ hết, "đang ở chế độ chọn" đều cần biết toàn bộ).
Một custom element **nâng cấp markup có sẵn** (site / PHP in ô — 135 in server-side, có thể hàng trăm ô), không tự render
ô:

```html
<td-media-grid label="Khung hình cuộn 12">
  <div data-td-media-item data-id="f1">
    <button type="button" data-td-media-open aria-label="Khung 1"><img src="…" alt=""></button>
    <!-- tuỳ site: nút ⋯ TdMenu, badge… nằm trong item, kit không đụng -->
  </div>
  …
</td-media-grid>
```

- Mỗi item cần `data-td-media-item` + `data-id` (chuỗi, duy nhất) + một phần tử mở `[data-td-media-open]` (`<button>` hoặc
  `<a href>` — lightbox `data-td-lightbox-item` vẫn dùng được). Kit **chèn** nút tick `button.td-media-grid__tick`
  (`type=button`, `tabindex="-1"`, `aria-pressed`, `aria-label` = `labels.select` "Chọn {name}" với `{name}` = aria-label /
  alt / `data-id`, icon `check` từ registry) nếu item chưa có `[data-td-media-tick]` của site. Không lồng button trong `<a>`
  (tick là anh em của phần tử mở).
- Item thêm / bớt sau khi mount (site append, phân trang, xoá) → `MutationObserver` (childList, subtree) nâng cấp item mới;
  item bị gỡ → bỏ khỏi lựa chọn (phát `select-change` nếu tập đổi). Gom theo microtask.
- Lớp: `.td-media-grid` (bố cục CSS grid qua token, site đổi được), item nhận class `.td-media-grid__item`, phần tử mở
  `.td-media-grid__open`. Trạng thái: item `[data-selected]`, host `[data-selecting]` (tập khác rỗng). ARIA: host
  `role="list"` + `aria-label` (attr `label`), item `role="listitem"`; tick `aria-pressed` (giống 135 / dwp — không grid /
  listbox / roving: phần tử mở là điểm Tab tự nhiên, tick `-1` tránh hàng trăm điểm Tab). Một live region
  `.td-sr-only[aria-live=polite]` đọc `labels.count` "Đã chọn {n}" khi tập đổi (gom, không đọc từng ô khi chọn dải).

## Vòng đời (nâng cấp tại chỗ)

`TdBaseElement._doRender()` gán `innerHTML = render()` — component này **override** để không bao giờ thay con: không gọi
render chuỗi, nâng cấp các item hiện có trong `connectedCallback` (như các enhancer hiện có: `<td-alert>`, `<td-dropdown>`
nâng cấp `<select>`), đồng bộ attribute **tăng dần** trong `attributeChangedCallback` (không render lại), gắn / gỡ
`MutationObserver` + listener khi connect / disconnect (gắn lại khi di chuyển, không nhân đôi). Test: con ban đầu và
control của site (nút ⋯, badge) còn nguyên sau nâng cấp, sau đổi `label` / `max` / `disabled`, sau gỡ rồi gắn lại host.

## Hành vi (state machine)

- Trạng thái: `Set` id đã chọn + `anchor` (id). "Đang chọn" = tập khác rỗng (suy ra, không lưu).
- **Chưa chọn gì:** bấm phần tử mở → `activate` (`detail: { id, item, event }`, cancelable — `preventDefault()` chặn hành
  vi mặc định của phần tử mở, ví dụ link / lightbox); bấm tick → chọn ô, anchor = ô.
- **Đang chọn:** bấm phần tử mở hoặc tick → lật ô (anchor = ô; tập rỗng → anchor = null). **Không** `activate`, chặn hành
  vi mặc định (listener **capture** trên host, `preventDefault` + `stopPropagation` để lightbox `bind()` / link không
  mở).
- **Shift + bấm** (cả khi chưa chọn gì nếu có anchor; không có anchor → như lật đơn): chọn **dải** theo thứ tự DOM từ anchor
  tới ô (chỉ thêm), anchor giữ nguyên.
- `max` (attr số nguyên ≥ 1, tuỳ chọn): thêm vượt cap → không thêm, phát `select-limit` (`detail: { max }`), live region
  đọc `labels.limit` "Tối đa {max} mục". Dải chỉ thêm tới khi đủ.
- **Bàn phím** — chỉ khi focus nằm trên `[data-td-media-open]` (hoặc con của nó); control khác trong item (nút ⋯ TdMenu,
  link…) **bị bỏ qua**, tự xử lý phím của nó: Space → lật (Shift+Space → dải), **chặn cuộn trang**; **Enter → luôn
  `activate`** (cancelable) bất kể đang chọn hay không, **không** đổi lựa chọn (đúng yêu cầu "Enter = activate"); click
  chuột khi đang chọn vẫn là lật. Esc: tập khác rỗng **và** không có
  lớp boundary nào đang mở (`hasActiveAbove(0)` của `layers.js` — modal, lightbox, menu, dropdown…) **và** không đang gõ
  IME → bỏ hết, giữ focus. Listener `keydown` trên `document` chỉ gắn khi tập khác rỗng.
- Disabled (attr `disabled`) → không chọn / không lật, `activate` vẫn chạy (xem ảnh); selection giữ nguyên.

## API

Attribute: `label`, `max`, `disabled`. Property / method: `selectedIds` (getter, mảng theo thứ tự DOM), `select(ids)`,
`deselect(ids)`, `toggle(id)`, `selectAll()`, `clear()` (method lập trình **không** phát `select-change` — như `setValue`
— trừ khi `{ emit: true }`), `items` (getter). Sự kiện (bubbles, composed): `select-change` (`detail: { ids, added,
removed }`, do người dùng), `activate`, `select-limit`. Hook `onSelectChange(ids)` gọi trước sự kiện. `TdMediaGrid.labels`
(`select`, `count`, `limit`) dịch được.

## Giao diện (Minimal surfaces)

Token `--td-media-grid-cols` (mặc định `repeat(auto-fill, minmax(160px, 1fr))`), `-gap`, `-radius`, `-tick-size` (24px),
`-tick-bg` (`rgb(0 0 0 / 35%)`), `-tick-border` (trắng), `-tick-on-bg` (`var(--td-btn-primary-bg)`), `-tick-on-fg` (`var(--td-btn-primary-fg)` — dark tự đảo theo primary),
`-selected-bg` (`--td-color-surface`), `-selected-scale` (0.88). Tick ẩn (`opacity: 0`) → hiện khi
`@media (hover: hover) and (pointer: fine)` + `:hover`, khi `:focus-within`, khi host `[data-selecting]`, khi item
`[data-selected]`; cảm ứng `(hover: none), (pointer: coarse)` → `opacity: 0.55`. Đã chọn: nền item `-selected-bg`, phần tử
mở `scale(var(--td-media-grid-selected-scale))`, tick đặc. Transition opacity / transform theo `--td-dur-*`; reduced
motion → không transform transition. Contrast (gate, **cả light và dark**): tick glyph ≥ 3.2 trên tick-on-bg; viền tick ≥ 3:1 trên ảnh tối và sáng
(viền trắng + vòng tối mảnh). Forced colors: tick viền `ButtonText`, chọn = `Highlight`. CSP: chỉ class / data attr.
