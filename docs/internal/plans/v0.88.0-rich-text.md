### Lane B — schema / sanitize / policy (`src/form/rich-text/`)
- `rich-text-policy.js` (thuần, không DOM; đã làm ở bước 1 — đây là interface chốt): `RICH_TEXT_POLICY = { version: 1,
  blocks: { tags: ['p','br'] }, features: { bold: {tags:['strong']}, italic: {tags:['em']}, underline: {tags:['u']},
  strike: {tags:['s']}, link: { tags: ['a'], attrs: { a: ['href'] } } }, presets: { comment: [...5] }, link: { schemes:
  ['https','mailto','tel'], optionalSchemes: ['http'], relative: true, fragment: true, rel: 'nofollow noopener', targets:
  ['_self','_blank'] } }` — `attrs.a` chỉ là thuộc tính NHẬN từ đầu vào (`href`); `rel`/`target` không bao giờ nhận, luôn
  ép ra (khớp mục PHP: "a chỉ `href`" + forceAttribute). `resolveFeatures({ preset, features }) → { features, unknown }`;
  `isSafeUrl(href, { allowHttp }) → string|null`; `normalizeLinkTarget(v) → 'none'|'_self'|'_blank'`;
  `policyFor(features, { allowHttp, linkTarget }) → { version, tags: {tag: attrs[]}, link: null | { schemes, relative,
  fragment, rel, target } }` (link = null khi tắt feature link; target thuộc luật link nên nằm trong đó — server cần nó
  để ép `target`, Codex plan r1 #2).
- `src/form/rich-text/rich-text-policy.json` sinh từ JS bằng script (`npm run build:rich-text-policy`, có `--check`), và
  `package.json#exports["./rich-text-policy.json"]`. `check:rich-text-policy` nối vào `test:ci:static` (Codex r1 #5);
  test manifest assert JSON có trong `npm pack --dry-run`.
- `rich-text-schema.js`: `buildSchema(PM, features, { allowHttp, linkTarget }) → Schema` — nhận module engine `PM` làm
  tham số (để test node không cần bundle thật vẫn chạy được với PM từ node_modules). Nodes: doc (block+), paragraph
  (`<p>`), text, hard_break (`<br>`). Marks chỉ cái được bật: strong (parse strong, b, font-weight ≥ 600 KHÔNG — chỉ
  tag), em (em, i), u (u), s (s, strike, del), link (a[href] qua `isSafeUrl`, sai → bỏ mark; toDOM luôn `rel` chuẩn +
  target theo `linkTarget` ('none' → không attr)). Không attr nào khác.
- `rich-text-html.js`: `parseHtml(PM, schema, html) → PM doc` (DOMParser của trình duyệt, `text/html`, document tách
  rời, chỉ đưa body vào `PMDOMParser.fromSchema(schema).parse`); `serializeHtml(PM, schema, doc) → string`
  (DOMSerializer vào fragment của `document.implementation.createHTMLDocument('')`, lấy innerHTML của div tạm; doc chỉ
  có 1 paragraph rỗng → `''`); `visibleText(doc) → string` (block/hard_break = `\n`, dùng cho required/maxlength, đếm
  code point).
- Test node `src/form/rich-text/rich-text-policy.test.js` (thuần) + browser test parse/serialize với fixture.
- Fixture chung `test/fixtures/rich-text/{malicious,canonical}.json`: `[{ name, input, features, allowHttp?, linkTarget?,
  expected }]` (linkTarget mặc định `none`; có ca rel/target đầu vào bị thay bằng giá trị server chọn)
  ≥ 25 ca độc (script, style, on*, javascript: các biến thể hoa/thường/tab/entity, data:, vbscript:, svg, iframe, img,
  form, style attr, nested a, rel/target giả) + ≥ 10 ca chuẩn.

### Lane C — component + toolbar + CSS + PHP
- `src/form/td-rich-text.js`: `class TdRichText extends TdFormElement`, tag `td-rich-text`, form-associated. Import
  `../vendor/td-rich-text-engine.js` + lane B. Attributes: `preset` (mặc định comment), `features`, `link-target`
  (none|_self|_blank), `allow-http`, `name`, `value` (giá trị đầu = reset), `label`, `placeholder`, `required`,
  `maxlength`, `disabled`, `readonly`, `helper-text`/`error-text` như form khác. Property `value` (get = HTML chuẩn, set
  = parse + sanitize, không phát event), `features` (get mảng đã resolve). Static `labels` (VN): bold "Đậm", italic
  "Nghiêng", underline "Gạch chân", strike "Gạch ngang", link "Liên kết", linkUrl "Địa chỉ liên kết", apply "Áp dụng",
  remove "Gỡ liên kết", cancel "Huỷ", invalidUrl "Địa chỉ không hợp lệ", toolbar "Định dạng".
- DOM (light): `.td-rich-text` > label, `.td-rich-text__toolbar[role=toolbar]` (nút `button.td-rich-text__tool
  [data-feature][aria-pressed]`, icon từ registry + `aria-label`), `.td-rich-text__editor` (PM view mount; dom
  `role=textbox aria-multiline=true aria-labelledby`, `aria-required`, `aria-invalid`, `aria-readonly`), helper/error,
  `.td-rich-text__link` (role=dialog, ẩn mặc định; input URL + 3 nút). DOM editor bền: base class KHÔNG rerender khi đổi
  value/validation/label/disabled.
- Vòng đời (Codex plan r1 #1): base rerender khi attribute observed đổi (`td-base-element.js` attributeChangedCallback →
  `_doRender`), khi effective-disabled đổi (`td-form-element.js` `_syncEffectiveDisabled`) và khi reconnect. TdRichText
  override `_doRender()`: lần đầu dựng shell + `EditorView`; các lần sau CHỈ đồng bộ tại chỗ (label text, aria-required/
  invalid/readonly, helper/error, `view.setProps({ editable })` theo effectiveDisabled/readonly, toolbar disabled) —
  không đụng `.td-rich-text__editor`. `preset`/`features`/`allow-http`/`link-target` đổi → dựng lại schema + `EditorState`
  từ HTML hiện tại qua `view.updateState` (cùng view, history mới), toolbar dựng lại. `disconnectedCallback` →
  `view.destroy()` + giữ HTML hiện tại; reconnect → tạo view mới từ HTML đó (history mất, chấp nhận). Browser test:
  đổi label/required/disabled/helper-text giữ nguyên node editor, selection và undo được; đổi features xoá history.
- Hộp link + focus (Codex r1 #6): mở (nút hoặc Mod-k) → lưu `{from,to}` selection PM, điền href hiện tại của mark (nếu
  có), focus ô URL. Áp dụng: URL qua `isSafeUrl` (sai → `invalidUrl` trong hộp, aria-invalid, không đóng); selection rỗng
  + đang trong link → sửa cả đoạn link; selection rỗng ngoài link → chèn text = URL có mark. Gỡ: bỏ mark link trên đoạn
  đó. Huỷ / Esc → đóng không đổi. Mọi đường đóng → trả focus editor + khôi phục selection đã lưu. Focus session cả
  component: `focusin` đầu tiên ghi giá trị khởi đầu; `focusout` mà `relatedTarget` ra ngoài host (kể cả null) → nếu
  value khác → `change` (dời qua toolbar / hộp link KHÔNG tính blur). Browser test đủ các đường trên.
- Phím: Mod-b/i/u, Mod-Shift-x (strike), Mod-k (hộp link), Shift-Enter = hard break, undo/redo; toolbar roving tabindex
  (←/→/Home/End), Tab ra khỏi toolbar vào editor.
- Form: `setFormValue(html, html)` mỗi transaction đổi doc; validity valueMissing (required + visibleText trim rỗng),
  tooLong (maxlength, code point); `formResetCallback` → giá trị đầu; `formStateRestoreCallback` → parse + sanitize;
  `formDisabledCallback`. Event `input` (bubbles, composed) mỗi transaction đổi doc; `change` khi blur nếu khác lúc focus.
  Đổi `preset`/`features`/`allow-http`/`link-target` sau khi chạy → dựng lại schema + state từ HTML hiện tại, xoá history.
- CSS `src/styles/components/rich-text.css` (@layer td.component, token `--td-rich-text-*`, light/dark, forced-colors,
  focus ring như input-field, min-height token, rule thiết yếu của prosemirror.css scoped `.td-rich-text .ProseMirror`).
  Vào `td.css` qua build-css. Touch: chuẩn touch.md (hover gate, pressed cho nút toolbar).
- Export: `package.json#exports["./rich-text"] = "./src/form/td-rich-text.js"` + thêm `./src/form/td-rich-text.js` vào
  `package.json#sideEffects` (Codex r1 #4; `src/package-manifest.test.js` bắt) + assert subpath trong test manifest;
  KHÔNG vào `index.js` (root barrel).
- PHP: xem lane B.
- Stories, docs `docs/components/rich-text.md` (+ hub), CSP matrix state `comment` + baseline, a11y page, touch case.

### PHP (lane B, Codex r1 #2 #3)
