## 1. Mục tiêu

dwp đang tự viết card album (ảnh bìa + tên + "42 ảnh · 12/02/2026" + nhãn "Live" / "Riêng tư") và ghi đó là **ngoại lệ có
tài liệu** vì kit chưa có card. Kit thêm một khối card dùng chung để dwp (và 135, dsuite…) bỏ ngoại lệ đó:

1. Cả card là **một** link (bàn phím: một tab stop; chuột: bấm đâu cũng đi; giữa / Ctrl-click / menu chuột phải mở tab
   mới như link thật).
2. Ô ảnh bìa (`<img>` hoặc `<picture>`) theo tỉ lệ token, **ô giữ chỗ** khi không có ảnh.
3. Tiêu đề, một dòng meta (vd. số ảnh · ngày), badge tuỳ chọn (dùng lại `.td-badge`).
4. Chạy trong lưới `@container` của site (không phụ thuộc viewport), không phóng to khi rê, có focus ring rõ.
5. CSP strict (dwp: `style-src-attr 'none'`; JS prod minify bằng esbuild) — không `style="…"`, không `<style>`.
6. PHP `td_card()` in đúng markup đó (SSR = chính markup cuối, không bước nâng cấp).

## 5. Hợp đồng markup (API công khai)

Đây là "SSR contract" của khối CSS: HTML tay, PHP và JS của site in **cùng** cây này. Không có `data-td-ssr`, không nâng
cấp.

```html
<!-- card link; ảnh bìa; badge; meta -->
<a class="td-card" href="/album/tet-2026">
  <span class="td-card__media">
    <img src="/media/tet-640.jpg" alt="" loading="lazy" decoding="async" width="640" height="480">
  </span>
  <span class="td-card__body">
    <span class="td-card__title">Tết 2026</span>
    <span class="td-card__badges"><span class="td-badge td-badge--danger">Live</span></span>
    <span class="td-card__meta"><span>42 ảnh</span><span class="td-card__sep" aria-hidden="true">·</span><time datetime="2026-02-12">12/02/2026</time></span>
  </span>
</a>

<!-- không ảnh: ô giữ chỗ (icon trang trí) -->
<span class="td-card__media"><span class="td-card__placeholder" aria-hidden="true"><svg class="td-icon td-icon--l" …></svg></span></span>

<!-- <picture> (markup tay) -->
<span class="td-card__media"><picture><source type="image/avif" srcset="…"><img src="…" alt=""></picture></span>

<!-- card tĩnh -->
<article class="td-card">…cùng con…</article>
```

| Class | Vai trò |
|---|---|
| `.td-card` | Gốc. `a.td-card` = card link (tương tác); `div` / `article` / `li > a` đều được. `position: relative`, cột flex, `color: inherit`, `text-decoration: none`, `-webkit-tap-highlight-color: transparent`. |
| `.td-card__media` | Ô ảnh: `aspect-ratio: var(--td-card-ratio)`, nền + viền 1px + bo góc, `overflow: hidden`. Con: `img`, `picture > img`, `.td-card__placeholder`. Ảnh `position: absolute; inset: 0; width/height: 100%; max-width: none; object-fit: var(--td-card-fit)` (như `.td-media-picker__coll-cover img`, chống reset `img { max-width:100%; height:auto }` của host). |
| `.td-card__placeholder` | Lấp ô ảnh, icon giữa, màu `--td-card-placeholder-fg`. |
| `.td-card__body` | Cột chữ dưới ảnh, padding `--td-card-body-pad`. |
| `.td-card__title` | Tiêu đề; kẹp `--td-card-title-lines` dòng (`-webkit-line-clamp` + `display: -webkit-box`, có `overflow-wrap: anywhere` cho chuỗi dài không cách). Có thể là `<hN class="td-card__title">` (margin 0, cỡ / đậm của card, không theo `h3` của host). |
| `.td-card__meta` | Một dòng, `--td-card-meta-fg`, cỡ `--td-card-meta-size`, `white-space: nowrap` + ellipsis. |
| `.td-card__sep` | Dấu ngăn meta, `aria-hidden="true"`, khoảng cách hai bên. |
| `.td-card__badges` | Hàng badge **đè góc trên-đầu của ô ảnh** (`position: absolute` theo `.td-card`, `inset-block-start` / `inset-inline-start: var(--td-card-badge-inset)`, xuống dòng, `max-inline-size` = bề rộng card trừ 2 × inset). Nằm **sau tiêu đề trong DOM** để tên truy cập đọc "Tết 2026 Live 42 ảnh…" thay vì "Live Tết 2026…" (Q3). |
| `.td-card--surface` | Biến thể hộp: nền `--td-card-bg` + viền `--td-card-border` + bóng `--td-card-shadow` + bo `--td-card-radius`; ô ảnh mất viền riêng, bo góc trên theo hộp (đồng tâm, luật 8). |
| `.td-card--ratio-{1x1,4x3,3x2,16x9,3x4}` | Đặt `--td-card-ratio` (allowlist D7). Mặc định không class = token (`4 / 3`, Q2). |
| `.td-card-grid` | (tuỳ chọn, D9) Lưới `auto-fill, minmax(min(var(--td-card-grid-min), 100%), 1fr)` + gap; **không** container query, **không** `container-type`. Site có lưới `@container` riêng thì bỏ qua class này. |

Trạng thái: `a.td-card:focus-visible`, `:hover` (trong cổng hover), `:is(:active, [data-td-pressed])`. Không bật tắt class
hiển thị.

## 7. PHP `td_card()`

```php
td_card(string $title, array $o = []): string
```

| Option | Kiểu | Hành vi |
|---|---|---|
| `href` | string | `Td::safeUrl()` (http chỉ khi site gọi `Td::allowHttpLinks()`), rồi **từ chối `mailto:` / `tel:`** (card không phải link liên hệ). Hợp lệ → `<a class="td-card" href>`; không có / bị từ chối → card tĩnh `<div>` (không link chết, không cảnh báo — như `td__filter_href`). |
| `target` | `Td::TARGETS` | Chỉ khi có link; `_blank` → thêm `rel="noopener noreferrer"` như `td_button`. |
| `image` | string \| array `{src, srcset?, sizes?, alt?, width?, height?}` | `src` qua `td__media_url()` hiện có (https / http / tương đối; `mailto:` / `tel:` / `javascript:` / `data:` → bỏ). `srcset`: tách từng ứng viên, URL qua `td__media_url()`, mô tả khớp `^\d+(\.\d+)?[wx]$`; một ứng viên hỏng → bỏ **cả** `srcset` (fail closed). `sizes`: chuỗi, escape, ≤ 512 byte. `width` / `height`: số nguyên 1–10000. `alt`: mặc định `''` (tiêu đề đã gọi tên card). `loading="lazy" decoding="async"` luôn in; `eager => true` bỏ `loading` (ảnh đầu màn hình). Ảnh bị bỏ → ô giữ chỗ. |
| `placeholder_icon` | string | Tên registry (mặc định `image`, Q6); tên lạ → icon mặc định. Qua `Td::icon($name, 'l')`. |
| `meta` | string \| list | Mỗi mục: string (text) hoặc `['text' => …, 'datetime' => …]` → `<time datetime>` (datetime khớp regex ngày / giờ ISO 8601 rút gọn, sai → `<span>`). Nối bằng `span.td-card__sep[aria-hidden]` "·". Mục rỗng bị bỏ; không mục nào → không in `.td-card__meta`. |
| `badges` | list | Mỗi mục: string hoặc `[text, opts]` → `td_badge(text, opts)` (cùng allowlist / escape). Rỗng → không in `.td-card__badges`. |
| `heading` | int 2–6 | Tiêu đề là `<hN>`; khác → `<span>`. |
| `ratio` | `'1x1' \| '4x3' \| '3x2' \| '16x9' \| '3x4'` | → class `td-card--ratio-…`; khác → bỏ qua. |
| `surface` | bool | → `td-card--surface`. |
| `id`, `class`, `attrs` | | Như `td_badge`: `id` scalar, `class` qua `Td::classTokens`, `attrs` qua `Td::attrs()` (allowlist: `aria-*`, `data-*`, `ALLOWED_ATTRS`; `on*` / `style` / `href` / `src` bị chặn); tên đã in (`class`, `href`, `target`, `rel`) **và `role`, `tabindex`, `aria-label`, `aria-labelledby`, `data-td-*`** giữ chỗ qua `$taken` (bị bỏ). Lý do: `ALLOWED_ATTRS` (`php/td.php` ~111) cho `role` / `tabindex`, nhưng `role="button"` / `tabindex="-1"` trên `a.td-card` phá D2 (một tab stop, link thật); `aria-label` / `aria-labelledby` ghi đè tên lấy từ nội dung, trái Q7 (§14); `data-td-*` dành cho kit (tiền lệ "owned names and data-td-* reserved" của các helper khác). Các `aria-*` khác (vd. `aria-describedby`, `aria-current`) vẫn qua. |

`$title` là **text** (escape). Thứ tự con cố định như §5; mọi giá trị qua `Td::e()` trong ngoặc kép. Helper không có
`element` mode (không có custom element). Tên hàm theo quy ước `td_*`; 135 / dwp gói lại trong adapter riêng của họ.

## 8. Hành vi CSS chi tiết

- **Ô ảnh:** `aspect-ratio` trên `.td-card__media` (box giữ chỗ trước khi ảnh tải → không CLS dù thiếu `width` /
  `height`). Ảnh lỗi với `alt=""`: không vẽ gì, nền `--td-card-media-bg` lộ ra (đo ở 3 engine; nếu engine nào vẽ icon vỡ
  thì ghi docs khuyên `alt=""` + `onerror` của site là việc site — kit không thêm JS).
- **Badge:** đè ảnh nhưng vẫn là badge đặc của kit (chữ trên nền của nó, không phụ thuộc ảnh); gợi ý `--glass` trong docs
  cho ảnh nhiều màu.
- **Rê (chỉ trong `@media (hover: hover) and (pointer: fine)`):** bare → viền ô ảnh `--td-card-hover-border` (ngoại lệ
  luật 6 theo tiền lệ coll, D4); `--surface` → nền đặc `--td-card-hover-bg`. Không đổi chữ, không gạch chân (Q5).
- **Nhấn:** `a.td-card:is(:active, [data-td-pressed])` → `.td-card__media::after` phủ `--td-color-pressed` (như
  `.td-media-picker__coll`), viền như hover; `a.td-card.td-card--surface:is(:active, [data-td-pressed])` thêm nền nhấn
  (lớp `--td-color-pressed` trên `--td-card-bg`) — base nhấn thứ hai, có mục riêng trong `PRESS_TARGETS` (§4).
  `transition-duration: 0s`.
- **Focus:** `a.td-card:focus-visible { outline: 2px solid transparent; box-shadow: var(--td-focus-ring); border-radius:
  var(--td-card-radius) }` — vòng quanh **cả** card (ảnh + chữ). Outline trong suốt giữ cho forced colors.
- **Chuyển động:** chỉ `border-color` / `background-color` `var(--td-dur-fast)`; reduced motion → không transition.
- **Fallback:** `prefers-contrast: more` → viền ô ảnh / hộp `currentColor`, bỏ bóng; `forced-colors: active` → viền
  `CanvasText`, focus + nhấn `outline: 2px solid Highlight`, ô giữ chỗ `Canvas` / icon `GrayText`.
- **Dark:** chỉ qua token (ADR 0020); không selector dark riêng ngoài khối token.
- **Host reset:** chạy được dưới profile `legacy+td` (Tailwind preflight `img { max-width: 100%; height: auto }`, `h3 {
  font-size: inherit }`) — kiểm bằng `test:csp:combined`.

## 9. Bảo mật

- **Không có JS** → không bề mặt XSS phía client của kit; HTML tay là trách nhiệm của site (như badge).
- **PHP:** text (`title`, meta, badge) escape `Td::e()` (`ENT_QUOTES | ENT_SUBSTITUTE`); `href` qua `Td::safeUrl()` + bỏ
  `mailto:` / `tel:` (chặn `javascript:`, `java\tscript:`, `data:`, `vbscript:`, `:` trước `/`); ảnh qua `td__media_url()`
  (giới hạn 8192 byte, UTF-8 hợp lệ); `srcset` kiểm từng ứng viên, fail closed; `datetime` qua regex; `heading` / `ratio`
  / `target` allowlist; `attrs` qua `Td::attrs()` (không `style`, không `on*`, không thuộc tính mang URL); `class` qua
  `Td::classTokens`. Không hatch HTML mới (security-model §2 không đổi).
- `target="_blank"` → `rel="noopener noreferrer"` (chống tabnabbing).
- **CSP:** không `style="…"`, không `<style>`, không CSSOM (không có JS); tỉ lệ per-card qua class allowlist (D7). Chạy
  dưới `style-src-attr 'none'` của dwp và nonce-only. Không `url()` trong CSS card (icon giữ chỗ là SVG inline của registry).
- **Security-model:** thêm mục **mới** "`.td-card` / `td_card()`" (chính sách URL của href / ảnh, `srcset` fail closed,
  `role` / `tabindex` / `aria-label` / `aria-labelledby` / `data-td-*` bị chặn trong `attrs`); lane ghi tiêu đề không số, phiên chính đánh số lúc gộp.
- Gate: `codex-security-review` bắt buộc (input người dùng → URL / escape trong PHP).

## 10. Trợ năng + cảm ứng

- **Tên truy cập** của link = nội dung theo thứ tự DOM: tiêu đề, badge, meta (dấu "·" `aria-hidden`; ảnh `alt=""`).
  Test assert tên ở 3 engine (khoảng trắng giữa các khối — `<span>` block có khoảng trắng nguồn giữa chúng; PHP in một
  khoảng trắng giữa con để không phụ thuộc engine). Q7 (chốt): cả nội dung, không `aria-labelledby`.
- **Không phần tử tương tác lồng** (HTML không hợp lệ + tên lẫn lộn) — docs ghi rõ, D10 cho nhu cầu sau.
- **Tiêu đề bị kẹp** vẫn đủ chữ trong DOM (trình đọc màn hình đọc đủ); người nhìn mất phần cuối — docs khuyên tiêu đề ngắn.
- **Heading:** tuỳ chọn `heading` để duyệt theo heading trong trang album.
- **Card tĩnh** không có `tabindex`, không con trỏ tay.
- **Cảm ứng ([touch.md](../design/touch.md)):** hover chỉ trong cổng (luật 1); `a.td-card` có luật nhấn ngoài cổng (luật 4)
  + `PRESS_TARGETS` (luật 6); hình nhấn chỉ đổi màu (luật 5); không `touch-action` mới (luật 9 — bảng không đổi); card
  ≥ 44px mọi chiều ở mọi bề rộng hợp lý (gate responsive đo). Không thông tin chỉ hiện khi rê (luật 3).
- **Hạn chế đã biết:** WebKit iOS chỉ áp `:active` khi trang có listener `touchstart`; `data-td-pressed` do
  `ensurePressStates()` đặt, mà hàm này chỉ chạy khi có phần tử kit nào đó connect. Trang **chỉ** có card (không module
  kit nào) → không có hình nhấn trên iPhone (điều hướng vẫn đúng). Xem §13.

## 16. Tiêu chí nghiệm thu
