## M1 — Chế độ chỉ chọn (`selection-only`)

- Attribute **`selection-only`**: chỉ chọn từ `options` / kết quả `search()`; chữ gõ chỉ để lọc, **không bao giờ** thành
  chip (Enter không có option active → không làm gì; `allow-create` bị bỏ qua + cảnh báo một lần nếu đặt cùng).
- Listbox `aria-multiselectable="true"`; các mục **đã chọn vẫn hiện** trong danh sách với dấu ✓ + `aria-selected="true"`
  (thay vì bị lọc khỏi danh sách như chế độ thường); Enter / Space (khi popup mở và có option active) / click **lật** chọn;
  popup **giữ mở** sau mỗi lần chọn (attribute `close-on-select` để đổi); Backspace ở ô rỗng gỡ chip cuối (như hiện có).
- `max-items` hiện có: khi đầy, mục chưa chọn `aria-disabled="true"` + thông báo live region "Đã đạt tối đa N mục".

## M2 — "Chọn tất cả kết quả đang hiện"

Attribute **`select-all`** (chỉ có hiệu lực cùng `selection-only`): dòng đầu listbox `role="option"`
`td-chip-input__option--all` "Chọn tất cả (N)" / "Bỏ chọn tất cả (N)" — N = số mục **đang hiện** (đã lọc, chưa disabled),
tới được bằng bàn phím như mọi option, chọn → thêm mọi mục đang hiện chưa chọn (dừng ở `max-items`, báo số đã thêm) hoặc gỡ
hết các mục đang hiện. Không bao giờ chọn mục chưa tải (kết quả server ngoài trang hiện tại — việc của app).

## M3 — Nâng cấp `<select multiple>` (progressive enhancement)

Như `td-dropdown` 0.17: lần connect đầu, `<select multiple>` con trực tiếp → `options` (value, label, `disabled`,
`<optgroup>` → nhóm hiển thị / disabled), các `<option selected>` (state sống `selectedOptions`) → giá trị ban đầu, `name`
/ `required` / `disabled` lên host, `<label for>` ngoài → host; gỡ select. Ngầm bật `selection-only`. Select đang focus lúc
nâng cấp → chờ `blur` (như dropdown v0.26) rồi nâng cấp một lần. Không có select → hành vi hiện tại không đổi.

## M4 — Gửi form

`name` giữ **nguyên văn** (Laravel / PHP dùng `name="roles[]"` — component không tự thêm `[]`); `FormData` có **một mục mỗi
giá trị đã chọn**, đúng thứ tự chọn; không chọn gì → không mục nào; `required` → validity `valueMissing` khi rỗng; reset → về
lựa chọn mặc định (option `selected` gốc / attribute `value`). Kiểm tra hành vi hiện tại của chip-input và sửa nếu lệch.

## M5 — PHP `td_multiselect($name, array $options, array $selected = [], array $o = [])`

- Mặc định (native): `<select multiple name="{name}" class="td-multiselect__native">` + option (value / label / disabled /
  optgroup như `td_dropdown`), `selected` theo `$selected`, `required`, `size` (mặc định 4) — dùng được khi không JS.
- `['element' => true]` / `ssr_elements`: `<td-chip-input data-td-ssr="chip-input@1" selection-only [select-all]
  [max-items] [placeholder] [label]>` + select ở trên (nâng cấp theo M3). Select element-mode được tạo kiểu
  (`.td-chip-input__native`) với **chiều cao tối thiểu bằng hộp chip** để giảm xô lệch (không triệt tiêu được hẳn vì số chip
  quyết định chiều cao sau nâng cấp — ghi docs). Escape / allowlist / giữ chỗ tên như các helper element khác.
