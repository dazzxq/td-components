Owner: "cái liquid glass chúng ta fake bằng css này lại ko đẹp lắm… bỏ hoàn toàn glass effect → chỉ đơn thuần giữ lại
shadow và blur nhẹ nhàng… lấy dcms làm tham khảo… simple thôi" → chốt "như mày đề xuất đi" (popup 94% + blur nhẹ).
Hướng đi: Codex think-about (gpt-5.6-sol + high, 2 vòng, CONSENSUS). Tham khảo: dcms2 `resources/css/dcms-glass.css`,
`resources/css/components/dcms-btn.css` (chỉ đọc). Không dependency mới, không đổi markup / class công khai / API JS.

## Mục tiêu

Mỗi bề mặt chỉ còn **nền + một viền mảnh + một shadow mềm (+ blur 12px nếu là popup nhỏ)**. Bỏ: sheen (gradient
bóng), inset rim hai tông, hairline ngoài, film / tint trong suốt của nút, status wash của toast, glow khi hover, mọi
scale trang trí (press / lift / pop / enter), lens clear của slider, glyph shadow. Giữ transform **chức năng** (vị trí
thumb slider, trượt thumb switch, zoom/kéo lightbox, xoay mũi tên dropdown).

## Công thức theo lớp

| Lớp | Công thức |
|---|---|
| Modal, loading card, tooltip, bảng datetime (nằm trong modal) | **Đặc** `--td-glass-solid`; không blur; viền + `--td-glass-shadow-lg` (modal) / `--td-glass-shadow` (tooltip) |
| Menu, dropdown, gợi ý chip-input, hovercard, toast | `--td-glass-bg-strong` 94% + `--td-glass-blur` 12px + viền + `--td-glass-shadow` |
| Toast | Nền trung tính như trên; **icon** mang màu trạng thái; bỏ wash |
| Lightbox toolbar / counter | Tối `--td-glass-clear-bg` 88% + blur 12px; bỏ dim cục bộ, glyph shadow, rim. Panel / sheet: đặc `--td-glass-clear-solid`. Caption gradient (lớp đọc chữ trên ảnh) giữ |
| Nút (mọi variant có nền) | **Màu đặc** `--td-btn-{v}-bg`; không blur / film / sheen / rim / hairline / glow / scale; một shadow `--td-btn-lift`; hover = nền đậm hơn (token hover hiện có / `color-mix` với đen ~8% + fallback cố định); focus ring giữ. Ghost + disabled: không shadow |
| Switch, slider, scroll-top, chip | Đặc; thumb / nút một shadow nhẹ; không blur, glow, scale trang trí |

### Ánh xạ selector (markup không đổi — mọi bề mặt vẫn mang `.td-glass-surface` + modifier như hiện nay)

| Nhóm | Selector (class JS đang phát ra) | Vật liệu |
|---|---|---|
| Đặc | `.td-modal__dialog`, `.td-loading__card`, `.td-tooltip`, `.td-scroll-top` (đều `.td-glass-surface--strong`) | Một rule trong `glass.css`: `:is(…).td-glass-surface` → `background-color: var(--_td-glass-fill, var(--td-glass-solid))`, `backdrop-filter: none`. Fallback vẫn ghi đè `--_td-glass-fill` (contrast / forced-colors) |
| Blur nhẹ | `.td-menu`, `.td-dropdown__menu`, `.td-chip-input__menu`, `.td-hovercard`, `.td-toast` | Recipe mặc định `.td-glass-surface--strong` (94% + blur 12px) |
| Lightbox | `.td-lightbox__toolbar`, `.td-lightbox__counter` (`--clear`) | `--clear` rút gọn: nền tối 88% + blur 12px + viền + shadow; panel / sheet lightbox đặc |

Gỡ các override cũ trong component CSS chỉ phục vụ glass (ví dụ modal / toast "covered-surface", wash toast, rim /
sheen riêng), để mỗi nhóm chỉ còn công thức trên. `--lg` chỉ còn đổi shadow sang `--td-glass-shadow-lg` (không blur
riêng).

### Nút màu tuỳ biến (`.td-btn--custom`, attribute `color` / `text-color` → `--td-btn-bg` / `--td-btn-fg`)

Giữ nguyên API công khai. Vào cùng hợp đồng nút đặc: nền đặc `--td-btn-bg`, một shadow `--td-btn-lift`, hover = nền đậm
hơn **đặc** (`color-mix(in srgb, var(--td-btn-bg) 92%, #000)`, fallback không `color-mix` → giữ nền + không đổi), bỏ đường
`background-image` gradient trong suốt khi hover. Có test browser + nằm trong contrast gate như hiện nay.

## Token (giá trị mặc định mới)

Light: `--td-glass-bg: rgb(255 255 255 / 90%)`, `--td-glass-bg-strong: rgb(255 255 255 / 94%)`, `--td-glass-solid: #fff`,
`--td-glass-fg: #18181b`, `--td-glass-border: rgb(0 0 0 / 7%)`, `--td-glass-blur` = `--td-glass-blur-lg` = `blur(12px)`,
`--td-glass-shadow: 0 4px 16px rgb(0 0 0 / 6%)`, `--td-glass-shadow-lg: 0 8px 24px rgb(0 0 0 / 9%)`,
`--td-btn-lift: 0 1px 2px rgb(0 0 0 / 6%), 0 2px 6px -2px rgb(0 0 0 / 8%)`.
Dark: `--td-glass-bg: rgb(28 28 30 / 90%)`, `-bg-strong: rgb(28 28 30 / 94%)`, `-solid: #1c1c1e`, `-fg: #f5f5f7`,
`-border: rgb(255 255 255 / 10%)`, blur như light, `-shadow: 0 4px 16px rgb(0 0 0 / 18%)`, `-shadow-lg: 0 8px 24px
rgb(0 0 0 / 24%)`, `--td-btn-lift: 0 1px 2px rgb(0 0 0 / 18%), 0 2px 6px -2px rgb(0 0 0 / 20%)`.
Lightbox (không theo theme): `--td-glass-clear-bg: rgb(20 20 22 / 88%)`, `-clear-solid: #141416`, `-clear-fg: #fff`,
`-clear-border: rgb(255 255 255 / 12%)`, `-clear-shadow: 0 4px 16px rgb(0 0 0 / 24%)`.
Nút: `--td-btn-primary-bg: var(--td-accent-fill)` (giữ theo accent của site); success / danger / info / warning `-bg`
= màu tint đặc hiện có (`#15803d` / `#b91c1c` / `#1d4ed8` / `#f59e0b` + fg hiện có); secondary dùng `--td-btn-secondary-bg
/-fg/-border/-hover` (dark có giá trị riêng). Giá trị cuối cùng phải qua contrast gate (chữ ≥ 4.7, icon ≥ 3.2).

**Giữ (công khai):** `--td-glass-bg`, `-bg-strong`, `-solid`, `-fg`, `-border`, `-blur`, `-blur-lg`, `-shadow`,
`-shadow-lg`, `-scrim`, `-clear-bg/-solid/-fg/-border/-shadow`, token hình học / thời lượng, `--td-btn-*-bg/-fg/-border/
-hover`, `--td-btn-lift`.
**Deprecated (vẫn khai báo, không còn tác dụng; xoá ở bản lớn sau):** `--td-glass-edge`, `-side-edge`, `-bottom`,
`-outline`, `-sheen`, `-dim`, `-dim-text`, `-clear-edge`, `-clear-glyph-shadow`, `-tint`, `-tint-alpha`, `-tint-fg`,
`-tint-edge`, `-glow`, `-glow-size`, `-press-scale`, `-lift-scale`, `-enter-scale`, `--td-btn-*-alpha`, `--td-btn-*-film`,
`--td-btn-sheen`, `--td-btn-secondary-glass`, `--td-btn-secondary-edge`.
**Alias tương thích một chu kỳ:** `--td-btn-{success,danger,info,warning,primary}-tint` → nếu site đặt thì vẫn là màu nền
nút (135 đang đặt `--td-btn-danger-tint`): `-bg` mặc định đọc `var(--td-btn-{v}-tint, <mặc định>)`, hoặc tương đương.
**Xoá ngay (nội bộ):** mọi `--_td-*` riêng cho rim / film / sheen / glow / scale, `--td-glass-wash`.
Class `.td-glass-surface*`, `.td-glass-dim*`, `.td-glass-tint` giữ tên (markup không đổi), recipe rút gọn; `.td-glass-tint`
= nút capsule đặc.

## Fallback (giữ, theo thứ tự)

1. Không hỗ trợ `backdrop-filter` → nền đặc. 2. `prefers-reduced-transparency` → đặc, không filter. 3. `<html
data-td-glass="off">` → đặc, không filter. 4. `prefers-contrast: more` → đặc, viền rõ, không filter / shadow. 5.
`forced-colors` (cuối) → màu hệ thống, viền thật, không filter / shadow / background-image. Nút luôn đặc nên chỉ còn
xử lý forced-colors + contrast cho viền.

## Test

- Token gate (`test/tokens/tokens.spec.mjs`): assertion cho **từng selector** trong bảng ánh xạ — nhóm đặc (modal,
  loading, tooltip, scroll-top) và mọi nút (kể cả `--custom`) **không** `backdrop-filter`, nền đặc; nhóm blur (menu,
  dropdown, chip-input menu, hovercard, toast) blur 12px + nền 94%; lightbox toolbar / counter blur 12px nền tối;
  không còn `background-image` sheen / rim; fallback vẫn ép đặc.
- Contrast gate: giữ ngưỡng, chạy lại 3 engine × light/dark × 4 backdrop; chỉnh token nếu thiếu.
- Browser test hiện có đo glass cũ (sheen, glow, scale, wash…) → sửa theo hành vi mới, không xoá test chức năng.
- CSP baseline: xem diff rồi recapture (`npm run capture:baseline`) cho component đổi giao diện; matrix giữ nguyên state.
