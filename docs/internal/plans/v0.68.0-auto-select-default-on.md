# v0.68.0 — `autoSelectFirst` mặc định BẬT

Trạng thái: **xong** (2026-10-12): Codex plan APPROVE r2; core, test, docs xong. Đã kiểm: `test:node` 1765, họ bộ test picker / field / gallery (27 file engines) 978 mỗi engine trên Chromium / Firefox / WebKit, `test:csp` và `test:csp:combined` 424/424 với baseline không đổi, `test:ci:static` xanh; thêm suite `td-v068-media-field-auto-select` chạy picker thật qua `td-media-field`. Nhánh `feat/v0.68.0-auto-select-default-on` từ `main` 60f2221 (v0.67.0).

## Nguồn

v0.67.0 thêm `autoSelectFirst` ở dạng opt-in (mặc định tắt) vì nó đảo quy tắc v0.36.0 (QĐ 69: "mở ra thì không tự chọn gì, 'Chèn'
tắt tới khi người dùng chọn"). Tao hỏi owner: "mặc định tắt hay bật?" và nói chưa trả lời thì giữ tắt. Owner trả lời trong chat
(2026-10-12): **"bật đê"**. Plan v0.67.0 ghi sẵn khả năng này: lật mặc định là một thay đổi riêng, có ghi trong CHANGELOG, như `assets`
ở 0.65.

## Hiện trạng cần biết

- `resolveOptions` (core) trả `autoSelectFirst: merged.autoSelectFirst === true`. Picker đọc giá trị đã resolve:
  `const autoFirst = opts.autoSelectFirst === true && !opts.selection.initialIds.length;` nên **picker không cần đổi logic**.
- `apply()` trong `resolveOptions` bỏ qua `null` cho `initialCollection` / `collections` (null = vắng, không đè lớp dưới).
  `autoSelectFirst: null` hiện chưa nằm trong danh sách đó.
- Chỉ dsuite dùng picker. 135 và dwp không dùng. `td-media-field` truyền `selection.initialIds = [giá trị]` khi đã có ảnh nên không bị
  tự chọn đè; field còn trống thì được chọn sẵn ảnh đầu. `td-media-gallery` mở picker `multiple` để thêm ảnh.
- Gần 30 file test chạm picker / field / gallery (`src/feedback/td-media-picker*`, `td-v033-media-picker-*`, `td-v035-*`,
  `td-v036-*`, `td-v066-*`, `td-v067-*`, `media-picker-fields`, `src/form/td-media-field*`, `td-media-gallery*`, `td-v043-*`,
  `td-v051-*`, `td-v044-*`, `td-v042-*`, `td-v062-*`, `td-v034-narrow`…) và baseline CSP / visual của `td-media-picker`,
  `td-media-field`, `td-media-gallery`. Nhiều test mặc định dựa vào "mở ra thì chưa chọn gì".

## Quyết định

1. **Chỉ `false` mới tắt.** `resolveOptions`: `autoSelectFirst: merged.autoSelectFirst !== false`. Không đặt, `undefined`, `null`
   → bật. Vì `false` là cách duy nhất tắt, mọi giá trị khác (kể cả chuỗi, số) đều bật; docs nói rõ "chỉ boolean `false`".
2. **`null` = vắng.** Thêm `autoSelectFirst` vào danh sách `null` bị bỏ qua trong `apply()` (như `initialCollection` /
   `collections`): `open({ autoSelectFirst: null })` không đè `configureDefaults({ autoSelectFirst: false })`.
3. **Mọi quy tắc khác của v0.67.0 giữ nguyên:** chỉ lần tải danh sách đầu (và "Thử lại" của nó khi lỗi), một asset đầu tiên chọn
   được, `multiple` cũng chỉ chọn một, bỏ qua khi `selection.initialIds` có phần tử, lập trình (không phát `selection-change`),
   một thông báo live region gộp, không chuyển focus.
4. **Cách tắt:** `TdMediaPicker.configureDefaults({ …, autoSelectFirst: false })` cho cả site, hoặc `open({ autoSelectFirst:
   false })` / `pickerOptions.autoSelectFirst` của `td-media-field` cho một lần mở.
5. **Không đổi logic picker.** Chỉ sửa comment còn ghi "opt-in" / "mặc định tắt" (docblock `_autoSelectFirst`, header, typedef core).
6. **Test cũ giữ nguyên ý nghĩa bằng cách tắt tường minh.** Các test được viết với tiền đề "mở ra chưa chọn gì" (kiểm "Chèn" tắt, đếm
   selection, v.v.) thêm `autoSelectFirst: false` vào chỗ mở picker (hàm `open` / `openReady` dùng chung của file đó, hoặc fixture),
   không đổi nội dung kiểm tra. Test nào **cố ý** kiểm hành vi tự chọn thì bỏ `false`. Baseline CSP / visual của picker giữ nguyên.
   Chỗ mở picker của chúng nằm ở **`test/csp/matrix.json`** (mỗi state mở picker bằng `TdMediaPicker.open({...})` trực tiếp, không có
   fixture dùng chung): **mọi** state mở picker trong file đó, kể cả các luồng `multiple`, phải thêm `autoSelectFirst: false`, vì mục
   đích của chúng là parity style của đúng trạng thái trước 0.68, không phải hành vi chọn. Tương tự mọi setup trực tiếp trong
   `test/touch`, `test/responsive`, `test/visual` (nếu có) và `test/theme`. (Codex plan r1 #1)
7. **Bộ test v0.67 đảo chiều:** không đặt option → được chọn sẵn; `autoSelectFirst: false` → không chọn gì (các ca "stays off" dùng
   `false` tường minh); thêm ca `null`, ca `configureDefaults({ autoSelectFirst: false })`, và ca `open({ autoSelectFirst: true })`
   vẫn bật.
