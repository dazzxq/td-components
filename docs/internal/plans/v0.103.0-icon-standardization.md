# v0.103.0: chuẩn hoá icon dsuite / dcms2 → kit

Luật: glyph tô đặc (`ds-fa-*`, `ds-flame`) = app-kept (filled), không map sang icon nét; logo, `audit-*`, `flame-tick`, `toc`, `embed`, `callout` = app-kept (app-specific).
