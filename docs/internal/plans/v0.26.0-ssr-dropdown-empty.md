## D1 — Vỏ dropdown (giữ đường `<select>` nâng cấp 0.17)

Hiện `td_dropdown()` in `<td-dropdown><select>…</select></td-dropdown>`; JS (connect đầu) đọc `<select>` (giá trị sống,
`disabled`, `required`, optgroup), gỡ nó, render trigger → khung hình đầu là `<select>` mặc định của trình duyệt (cao / viền /
font khác) rồi nhảy sang trigger (layout shift).
- **Element mode** (`['element' => true]` / `ssr_elements`): helper in `<td-dropdown data-td-ssr="dropdown@1" …>` + `<select
  class="td-dropdown__native td-field__control" …>` — **cùng hộp với trigger**: CSS `.td-dropdown__native` (chỉ áp khi
  host `:not(:defined)` hoặc chưa nâng cấp) cho **giữ mũi tên native** (không `appearance: none`, không
  ảnh `data:` — CSP chặt `img-src 'self'`), đặt **hộp** trùng trigger: `box-sizing`, chiều cao / `min-height`, padding,
  viền, bo góc, font, line-height, màu nền / chữ theo token trigger (`--td-field-*`), độ rộng `100%`. Mũi tên native có thể
  khác hình chevron của trigger (khác **pixel**, không khác **hộp**) — chấp nhận; test đo hộp, không đo hình mũi tên. Không-JS: select native chọn / submit / `required` như cũ.
- **Thứ tự connect đầu (cụ thể):** `TdDropdown.connectedCallback()` hiện gọi `_upgradeSelect()` (gỡ select) **trước**
  `super.connectedCallback()`. Thêm bước **trước mọi thay đổi DOM**: nếu host có dấu `dropdown@1` và `<select>` con trực
  tiếp **đang là `document.activeElement`** → không `_upgradeSelect()`, không `super.connectedCallback()` (không render /
  bind); gắn **một** listener `blur` (capture) trên select. Khi `blur`: gỡ listener, chạy đường bình thường **đúng một lần**
  (`_upgradeSelect()` chụp lựa chọn sống **lúc đó** → `super.connectedCallback()`). Ngắt kết nối khi đang hoãn → gỡ
  listener, xoá cờ; gắn lại → đánh giá lại từ đầu (focus có thể đã khác). Không dùng cơ chế `'defer'` của base (base chưa
  thấy select). Thay xong trigger có **cùng bounding box** (test 0 lệch). Label ngoài
  `for` → host (đã có). Lệch / thiếu dấu → hành vi 0.17 hiện tại (không đổi).
- Host không element mode: không đổi gì.

## D2 — `td_empty()` + hydrate `<td-empty-state>`

- Helper mới `td_empty(string $title, string $message = '', array $o = [])`: `icon` (registry / `site-*`; **không có hoặc tên
  lạ → `inbox`**, đúng như `TdEmptyState` hiện fallback), `size` (sm|md|lg), `compact`, `heading` (2–6, mặc định như component), `actions` (mảng `['label' =>, 'href' =>,
  'variant' =>]` → in bằng `td_link(…, ['element' => true])` trong `.td-empty-state__actions`, bỏ `hidden`), `id`,
  `class`, `attrs` (allowlist). Luôn in **element** (component không state, không có dạng native): `<td-empty-state
  data-td-ssr="empty-state@1" title message size [compact] [heading-level] [icon]>` + đúng cấu trúc `render()` (icon SVG
  điền sẵn qua registry PHP, heading đúng cấp, message, actions).
- JS `TdEmptyState`: `hydratable = true`, `SSR_SCHEMA = 1`, `canHydrate()` so cấu trúc + allowlist thuộc tính (mẫu v0.25:
  `on*` / `style` / `data-td-*` lạ → render lại); hydrate giữ node; **actions SSR giữ nguyên** cho tới khi site gán
  property `actions` (JS) — lúc đó thay như hiện nay. Lệch → render lại (không state). **Hai trạng thái hợp lệ của actions:**
  mỗi action là `<td-button data-td-ssr="button@1">` (chưa hydrate: dấu còn, `td-button` chưa define hoặc định nghĩa sau)
  **hoặc** `<td-button>` đã hydrate (dấu đã gỡ, cùng control `<a class="td-btn">`) — cả hai được chấp nhận; allowlist thuộc
  tính áp như v0.25 cho cả hai (thuộc tính lạ → render lại). Thứ tự define: gốc package (`index.js`) định nghĩa `td-button`
  trước `td-empty-state`; import riêng `empty-state` → nút con chưa define (vẫn là SSR hợp lệ, không JS vẫn bấm được link).

## Test

- Fixture `test/ssr/dropdown.fixtures.json` + `empty.fixtures.json` → HTML sinh sẵn (kiểm stale).
- Nhóm SSR 3 engine: dropdown — bounding box host / control trước define (select đã tạo kiểu) = sau (trigger), Chromium
  không `layout-shift`; lựa chọn người dùng đổi trước define giữ; select đang focus → defer tới blur rồi nâng cấp, focus
  không rơi; `FormData` một mục; `required` không-JS chặn submit; optgroup / disabled; label ngoài. Empty-state — DOM sau
  hydrate = `render()` **cho fixture không actions**
  (so chuẩn hoá: nội dung SVG icon do server điền được so theo tên `data-icon`, không theo chuỗi); fixture **có actions**
  kiểm riêng: giữ identity node actions, cấu trúc an toàn (allowlist), bấm được, gán `actions` JS thay đúng — không so
  `render()` (render luôn ra actions rỗng / hidden); 0 lệch; icon không có / tên lạ → `inbox`
  cả PHP lẫn JS; actions SSR còn và bấm được — chạy **hai** cách nạp: gốc package (button hydrate trước) và chỉ
  `empty-state` (button chưa define); gán `actions` JS thay đúng; markup bị chèn thuộc tính lạ →
  render lại.
- PHP: `td_empty` escape / allowlist / icon / heading / actions; dropdown element mode bảng chiếu + giữ chỗ tên.
- CSP states `td-dropdown.ssr`, `td-empty-state.ssr` + baseline. `npm test` đầy đủ.
