## Nhóm A — nền tảng + form control (file: base/*, input-field, checkbox, toggle, slider, button)

- **A1 Property đặt trước khi connect / trước khi define bị mất** (`TdBaseElement._setupProperties`): (1) với mọi
  attribute được observe, nếu instance có **own property** cùng tên camelCase (gán sớm) → lấy giá trị ra và `delete`;
  (2) cài **toàn bộ** accessor (bỏ qua tên đã có accessor trên prototype của lớp con, vd. `value`); (3) phát lại các giá trị đã lấy qua setter **trước khi** `_initialized` bật và trong lúc cờ `_suppressRender`
  bật — cờ được kiểm ở **chốt chung `_doRender()`** (return sớm), nên cả lớp con tự override
  `attributeChangedCallback` và gọi `_doRender()` trực tiếp (dropdown, input-field…) cũng không render dở dang;
  (4) tắt cờ, `connectedCallback` render **đúng một lần**. Test: 3 property gán trước khi append và trước
  `customElements.define` → giá trị cuối đúng, attribute phản ánh, `render()` chỉ chạy 1 lần lúc connect — cho
  `td-sample` **và** `td-dropdown` (lớp con render thẳng trong `attributeChangedCallback`).
- **A2 `td-input-field.value` trả giá trị cũ** → accessor `value` trên prototype: get = giá trị sống (`getValue()`),
  set = `setValue()`. (Đổi hành vi: trước đây trả attribute.)
- **A3 input-field hỗ trợ `pattern` / `minlength`** trong validity tự tính (`patternMismatch`, `tooShort` — `tooShort`
  chỉ khi người dùng đã sửa, như chuẩn trình duyệt); thông báo lấy từ `TdInputField.messages`.
- **A4 Nhãn validation dịch được**: `TdInputField.messages`, `TdSlider.messages`, `TdCheckbox.messages`,
  `TdToggle.messages` (object tĩnh, mặc định tiếng Việt hiện tại, `{placeholder}` như chip-input).
- **A5 checkbox/toggle khôi phục `checked`** khi trình duyệt restore form: `TdCheckableElement` override
  `_restoreState` (FormData state = value khi checked, `null`/vắng khi không) → đặt `checked` đúng, không ghi đè
  attribute `value`.
- **A6 slider**: `required` bỏ khỏi observed (không có nghĩa với range — native `<input type=range>` cũng không có
  valueMissing) và docs ghi rõ; `setValue()` snap theo `step` (giống native); không có `value` → mặc định = `min`
  (native mặc định là trung điểm; ta chọn `min` như hiển thị thumb hiện tại) ⇒ hết `rangeUnderflow` giả.
- **A7 Không xoá CSS var inline của site khi re-render** (button, checkbox, toggle, slider, **pagination**): chỉ
  `removeProperty` những biến chính component đã đặt trước đó (ghi nhớ tập biến đã set). Test browser: site đặt
  `el.style.setProperty('--td-…', x)` trước và sau lần render đầu, đổi attribute liên quan → biến của site còn nguyên
  với cả 5 component. (Pagination nằm ở nhóm B về file, nhưng dùng chung helper.)

## Nhóm C — toast, loading, modal, form-validation

- **C1 `TdToast.labels.close`** + **API đóng**: `TdToast.show/success/…` trả về handle `{ close() }` đại diện cho
  **yêu cầu** (kể cả khi toast còn trong hàng đợi 50 ms hoặc đang chờ lượt stagger 80 ms) lẫn toast đã hiện.
  `close()`: còn trong hàng đợi → gỡ khỏi hàng đợi; đã lên lịch stagger → huỷ timer đó; đã hiện → đóng như nút Đóng.
  `TdToast.clear()`: xoá hàng đợi, huỷ mọi timer stagger đang chờ, đóng mọi toast đang hiện. Gọi lại `close()` →
  no-op. Test: close ngay sau show (trước 50 ms), close trong khoảng stagger, clear ngay sau 5 lần show → không toast
  nào xuất hiện; close/clear toast đang hiện.
- **C2 `TdLoading.labels.loading`** (mặc định `'Đang tải...'`); `TdLoading.wrap(fn, opts)` nhận
  `{ message, maxDuration }` (chuỗi vẫn được chấp nhận như trước).
- **C3 `TdModal.labels`** thêm tiêu đề/nội dung mặc định: `confirmTitle`, `confirmMessage`, `successTitle`,
  `errorTitle`, `infoTitle`.
- **C4 `TdModal.confirm`: `onConfirm` đồng bộ trả `false` hoặc throw → giữ hộp thoại mở** (giống `actions`); throw
  còn `console.error`. Đổi hành vi, ghi docs.
- **C5 TdFormValidation**: form `reset` → xoá summary, note lỗi, `aria-invalid`, và tắt live re-check; `onValid`
  bọc try/catch.

## Nhóm D — tiện ích, theme, đóng gói

- **D1 `TdDateTime.toAbsolute`** thay token bằng một regex quét token một lượt (không thay trong từ): chỉ nhận token
  đứng riêng (`YYYY|MM|DD|HH|mm|ss|…` theo tập hiện có) và cho phép escape `[...]` văn bản; timestamp `0` là hợp lệ
  (1970); `toRelative` với thời điểm tương lai → "sắp tới"/"trong N phút" thay vì "Vừa xong".
- **D2 Dark theme theo màu brand**: token mới `--td-accent-fill` = màu nền đặc mang chữ trắng. Light:
  `var(--td-accent)`. Dark: `color-mix(in srgb, var(--td-accent) 80%, #000)` (accent dark mặc định #3b82f6 → ≈ #2f68c5,
  chữ trắng ≈ 5.3:1), fallback không `color-mix` = #2563eb qua `@supports`. `--td-btn-primary-bg` (dark) và
  `--td-pagination-active` (dark) = `var(--td-accent-fill)`. Như vậy site đổi **một** token `--td-accent` (cả light
  lẫn dark) là nút primary + trang active đổi theo; site muốn chỉnh riêng thì đè `--td-accent-fill`. Test: gate tương
  phản (primary) qua; browser test dark mode: đổi `--td-accent` → nền nút primary và trang active đổi, chữ trắng trên
  trang active mặc định ≥ 4.5:1 (light + dark).
- **D3 z-index**: sửa comment "dropdown 100" (thực tế popover 450) trong tokens.css; giữ các token không dùng (public,
  xoá = phá vỡ) nhưng ghi rõ "dự trữ".
- **D4 Đóng gói**: `package.json` — `files` loại test/stories (`!src/**/*.test.js`, `!src/**/*.browser-test.js`,
  `!src/**/*.stories.js`, `!src/**/*.stories.css`?), `sideEffects` liệt kê module có side effect (mọi file đăng ký
  element + tooltip + `*.css`), `engines.node >=20`, `exports["./package.json"]`, `vite` thành devDependency tường
  minh (đã có sẵn trong lockfile qua Storybook — không thêm package mới). Barrel `index.js` export thêm
  `TdIconElement` (đăng ký `<td-icon>`). `_validateIconDefinition` **bỏ `export`** (chỉ dùng nội bộ trong
  `td-icon.js`, không test nào import) — test: namespace `import * as icons from './td-icon.js'` không còn khoá đó.
- **D5 Token khai báo trên element → khai báo mặc định ở `:root`** (`@layer td.tokens`), component chỉ đọc `var()`:
  `--td-lb-*` (lightbox), `--td-checkbox-box`, kích thước mặc định của switch, `--td-spinner-size`,
  `--td-empty-state-pad/-gap`, `--td-table-cell-px`, `--td-pagination-item-size` (touch: media query trên `:root`).
  Class kích thước (`--sm/--lg`) vẫn đặt biến trên element (đè có chủ đích cho size đó). Test: `:root { --td-… }`
  không layer của site đổi được giá trị ở kích thước mặc định cho từng token trên; CSP baseline không đổi hình.
