## 4. Thiết kế

### 4.1 Module `src/form/button-busy.js`

```js
/** @internal dùng chung td-button + helper công khai */
export function syncButtonState(control, { busy, inert = false, restore = {} }) { … }
/** @public */  export function setButtonBusy(target, busy) { … }
/** @public */  export function runWithButton(target, fn) { … }
```

**`syncButtonState(control, state)` — hàm duy nhất ghi trạng thái bận** (`control` là `button.td-btn` hoặc `a.td-btn`):
- `busy`: bật / tắt trạng thái bận.
- `inert` (chỉ link): link phải vô hiệu bất kể bận (disabled hoặc không có href an toàn) — td-button truyền vào
  (`disabled || !href`).
- `restore`: `{ href, tabindex, role, ariaDisabled }` — giá trị cần trả khi **không bận và không inert**; `null` = gỡ
  attribute. Nhánh trả **áp dụng nguyên văn cả bốn** (`href`, `tabindex`, `role`, và `aria-disabled` — kể cả link có `href`
  mà tác giả đã đặt `aria-disabled="true"`, vẫn về đúng tổ hợp đó). td-button truyền `href` đã lọc (`_linkHref()`), `tabindex` / `role` từ `_linkPass`, `ariaDisabled: null`.
  Đường helper truyền ảnh chụp lấy từ `WeakMap` (4.3).
- Việc làm, theo đúng thứ tự an toàn của `_syncState` hôm nay:
  - **button**: `busy` → `aria-busy="true"` + `aria-disabled="true"`; không bận → gỡ `aria-busy`, và `aria-disabled` về
    `restore.ariaDisabled` (null = gỡ). **Không bao giờ** đụng `disabled` gốc (td-button tự đặt `btn.disabled` ở chỗ nó,
    ngoài hàm này).
  - **link**: `inert || busy` → `tabindex` (`inert ? '-1' : '0'`) **rồi** gỡ `href`, `role="link"`, `aria-disabled="true"`;
    ngược lại → đặt `href` (null = gỡ) **rồi** đặt / gỡ `tabindex`, `role`, `aria-disabled` đúng theo `restore`. `aria-busy` theo `busy`.
  - **spinner** (B5): `ensureSpinner(control)` khi `busy` (xem 4.4); `spinner.hidden = !busy`.
  - **guard** (B4): khi `busy` → `ensureGuard(control.ownerDocument)`.
- Idempotent: gọi lặp cùng đối số không đổi DOM thêm (không ném lại `setAttribute` thừa quan trọng với focus: thứ tự trên
  đảm bảo link đang focus không bị bỏ focus giữa chừng).

**`td-button._syncState()`** (dòng 429): thay hai nhánh tự viết bằng
`const pass = this._linkPass?.el === btn ? this._linkPass : null;` (giữ nguyên dòng tra hiện có, đặt **trước** lời gọi; null-safe) rồi
`syncButtonState(btn, { busy: loading, inert: disabled || !href, restore: { href, tabindex: pass?.tabindex ?? null, role: pass?.role ?? null, ariaDisabled: null } })`
cho link, và `syncButtonState(btn, { busy: loading })` cho button; **giữ nguyên** phần `btn.disabled = disabled`, `name` /
`value`, `aria-label`, `FORWARDED_ARIA`. Spinner (dòng 472) do hàm chung làm. Kết quả hành vi **y hệt** (test cũ chứng minh).

### 4.2 `setButtonBusy(target, busy)`

1. `resolveTarget(target)`: phải là Element (`target?.nodeType === 1`, không `instanceof`). Quy về **host** nếu
   `localName` ∈ {`td-button`, `td-action-button`}, hoặc nếu là control `.td-btn` mà `parentElement` là host (B10). Ngược
   lại phải là `button` / `a` có `classList.contains('td-btn')`; còn lại → `TypeError('setButtonBusy: expected button.td-btn,
   a.td-btn or <td-button>')`. `busy` ép `!!busy`.
2. **Host**: `typeof target.setLoading === 'function' ? target.setLoading(busy) : toggle attribute 'loading'` (B11). Hết;
   `td-button` tự gọi `syncButtonState` qua `_syncState`.
3. **Control thường**: `WeakMap<Element, Snapshot>` `saved`.
   - `busy` và **chưa có** snapshot → chụp `{ href, tabindex, role, ariaDisabled, inert }` (`inert` = link đã không có `href`
     hoặc `aria-disabled="true"` từ trước) rồi `syncButtonState(control, { busy: true, inert: snapshot.inert, restore: snapshot })`
     (link inert từ trước giữ `tabindex="-1"` suốt lúc bận — **cùng** quy tắc `inert ? '-1' : '0'` của td-button hôm nay).
     Đã có snapshot → bỏ qua (idempotent, không ghi đè ảnh chụp bằng trạng thái bận).
   - `!busy` và có snapshot → `syncButtonState(control, { busy: false, inert: false, restore: snapshot })` (luôn `inert: false`:
     nhánh trả áp dụng **nguyên văn** snapshot, nên link disabled có `href` / disabled không `href` đều về đúng như lúc chụp), rồi xoá
     snapshot.
   - `!busy` và **không** có snapshot → trường hợp markup SSR đã in sẵn `aria-busy`: chỉ gỡ `aria-busy` (button: gỡ cả
     `aria-disabled` đi kèm), ẩn spinner; **không** đụng gì khác (không xoá `aria-*` của tác giả).
4. Trả `undefined`.

Link đã inert từ trước (disabled bằng PHP: `aria-disabled="true" tabindex="-1"`, không `href`; hoặc tác giả đặt `href` +
`aria-disabled="true"`): bận → `tabindex="-1"` (như td-button disabled + loading hôm nay; **không** nâng lên 0); hết bận → trả
đúng snapshot (kể cả `href` còn nguyên + `aria-disabled="true"` + `role` / `tabindex` gốc).

### 4.3 `runWithButton(target, fn)`

```js
const running = new WeakMap(); // control | host → Promise đang bay
```
1. `fn` không phải hàm → `Promise.reject(new TypeError('runWithButton: a function is required'))` (giống `run`).
   `target` sai kiểu → **ném đồng bộ** `TypeError` (giống `setButtonBusy`; lỗi lập trình, không phải lỗi thao tác).
2. Host có `run` → `return target.run(fn)` (đường `td-button` sẵn có: cùng `_running`, cùng semantic; mọi caller trộn
   `btn.run()` và `runWithButton(btn)` dùng chung một promise).
3. Còn lại (control thường, hoặc host chưa nâng cấp): `if (running.has(el)) return running.get(el)`; `setButtonBusy(el, true)`;
   `const p = Promise.resolve().then(() => fn()).finally(() => { running.delete(el); setButtonBusy(el, false); })`;
   `running.set(el, p)`; `return p`. **Thứ tự bắt buộc:** `running.set` và bận **trước** khi `fn` chạy (fn chạy ở microtask
   sau, như `run`), nên gọi lồng đồng bộ trong `fn` nhận đúng `p`; `finally` luôn gỡ kể cả `fn` ném / reject; lỗi của `fn`
   được ném lại cho caller (caller tự `catch`, như `run`).
4. Hệ quả cố ý: `fn` **không** chạy đồng bộ trong lời gọi. Mẫu AJAX gọi `e.preventDefault()` đồng bộ trong handler **trước**
   `runWithButton`; `FormData` dựng **trong** `fn` vẫn thấy submitter đúng vì nút không `disabled` (B2).

### 4.4 Spinner, guard, hai thứ lười

**`ensureSpinner(control)`** (chỉ khi `busy`):
- đã có `:scope > .td-btn__spinner` → dùng.
- chưa có (markup viết tay) → dựng **một lần** bằng `control.ownerDocument.createElement('span')` /
  `createElementNS('http://www.w3.org/2000/svg', …)`: `span.td-btn__spinner.td-spinner.td-spinner--sm[aria-hidden="true"]`
  > `svg.td-spinner__svg[viewBox="0 0 50 50"][aria-hidden="true"][focusable="false"]` > hai `circle`
  (`td-spinner__track`, `td-spinner__arc`, `cx=25 cy=25 r=20`) — đúng hình PHP / td-button in (dòng 322–325). Không `innerHTML`,
  không style attribute. Thêm vào **cuối** control; giữ lại sau khi hết bận (chỉ `hidden`).
- Markup viết tay **không có** `.td-btn__label` mà có text node trực tiếp: gói **các text node không rỗng** vào một
  `span.td-btn__label` (một lần, giữ nguyên chữ) để CSS ẩn được chữ dưới spinner. Có `.td-btn__label` rồi thì không đụng.

**`ensureGuard(doc)`**: `const guarded = new WeakSet()`; lần đầu cho `doc` → `doc.addEventListener('click', onClick, true)`.
`onClick(e)`: tìm control bận trên `e.composedPath()` (fallback chuỗi `target.parentNode` nếu không có `composedPath`) — phần tử
đầu tiên `matches('.td-btn[aria-busy="true"]')`; thấy → `e.preventDefault(); e.stopImmediatePropagation()`. Dùng đường
`composedPath` nên **click trên SVG con / icon / nhãn bên trong nút** và nút trong shadow root của site đều bị nuốt. Chặn
`Enter` / `Space` (kích hoạt thành `click`) và **implicit submission** (Enter trong ô nhập khi nút gửi mặc định đang bận:
trình duyệt phát `click` giả lên nút đó → bị nuốt → form không gửi).
- Không bao giờ gỡ listener (một listener rẻ mỗi document; test đếm đúng 1).
- Giới hạn (ghi docs): guard chỉ có từ lần `syncButtonState` bận đầu tiên của document đó; listener capture ở `window` hoặc
  đăng ký trước trên `document` vẫn chạy trước; nút `aria-busy` do SSR in sẵn mà **chưa từng** qua helper / `td-button` thì
  chưa được bảo vệ cho tới lúc đó; `form.requestSubmit()` / `form.submit()` bằng code không đi qua nút nên không bị chặn.
- `td-button.afterRender()` (dòng ~414): **bỏ phần `this.hasAttribute('loading')`** của listener per-control (nay do guard
  document lo), **giữ** phần "link không có `href`" (disabled / inert link) — đó là hợp đồng khác (không liên quan bận).
  Làm **sau** khi test hợp đồng "click bị nuốt" (browser: `td-batch1` 238, `td-v017` 218, `ssr` 268) chạy xanh với guard mới;
  nếu bất kỳ test nào đỏ vì thứ tự listener thì giữ lại guard per-control cho `loading` (không ảnh hưởng đúng sai, chỉ thừa
  một listener) và ghi vào báo cáo.

### 4.5 CSS (`src/styles/components/button.css`)

Thay luật dòng ~313:

```css
.td-btn[aria-busy="true"] > :not(.td-btn__spinner) { opacity: 0; }
```
(thay `> .td-btn__label, > .td-btn__icon { visibility: hidden }`). Lý do: `opacity: 0` giữ phần tử trong cây truy cập (nhãn
vẫn là **tên** của nút khi bận) và giữ bố cục (cỡ nút không đổi) — `visibility: hidden` xoá cả hai tên lẫn nội dung khỏi
cây. `> :not(.td-btn__spinner)` (thay vì liệt kê label / icon) phủ cả markup viết tay có `<svg>` / `<i>` / `<span>` lạ; nhãn
chữ trần đã được gói vào `.td-btn__label` ở 4.4. Với `td-button` / PHP markup hiệu ứng **y hệt** (chỉ có label / icon /
spinner). Spinner vốn nằm ngoài luật (`position: absolute; inset: 0`).
- Không đụng `cursor: progress`, không animation mới (nên không đụng `prefers-reduced-motion`), không `:hover` mới
  (hover-gate / `:active` / `PRESS_TARGETS` không đổi: luật nhấn / hover **đã** loại `[aria-busy="true"]`).
- Màu: nút bận giữ màu nền / chữ như nút thường (luật disabled loại trừ busy) → spinner (`currentColor`) vẫn tương phản như
  hôm nay; không token mới (golden không đổi).
- Hỏng cần soát: `td-v069-button-plain.engines.browser-test.js:409–433` đang khẳng định `visibility: hidden` của label / icon
  khi loading → đổi thành `opacity` `'0'` (và `visibility` `'visible'`); đây là **thay đổi hành vi có chủ đích**, ghi CHANGELOG.

## 5. Bảo mật

- Không chuỗi nào của site thành HTML: spinner dựng bằng `createElement` / `createElementNS` với chuỗi hằng của kit; tên
  class cố định; không `innerHTML`, không `style=` (CSP-strict, dwp `style-src-attr 'none'`).
- `target` / `fn` là code tin cậy của site nhưng helper không tin kiểu: sai kiểu → `TypeError`, không im lặng; không đọc
  `Function.name`; không `instanceof` (phần tử từ iframe vẫn đúng).
- Guard click: chỉ **chặn** (không phát sinh hành động), phạm vi hẹp `.td-btn[aria-busy="true"]`; không bao giờ gỡ listener
  nên không có race cài / gỡ; `WeakSet` / `WeakMap` không giữ phần tử sống (không rò bộ nhớ).
- Snapshot link: chỉ lưu giá trị attribute site đã đặt và trả lại nguyên văn; `href` khôi phục **không** qua nới lỏng whitelist
  (td-button vẫn dùng `_linkHref()`; đường plain trả đúng chuỗi site có từ đầu — không phải đầu vào mới).
- Cảnh báo docs: busy **không** thay thế idempotency phía server (double-click không phải nguồn trùng duy nhất: nhiều tab,
  retry mạng, bfcache).
- Gate: **codex-security** không bắt buộc theo luật (không auth / input / endpoint), nhưng guard capture toàn document chạm
  vào mọi click nên cho **impl-review** đọc kỹ 4.4; nếu impl-review yêu cầu thì chạy thêm security.

## 6. Trợ năng + cảm ứng

- Bận giữ **tên** nút (B6/4.5), `aria-busy="true"` + `aria-disabled="true"`, focus ở lại (không `disabled`), vẫn trong thứ tự
  Tab, `Enter` / `Space` / chạm bị nuốt. Không live region mỗi nút (B8): thông báo kết quả là việc của site (toast).
- Link bận: `role="link"`, `tabindex="0"`, không `href` → trình đọc màn hình đọc "link, đã vô hiệu / bận" (hành vi td-button
  hôm nay, không đổi).
- Spinner `aria-hidden="true"`; chuyển động theo `prefers-reduced-motion` của `spinner.css` hiện có.
- Cảm ứng ([touch.md](design/touch.md)): không đổi vùng chạm, không hover mới; hình nhấn đã loại nút bận.

## 7. Test

**Node** (`src/form/button-busy.test.js`, DOM giả tối thiểu tự viết trong file — phần tử có `attributes`, `classList`,
`children`, `parentElement`, `ownerDocument` có `addEventListener` ghi lại + `createElement` / `createElementNS`, `matches`
đơn giản; **mô-đun thuần** nên không cần shim `customElements`):
1. `resolveTarget`: `button.td-btn` / `a.td-btn` / host / control-của-host đều đúng đích; `div`, `button` thiếu `.td-btn`,
   `null`, chuỗi → `TypeError` (cả hai hàm).
2. Button: bận → `aria-busy` + `aria-disabled`, **không** `disabled`; hết bận → gỡ sạch, `aria-disabled` tác giả có sẵn được trả.
3. Link: thứ tự thao tác (ghi lại chuỗi `setAttribute` / `removeAttribute`: `tabindex` trước khi bỏ `href`; `href` trước khi
   bỏ `tabindex`); ảnh chụp trả đúng `href` / `tabindex` / `role` / `aria-disabled` cũ; ba loại link inert từ trước (không `href` +
   `tabindex="-1"` + `aria-disabled`; **có `href` + `aria-disabled="true"`**; có `role` tác giả) bận → `tabindex="-1"`, hết bận → về
   **đúng** ảnh chụp.
4. Idempotent: `setButtonBusy(el, true)` hai lần không ghi đè snapshot; `false` không có snapshot không xoá `aria-*` của tác giả
   (chỉ gỡ `aria-busy` in sẵn).
5. `runWithButton`: bận **trước** `fn`; gọi lại khi đang bay → **cùng** promise, `fn` chạy 1 lần; gọi lồng đồng bộ trong `fn` →
   cùng promise; resolve / reject / `fn` ném đồng bộ đều gỡ bận; sau settle gọi lại chạy lần mới; `fn` không phải hàm →
   reject `TypeError`; host có `run` → uỷ quyền `host.run` (đếm).
6. Guard: `ensureGuard` cài **đúng 1** listener mỗi document dù gọi 100 lần; hai document → hai listener độc lập; click giả
   từ phần tử con của control bận → `preventDefault` + `stopImmediatePropagation`; control không bận → không đụng.
7. `ensureSpinner`: tạo đúng một lần (gọi lặp không nhân bản); markup có sẵn → dùng lại; text trần được gói vào
   `.td-btn__label` đúng một lần.

**Browser 3 engine** (`src/form/td-v096-button-busy.engines.browser-test.js`, mẫu `td-v069-button-plain.engines.browser-test.js`;
không dùng chuột thật → không vào `POINTER_FILES`):
1. **`button.td-btn` thường** (markup PHP: label + icon + spinner `hidden`): bận → `aria-busy` / `aria-disabled`, spinner hiện,
   `getComputedStyle(label).opacity === '0'` **và** `visibility === 'visible'`, `el.disabled === false`, **focus giữ** (`document.activeElement`),
   click (cả `el.click()` lẫn `dispatchEvent`) không tới listener của site; hết bận → trả lại.
2. **`a.td-btn` link**: `href` mất khi bận, `tabindex="0"`, focus giữ; hết bận → `href` đúng, `tabindex` / `role` về như cũ; click
   không điều hướng (listener `click` ghi nhận không chạy, URL không đổi). Thêm: link `href` + `aria-disabled="true"` tác giả (bận
   → `tabindex="-1"`, hết bận → `href` và `aria-disabled` nguyên văn).
3. **Host `<td-button>`**: `setButtonBusy(host, true)` ⇔ `host.hasAttribute('loading')`; control bên trong đúng hợp đồng; truyền

4. **Nhiều document**: nút trong `iframe` (srcdoc cùng origin) có guard của **document đó**; nút bận trong iframe nuốt click,
   nút ở document cha không bị ảnh hưởng; mỗi document đúng 1 listener (đếm bằng cách bấm hai lần, `fn` đếm 0).
5. **Click vào SVG con**: `svg.dispatchEvent(new MouseEvent('click', { bubbles: true, composed: true }))` trên icon / spinner bên trong

6. **Markup viết tay không spinner** (`<button class="td-btn td-btn--primary">Lưu</button>`): bận → helper dựng spinner **một lần**

  - **Mẫu AJAX** (thay thế cho `run()` khi nút là `.td-btn` thường):
    ```js
    form.addEventListener('submit', (e) => {
      e.preventDefault();                                  // đồng bộ, TRƯỚC runWithButton
      const submitter = e.submitter;                       // nút được bấm (hoặc null khi Enter trong ô nhập → nút mặc định)
      runWithButton(submitter ?? form.querySelector('[type=submit]'), async () => {
        // FormData(form, submitter) ném TypeError khi submitter là null → chỉ truyền khi có
        const body = submitter ? new FormData(form, submitter) : new FormData(form);
        const res = await fetch(form.action, { method: 'POST', body });
        if (!res.ok) throw new Error(res.status);          // lỗi → bận được gỡ, caller catch
      }).catch(showError);
    });
    ```
    kèm giải thích vì sao `new FormData(form, submitter)` lấy đúng `name=value` (nút **không** `disabled` gốc), và `submitter` là `null`
    khi `form.requestSubmit()` không truyền nút (hoặc `dispatchEvent` tay) — khi đó **phải** dùng `new FormData(form)` một tham số (hai
    tham số với `null` ném `TypeError`), như mẫu trên; công thức submit thường cũng phải bảo vệ `e.submitter` null
    (`if (e.submitter) setButtonBusy(e.submitter, true)`);
