## E1 — `td-input-field` truyền thuộc tính native xuống control (ưu tiên 1)

`autocomplete`, `inputmode`, `enterkeyhint`, `autocapitalize`, `spellcheck`, `autofocus` → áp lên `<input>` /
`<textarea>` bên trong (whitelist giá trị theo HTML: `autocomplete` là token list `[a-z0-9 -]`; `inputmode` ∈ none,
text, decimal, numeric, tel, search, email, url; `enterkeyhint` ∈ enter, done, go, next, previous, search, send;
`autocapitalize` ∈ off, none, on, sentences, words, characters; `spellcheck` true/false). `autofocus`: focus control
một lần khi gắn vào trang (không cướp focus nếu đã có element khác đang focus ngoài body). Cập nhật tại chỗ khi đổi
attribute. Test: password manager contract (`autocomplete="current-password"` có trên `<input type=password>`),
giá trị lạ bị bỏ, đổi động.

## E2 — `td-dropdown`: progressive enhancement từ `<select>` + `.value` sống

- Khi gắn lần đầu, nếu host có con trực tiếp `<select>` và **chưa** có `options` gán bằng JS: đọc `<option>` /
  `<optgroup>` (optgroup phẳng hoá, nhãn group bỏ qua — ghi docs) → `options` (`value`, `label` = text đã trim,
  `disabled`), lựa chọn = option `selected` (hoặc attribute `value` của host nếu có), `name` / `required` /
  `disabled` lấy từ select nếu host chưa có. Sau đó **gỡ** `<select>` khỏi DOM (component form-associated thay nó →
  không submit trùng). Không JS: select native hoạt động và submit bình thường.
- `multiple` trên select → không nâng cấp (dropdown chỉ chọn một), để nguyên select + `console.warn`.
- `.value` (property) = giá trị đang chọn (`getValue()`), set = `setValue()` — giống `input-field` 0.16.0 (đổi hành vi).
- Test: markup `<td-dropdown><select name=city required><option value=hn selected>Hà Nội</option>…</select></td-dropdown>`
  → sau upgrade: options đúng, value `hn`, FormData `city=hn`, không còn select, required hoạt động; `multiple` bị bỏ
  qua; options gán JS trước connect thắng select; `.value` sống.

## E3 — `td-button`: biến thể `ghost` + nút dạng link (`href`)

- `variant="ghost"`: nền trong suốt, không kính/không blur/không viền, chữ màu accent; hover nền mờ
  (`--td-color-hover`); focus ring như các nút khác; disabled xám. Token `--td-btn-ghost-fg/-hover-bg`. Contrast gate
  thêm case ghost (label ≥ 4.7 trên nền trắng/đen của theme — ghost nằm trên nền trang, không trên ảnh: gate dùng
  backdrop trắng (light) / đen (dark) cho ghost).
- `href` → render `<a class="td-btn …" href>` thay `<button>` (URL qua whitelist: http(s), tương đối, `#`, `mailto:`,
  `tel:`; khác → bỏ href + `console.warn`); `target` whitelist (`_blank|_self|_parent|_top`), `_blank` tự thêm
  `rel="noopener noreferrer"`; `download` attribute chuyển tiếp; `disabled`/`loading` trên link → bỏ `href`,
  `aria-disabled="true"`, `tabindex="-1"` khi disabled. `type`/form không áp cho link.
- Test: link markup, URL xấu (`javascript:`) bị bỏ, `_blank` rel, disabled link, ghost computed styles + contrast.

## E5 — Adapter PHP chính thức (SSR)

File `php/td.php` (ship trong gói: `files` thêm `php/`), PHP ≥ 8.1, không phụ thuộc framework, **không** biến toàn
cục ngoài hàm có tiền tố `td_` và class `TdComponents\Td`:

- `Td::configure(string $baseUrl, string $kitDir)` — URL gốc thư mục vendor (có phiên bản) + đường dẫn file hệ thống.
- `Td::importMap(array $extra = []): array` + `td_import_map_tag(?string $nonce)` (in `<script type="importmap">`,
  JSON `JSON_HEX_TAG|JSON_HEX_AMP|JSON_HEX_APOS|JSON_HEX_QUOT|JSON_UNESCAPED_SLASHES`), `td_stylesheet_tag(?string
  $nonce)`.
- `td_icon`, `td_button` (mọi variant gồm ghost, `href` → `<a>` như E3), `td_field` (gồm E1 attrs), `td_dropdown`
  (in `<td-dropdown>` chứa `<select>` native — E2 progressive enhancement, không cần JS để submit), `td_toggle`,
  `td_checkbox`. Markup **khớp đúng DOM contract** của component (class BEM, ARIA) để CSS td.css tạo dáng khi chưa
  có JS và component không nhảy hình khi upgrade.
- An toàn: mọi giá trị qua `htmlspecialchars(ENT_QUOTES|ENT_SUBSTITUTE, 'UTF-8')`; tên attribute qua whitelist (chặn
  `on*`, `style`, `href/src/action/formaction/srcdoc`); URL qua whitelist như E3; class app chỉ nhận token hợp lệ;
  JSON qua cờ HEX.
- Test: `node --test` chạy `php` CLI (bỏ qua có cảnh báo nếu không có php) render từng hàm → so với snapshot + kiểm
  escaping (payload XSS trong label/value/attr/URL); browser test: markup SSR của button/field/checkbox/toggle/dropdown
  được component upgrade đúng (giá trị, form) và computed style giống markup do component tự render.

- `<td-password-meter for="id-của-input">` (hoặc bọc quanh input): thanh 4 mức + nhãn (`TdPasswordMeter.labels`,
