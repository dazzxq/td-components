## E2 — `td-dropdown`: progressive enhancement từ `<select>` + `.value` sống

- Khi gắn lần đầu, nếu host có con trực tiếp `<select>` và **chưa** có `options` gán bằng JS: đọc `<option>` /
  `<optgroup>` (optgroup phẳng hoá, nhãn group bỏ qua — ghi docs) → `options` (`value`, `label` = text đã trim,
  `disabled` = option disabled **hoặc** optgroup cha disabled). Lựa chọn, theo thứ tự ưu tiên: (1) attribute `value`
  của host nếu có (ý đồ tường minh của site); (2) **trạng thái sống** `select.value` (bao gồm lựa chọn người dùng đã
  đổi trước khi JS nâng cấp, và trường hợp native chọn option đầu tiên khi không option nào `selected`). **Giá trị
  mặc định cho reset** = option `defaultSelected` cuối cùng, không có thì option đầu tiên không disabled (đúng luật
  reset của `<select>`) → lưu làm initial value của component (`formResetCallback` trả về giá trị này).
  `name` / `required` / `disabled` / `aria-label` lấy từ select nếu host chưa có; `<label for=id-của-select>` → đổi
  `for` sang id control của component (giữ nhãn). Sau đó **gỡ** `<select>` (component form-associated thay nó → không
  submit trùng). Không JS: select native hoạt động và submit bình thường.
- **Option disabled** (mới cho dropdown, cần cho parity): option có `disabled: true` render `aria-disabled="true"`,
  không chọn được bằng chuột/phím, bị bỏ qua khi di chuyển bằng phím (↑↓ Home End type-ahead), vẫn hiển thị (mờ).
  Áp cho cả options gán bằng JS.
- `multiple` trên select → không nâng cấp (dropdown chỉ chọn một), để nguyên select + `console.warn`.
- `.value` (property) = giá trị đang chọn (`getValue()`), set = `setValue()` — giống `input-field` 0.16.0 (đổi hành vi).
- Test: markup `<td-dropdown><select name=city required><option value=hn selected>Hà Nội</option>…</select></td-dropdown>`
  → sau upgrade: options đúng, value `hn`, FormData `city=hn`, không còn select, required hoạt động; không option nào
  `selected` → giá trị = option đầu (như native); người dùng đổi select trước upgrade → giữ lựa chọn đó; reset form →
  về mặc định native; option/optgroup disabled không chọn được và bị phím bỏ qua; `<label for>` vẫn gắn; `multiple`
  bị bỏ qua; options gán JS trước connect thắng select; `.value` sống.

## E3 — `td-button`: biến thể `ghost` + nút dạng link (`href`)

- `variant="ghost"`: nền trong suốt, không kính/không blur/không viền, chữ màu accent; hover nền mờ
  (`--td-color-hover`); focus ring như các nút khác; disabled xám. Token `--td-btn-ghost-fg/-hover-bg`. Contrast gate
  thêm case ghost (label ≥ 4.7 trên nền trắng/đen của theme — ghost nằm trên nền trang, không trên ảnh: gate dùng
  backdrop trắng (light) / đen (dark) cho ghost).
- `href` → render `<a class="td-btn …" href>` thay `<button>` (URL qua whitelist: http(s), tương đối, `#`, `mailto:`,
  `tel:`; khác → bỏ href + `console.warn`); `target` whitelist (`_blank|_self|_parent|_top`), `_blank` tự thêm
  `rel="noopener noreferrer"`; `download` attribute chuyển tiếp (tên file lọc ký tự đường dẫn). `type`/form không áp
  cho link.
- Trạng thái của link (khác nhau, như `<button>` hiện có):
  - **disabled**: gỡ `href` (lưu lại), `aria-disabled="true"`, `tabindex="-1"` (ra khỏi thứ tự Tab — như button
    disabled), click bị chặn; style = trạng thái disabled của nút (`.td-btn[aria-disabled="true"]` dùng cùng token
    disabled). Bỏ disabled → khôi phục `href`, `tabindex`.
  - **loading**: `aria-busy="true"` + `aria-disabled="true"`, gỡ `href` tạm (không mở tab mới/middle-click), **giữ
    focus** (vẫn `tabindex="0"`), click bị chặn, spinner như button. Hết loading → khôi phục `href`.
- Test: link markup, URL xấu (`javascript:`) bị bỏ, `_blank` rel, disabled (không href, tabindex -1, computed style
  disabled, click không điều hướng), loading bật/tắt động (href gỡ rồi khôi phục, focus giữ), ghost computed styles
  + contrast.

## E5 — Adapter PHP chính thức (SSR)

File `php/td.php` (ship trong gói: `files` thêm `php/`), PHP ≥ 8.1, không phụ thuộc framework, **không** biến toàn
cục ngoài hàm có tiền tố `td_` và class `TdComponents\Td`:

- `Td::configure(string $baseUrl, string $kitDir)` — URL gốc thư mục vendor (có phiên bản) + đường dẫn file hệ thống.
- Import map — **một** hợp đồng, hai cách gọi:
  - `Td::importMap(array $extra = []): array` → mảng `specifier => url` gồm mọi entry `.js` trong `exports` của
    `package.json` đã vendor + `$extra`. Trùng key với kit → `InvalidArgumentException` (site không vô tình ghi đè
    module kit; muốn thay thì không dùng helper). Thứ tự: kit trước, extra sau.
  - Wrapper toàn cục: `td_import_map(array $extra = []): array` (= `Td::importMap`) và
    `td_import_map_tag(array $extra = [], ?string $nonce = null): string` (in `<script type="importmap">` JSON
    `JSON_HEX_TAG|JSON_HEX_AMP|JSON_HEX_APOS|JSON_HEX_QUOT|JSON_UNESCAPED_SLASHES`, nonce escape) — site chỉ có
    **một** import map nên mọi entry riêng của site truyền qua `$extra`.
  - `td_stylesheet_tag(?string $nonce = null): string`.
- **Hợp đồng markup** (quyết định rõ ràng — thu hẹp lời hứa "upgrade"):
  - `td_button`, `td_field`, `td_checkbox`, `td_toggle` in **control NATIVE đứng riêng** mang đúng DOM contract/BEM
    của component (`button.td-btn…` / `a.td-btn…`, `.td-field` + `input|textarea.td-field__control`,
    `label.td-checkbox` + `input.td-checkbox__input`, `label.td-switch` + `input[role=switch]`) — td.css tạo dáng,
    submit/validation **native** (kể cả `type=month|datetime-local`, nút submit có `name`/`value`), **không cần JS,
    không upgrade**. Dùng `<td-*>` custom element khi cần hành vi JS (loading/run, counter, error contract động…) —
    docs ghi rõ lựa chọn.
  - `td_dropdown` in host `<td-dropdown>` chứa `<select>` native → **upgrade** theo E2 (helper duy nhất upgrade).
  - `td_icon` in `svg.td-icon` đầy đủ geometry từ `icons.json`.
  - **Tương thích 135**: tên hàm + option trùng `135/src/Ui/markup.php` (`td_button($label, $opts)`,
    `td_link($label, $href, $opts)`, `td_field($name, $value, $opts)`, `td_dropdown($name, $options, $value, $opts)`,
    `td_toggle($name, $checked, $label, $opts)`, `td_checkbox($name, $checked, $label, $opts)`, `td_icon($name, $size,
    $label)`), cộng `variant=ghost` thật (135 đang map ghost → secondary) và `td_button` có `href` → `<a>`. 135 thay
    `src/Ui/*` bằng file của kit + `Td::configure()`; icon riêng của site qua `Td::registerIcons(array)`.
- An toàn: mọi giá trị qua `htmlspecialchars(ENT_QUOTES|ENT_SUBSTITUTE, 'UTF-8')`; tên attribute qua whitelist (chặn
  `on*`, `style`, `href/src/action/formaction/srcdoc`); URL qua whitelist như E3; class app chỉ nhận token hợp lệ;
  JSON qua cờ HEX.
- Test: `node --test` chạy `php` CLI (bỏ qua có cảnh báo nếu không có php; CI Ubuntu có php) render từng hàm → so
  snapshot + escaping (payload XSS trong label/value/attr/URL/nonce/extra import map), `td_import_map` +
  `td_import_map_tag` (merge, trùng key ném lỗi). Browser test với HTML do PHP in ra: (a) **không JS** — FormData của
  form chứa đủ field (text, password có autocomplete, month, datetime-local, checkbox, toggle, select trong
  td-dropdown, nút submit có name/value làm submitter); (b) **sau khi nạp JS** — FormData của td-dropdown đã upgrade
  giống hệt (a); (c) **style parity** — computed style các phần tử chính của markup SSR button/field/checkbox/toggle
  khớp markup do `<td-button>/<td-input-field>/<td-checkbox>/<td-toggle>` tự render (màu, viền, kích thước, radius).

## E6 — Lightbox: nhiều biến thể tải

Option mới `downloads(item, ctx) → Array<{ label, url, filename? }>`. Trình tự: gọi hook (throw → coi như rỗng) →
**lọc** qua `isAllowedUrl` của lightbox → **rồi mới** rẽ nhánh theo số mục còn lại: 0 → ẩn nút tải; 1 → nút tải
thường (`<a download>`); ≥ 2 → nút tải mở `TdMenu` (E5a) với mục `download: filename ?? true` (thiếu filename vẫn là
link tải, tên lấy từ URL), và `isAllowedUrl: (url) => lightboxPolicy(url, currentItem)` — closure gọi đúng chữ ký
`isAllowedUrl(url, item)` của lightbox với item gốc đang xem. `download` (một URL) giữ nguyên; có cả hai → `downloads` thắng. Menu đóng khi đổi ảnh / đóng
lightbox. Test: 0/1/nhiều sau khi lọc, `download` attr + filename, scheme tuỳ biến (`blob:`) khi site cho phép, bàn
phím mở/chọn/đóng, đóng lightbox đóng menu, nhiều mục **không có filename** vẫn có attribute `download`, policy
`isAllowedUrl(url, item)` phụ thuộc dữ liệu item (ví dụ `item.data.private`) được gọi với đúng item.
