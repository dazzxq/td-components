## Shared

- **Icon insertion (review ISSUE-2):** `render()` keeps returning HTML strings (td-button node-test contract). It
  emits empty slots `<span class="td-…__icon" data-td-icon="check"></span>`; `afterRender()` fills every
  `[data-td-icon]` slot with `tdIcon(name, …)` nodes (a small shared helper `fillIconSlots(root)` in
  `src/icons/td-icon.js`). DOM + golden-contract tests assert the rendered `<svg data-icon>`.
- **Bundle (review ISSUE-3):** add `components/spinner.css`, `button.css`, `checkbox.css`, `switch.css`,
  `loading.css` to `src/styles/manifest.json` (after `icon.css`, before `lightbox.css`), `npm run build:css`,
  commit `td.css`; a node test asserts td.css contains each block (`.td-btn`, `.td-checkbox`, `.td-switch`,
  `.td-loading`, `.td-spinner`).
- **Error contract (roadmap; review ISSUE-1)** in `TdFormElement`: public `setError(message)` / `clearError()`
  and the `error-text` attribute (same semantics as td-input-field). The base keeps the message, renders a note
  `<span class="td-field-error" id="{stable id}">` (text only, announced via `aria-errormessage`) appended after
  the control (hook `_errorHost()` → where to put it), sets
  `aria-invalid="true"` + `aria-errormessage="{id}"` on `_focusTarget()`, removes all three on clear, clears
  on `formResetCallback`. Constraint validity stays separate (`setCustomValidity`). Wired for checkbox + switch
  now (td-input-field keeps its own until batch 2). CSS `.td-field-error` + `[aria-invalid="true"]` styling for
  the checkbox mark / switch track. Tests: API, attribute, a11y attributes, reset, re-render survival.
- **Accessible name precedence (review ISSUE-5)** for checkbox + switch: (1) internal `label` attr → the wrapping
  `<label>`; (2) else host `aria-label` → copied to the inner input; (3) else external labels of the
  form-associated host (`this._internals.labels`) → their ids (generated `td-lbl-N` when missing) set as the
  input's `aria-labelledby`. Tests for each path.
- **Hit targets (review ISSUE-11)** for checkbox + switch: the wrapping `<label>` hit area is ≥ 24×24 px for every
  size (min-width/min-height + centred mark/track, visual size unchanged) and ≥ `--td-touch-min` (44 px) under
  `@media (pointer: coarse)`. Browser test measures the label bounding box for unlabeled `sm` checkbox + switch.
- **One `change` event (review ISSUE-4)** for checkbox + switch: the inner input's native `change` (and `input`)
  are stopped at the host; the host emits exactly one custom `change` `{ checked }` for keyboard and pointer
  activation; controlled switch cancels the native toggle (`preventDefault` on click) and still emits once.
- `src/styles/components/spinner.css` — `.td-spinner` (`--sm|md|lg`, `__track`, `__arc`), SVG dash animation,
  colour `var(--td-spinner-color, currentColor)`; reduced motion → rotation stops, arc pinned; forced colours →
  `CanvasText`. Used by button loading + TdLoading (lightbox keeps its own ring for now).
- Tokens (tokens.css + theme-dark.css): `--td-btn-*`, `--td-switch-*`, `--td-checkbox-*`, `--td-z-loading`,
  `--td-control-border-strong` for non-text contrast (≥ 3:1: gray-500 #8a8a93 = 3.42:1).
- Every migrated component: no Tailwind classes, no adoptStyles, no inline styles except CSSOM custom
  properties on the host for per-instance values (`--td-btn-bg/fg`, `--td-checkbox-color`, `--td-switch-on`,
  `--td-spinner-color/track`), all through `safeColor`. `:focus-visible` rings from `--td-focus-ring`.
  Reduced motion + forced colours rules in each component CSS.

## td-button

DOM: `<button class="td-btn td-btn--{variant} td-btn--{size}[ td-btn--full][ td-btn--custom]" type>`
`[<span class="td-btn__icon">…</span>]<span class="td-btn__label">…</span>[icon right]`
`[<span class="td-btn__spinner td-spinner td-spinner--sm" aria-hidden="true">]`.
- Sizes sm/md/lg keep names; heights 32/40/48 px (sm below 44 on touch: `@media (pointer: coarse)` raises
  min-height to `--td-touch-min`). Loading hides label/icon with `visibility: hidden` (width kept).
- `color`/`text-color`: host CSSOM `--td-btn-bg/--td-btn-fg` + `td-btn--custom`. Auto text colour (review
  ISSUE-9): the safeColor-accepted value is normalised in the browser with a temporary probe element: appended
  to `document.documentElement`, its `color` set via CSSOM, read with `getComputedStyle` → `rgb()/rgba()`, removed
  synchronously in the same call (the only transient DOM write; no persistent styles — the narrow exception to
  the "no DOM writes in render" rule; it runs once per distinct colour, cached); alpha < 1 is composited over white (documented: pass `text-color` for
  translucent backgrounds on non-white surfaces); pick `#000` or `#fff` by the higher WCAG contrast ratio
  (relative luminance). Node fallback (no DOM): hex/rgb parsing only. Tests for hex3/hex6/hex8, rgb(a),
  hsl, named colours, alpha.
- Update in place for `loading`, `disabled`, `label`; full render only for structural attrs.
- `render()` keeps returning a string containing `type="…"` (node test contract).
- a11y: `aria-busy`, spinner `aria-hidden`, icon `aria-hidden`, `aria-label` passthrough from the host's
  `aria-label` attribute for icon-only buttons.

## td-checkbox

DOM: `<label class="td-checkbox td-checkbox--{size}"><input type="checkbox" class="td-checkbox__input">`
`<span class="td-checkbox__mark">{tdIcon('check', {class:'td-checkbox__icon'})}</span>`
`[<span class="td-checkbox__label">…</span>]</label>`; host `--td-checkbox-color` (renamed from `--td-cb-color`).
- `checked` attribute change updates `input.checked` in place (no re-render → focus kept).
- Visible `:focus-visible` ring on the mark; unchecked border `--td-checkbox-border` ≥ 3:1; drop `aria-checked`;
  host `aria-label` passthrough to the input when there is no `label`.
- Events: keep the custom `change` `{ checked }`; the native `change` from the inner input is stopped at the host
  (**behaviour change**: one event instead of two, documented).

## td-toggle → `.td-switch`

DOM (D5): `<label class="td-switch td-switch--{size}"><input type="checkbox" role="switch" class="td-switch__input">`
`<span class="td-switch__track"><span class="td-switch__thumb">{icons off/on}</span></span>`
`[<span class="td-switch__label">…</span>]</label>`; host `--td-switch-on`.
- `controlled`: `preventDefault()` on the input click (state unchanged), still emit `change` `{checked: !checked}`.
- Keyboard: native Space. **Behaviour change**: Enter no longer toggles (APG switch pattern).
- `[data-dragging]` while the pointer is down on the thumb → knob lift via `--_td-glass-lift-knob` (no glass at
  rest, liquid-glass table); reduced motion disables the lift.
- Forced colours: track border + thumb `CanvasText`.

## TdLoading (+ `TdLoadingSpinner`)

- Overlay `#td-loading.td-loading[hidden]` (scrim `--td-glass-scrim`, `z-index: var(--td-z-loading)`), card
  `.td-loading__card.td-glass-surface.td-glass-surface--strong` (floating, text-bearing → Regular strong glass),
  `.td-loading__spinner.td-spinner.td-spinner--lg`, `#td-loading-message.td-loading__message`.
- a11y + lifetime (review ISSUE-6): overlay `role="status" aria-live="polite"`; the card is focusable
  (`tabindex="-1"`) and receives focus on show (previous focus saved). While shown, `<body>` children except the
  overlay and `#td-toast-container` get `inert` (record/restore only what it set) + one scroll lease. A single
  internal `release()` restores inert, scroll and focus exactly once and is called by every exit path: `hide()`,
  max-duration auto-hide, and the last concurrent `wrap()` settling (fulfilled or rejected). Browser tests
  cover each path + toast stays interactive + focus restored.
- `show/hide` API unchanged; **`wrap()` becomes ref-counted** (overlay hides when the last concurrent wrap
  settles); `show()`/`hide()` stay direct (hide() resets the count). Max-duration auto-hide kept.
- `TdLoadingSpinner.create({ size, color, trackColor, className, label })` → `.td-spinner` element; colours via
  host CSSOM custom props (safeColor); `label` → `role="status"` + `aria-label`, else `aria-hidden="true"`.
