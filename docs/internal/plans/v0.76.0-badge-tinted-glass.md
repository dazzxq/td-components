## Mục tiêu

1. `.td-badge--{neutral,accent,success,warning,danger,info}` mặc định: nền tint (mức ~200), chữ đậm (mức ~800), **không viền
   nhìn thấy**, bóng đổ mềm hai lớp. Chế độ tối: nền mức ~900, chữ mức ~200.
2. Modifier mới `.td-badge--glass`: cùng bảng màu nhưng nền trong suốt (~80 %) + `backdrop-filter: blur(12px) saturate(160%)`
   + viền trắng mảnh + vệt sáng trong ở mép trên + cùng bóng đổ. Có fallback khi không hỗ trợ `backdrop-filter`, hoặc khi người
   dùng bật `prefers-reduced-transparency` / `prefers-contrast: more` / `forced-colors`: khi đó dùng nền đặc của C.
3. PHP `td_badge($text, ['glass' => true])` sinh class `td-badge--glass`. JS: badge chỉ có CSS, không có element.
4. `--outline` và `--stamp` giữ nguyên hành vi (trong suốt, mực `-ink`, không bóng). `--glass` đi cùng `--outline` / `--stamp`
   thì không có tác dụng (outline / stamp thắng).
5. Mọi cặp chữ/nền ≥ 4.7:1 ở cả sáng lẫn tối (cổng `test:contrast` hiện có).

## Token (lớp `td.tokens`, `:root, [data-td-theme]` + khối tối)

- `--td-badge-{v}-bg` / `--td-badge-{v}-fg`: đổi giá trị theo bảng (đây là token công khai có sẵn, chỉ đổi giá trị mặc định).
- `--td-badge-{v}-border`: giữ tên (API công khai) nhưng giá trị mặc định = `transparent` (viền 1px vẫn chiếm chỗ, nên kích
  thước badge không đổi). `prefers-contrast: more` vẫn dùng `currentColor`.
- `--td-badge-shadow`: đổi thành `0 1px 2px rgb(0 0 0 / 10%), 0 2px 6px -1px rgb(0 0 0 / 10%)`; tối:
  `0 1px 2px rgb(0 0 0 / 50%), 0 2px 6px -1px rgb(0 0 0 / 45%)`. Hiện token này chưa có giá trị tối riêng, thêm ở khối tối.
- MỚI `--td-badge-glass-alpha` (`85%`), `--td-badge-glass-blur` (`12px`), `--td-badge-glass-edge` (sáng
  `rgb(255 255 255 / 55%)`, tối `rgb(255 255 255 / 16%)`), `--td-badge-glass-highlight` (sáng `rgb(255 255 255 / 60%)`, tối
  `rgb(255 255 255 / 12%)`). Nền kính = `color-mix(in srgb, var(--td-badge-{v}-bg) var(--td-badge-glass-alpha), transparent)`
  trong `@supports (backdrop-filter: blur(1px)) and (color: color-mix(...))`. Nếu thiếu một trong hai thì nền đặc C.
- MỚI `--td-badge-{v}-glass-fg` (chữ riêng cho kính, đậm hơn chữ C một nấc): sáng neutral `#27272a`, success `#14532d`,
  warning `#7c2d12`, danger `#7f1d1d`, info `#1e3a8a`, accent `#172554` (accent theo palette: `accent 45 % + #000`, cổng tự
  kiểm); tối neutral `#f4f4f5`, success `#dcfce7`, warning `#ffedd5`, danger `#fee2e2`, info `#dbeafe`, accent `#dbeafe`.
- **Đảm bảo tương phản trên MỌI nền phía sau** (Codex R1 #1): nền kính = tint ở alpha 85 % đè lên phông bất kỳ. Độ sáng
  của nền đã pha luôn nằm giữa hai cực "pha lên đen" và "pha lên trắng" (blur / saturate chỉ đổi phông, không đưa kênh màu
  ra ngoài [0, 1]). Tỉ lệ tương phản đơn điệu theo độ sáng nền khi nền không vượt qua độ sáng của chữ, nên chỉ cần đo hai cực.
  Đã đo: tệ nhất 4.94:1 (alpha 85 %, chữ glass-fg ở trên, cả sáng lẫn tối, cả 6 biến thể). Hạ alpha hoặc dùng chữ của C sẽ
  rớt xuống 3.4–3.9:1. Vì vậy alpha là token nhưng docs ghi rõ: site hạ alpha thì tự chịu tương phản.
- `src/theme/tokens.js:109` (danh sách token theme) và `src/theme/presets.js:235/276` (preset có giá trị badge accent): cập
  nhật giá trị accent cho khớp; thêm token mới vào danh sách nếu danh sách đó liệt kê token re-resolve theo scope.
- `test/tokens/golden.json`: các delta badge là **có chủ đích**. Cập nhật theo đúng cách golden spec cho phép (đọc
  `test/tokens/golden.spec.mjs`), không ghi lại cả file.

## CSS (`src/styles/components/badge.css`)

- `.td-badge` mặc định: thêm `box-shadow: var(--td-badge-shadow)` (đã có), viền giữ `1px solid var(--td-badge-{v}-border)`.
- `.td-badge--glass:not(.td-badge--outline, .td-badge--stamp)` trong `@supports`: `background-color` dùng color-mix ở trên,
  `backdrop-filter` + `-webkit-backdrop-filter`, `border-color: var(--td-badge-glass-edge)`,
  `box-shadow: inset 0 1px 0 var(--td-badge-glass-highlight), var(--td-badge-shadow)`.
- Fallback (Codex R1 #2): dùng lại **đúng** hợp đồng tắt kính có sẵn của `src/styles/glass.css`, không đặt cơ chế mới:
  `@media (prefers-reduced-transparency: reduce)` (hiện chỉ Chromium có), **`:root[data-td-glass="off"]`** (site tự tắt;
  Safari / iOS không có media query kia, nên đây là đường duy nhất trên WebKit), `(prefers-contrast: more)`,
  `(forced-colors: active)`. Mọi trường hợp: bỏ `backdrop-filter`, nền đặc C, chữ glass-fg vẫn đạt (đo trên nền đặc).
  Docs ghi rõ: tự động tắt theo cài đặt người dùng chỉ có ở engine hỗ trợ query; còn lại site dùng `data-td-glass="off"`. Theo cách `src/styles/glass.css` đang làm cho popup (đọc và dùng lại pattern, ví dụ
  `--_td-glass-fill-a11y`, nếu áp được).
- Cập nhật comment đầu file (đang mô tả kiểu đặc v0.36.0) và bảng Badge trong `docs/internal/design/liquid-glass.md:28`. Luật
  minimal surfaces nói badge là nội dung, không phải glass. `--glass` là ngoại lệ **tuỳ chọn**, do owner chốt. Ghi "Bổ sung
  v0.76" vào ADR 0011 (một đoạn ngắn: vì sao cho phép, fallback).
