### Quyết định thiết kế

1. **Mỗi bản tô đặc là một icon riêng `<id>-filled`** (15: `chart-no-axes-column-filled`, `eye-filled`,
   `clock-filled`, `circle-check-filled`, `circle-pause-filled`, `save-filled`, `corner-right-down-filled`,
   `trash-filled`, `home-filled`, `flame-filled`, `calendar-days-filled`, `phone-filled`, `phone-off-filled`,
   `user-plus-filled`, `user-minus-filled`). Lý do: mọi chỗ nhận tên icon (slot, picker, `td_icon`, giá trị đã lưu)
   chạy ngay không cần đổi, site cũng tự thêm `site-x-filled` qua `registerIcons()`.
2. **Dữ liệu = MỘT `<path>` tô đặc, `paint: "fill"`**, tính sẵn offline: (fill(body) ∪ stroke(body, 2)) − stroke(cut)
   ∪ stroke(over), nét tròn. KHÔNG dùng `<mask>` / `url(#id)` / `<g>`: bộ lọc định nghĩa (JS `TAGS`/`ATTRS`,
   PHP `ICON_TAGS`/`ICON_ATTRS`, `svgStringToDefinition` chặn `url()`) giữ nguyên, không cần id duy nhất, SSR và
   JS ra cùng markup. Đã đo: bản path so với bản mask owner duyệt lệch 0,01–1,1% pixel ở 192px (răng cưa mép),
   `eye` 3% (viền dưới < 1px). Công cụ: `scripts/filled-icons/` gồm `design.json` (body/cut/over từng icon, bản
   owner duyệt) + `flatten.py` (picosvg + skia-pathops, **chỉ dev, không vào package/devDependencies**; README một
   dòng cách chạy trong venv). Kết quả ghi thẳng vào `icons.json`, commit.
3. **Nguồn gốc**: bản filled là hình phái sinh từ Lucide (ISC cho phép sửa) → mục icons.json ghi `"lucide": "<tên
   gốc>"` (giữ ghi công ISC, thoả luật "đúng một trong lucide / source td" của ADR 0039). Không dùng `source: "td"`.
4. **API `variant`** (chỉ `'outline'` mặc định | `'filled'`; giá trị khác = outline):
   - JS `tdIcon(name, { variant })`: resolve tên/alias → `r`; `variant === 'filled'` và có `r + '-filled'` → vẽ nó,
     không có → vẽ `r` (rơi về nét, không warn). `data-icon` = tên thực vẽ. Tên đã là `x-filled` thì giữ nguyên.
   - `<td-icon variant="filled">`: thêm `variant` vào `observedAttributes`; kiểm tra giữ con SSR so với tên hiệu lực
     (sau khi áp variant), không phải `name`.
   - Slot: `data-td-icon-variant="filled"` trong `fillIconSlots`.
   - PHP: `Td::icon($name, $size, $label, $class, string $variant = '')` + `td_icon($name, $size, $label,
     $variant = '')`; cùng luật rơi về. Thêm `Td::iconVariant()`? KHÔNG (không cần).
   - Không đổi `td-icon-picker` (filled là icon thường, hiện trong picker với nhãn "… (tô đặc)").
5. **Search metadata**: 19 mục mới trong `icons-search.json` (bản filled: nhãn `<nhãn gốc> (tô đặc)`, từ khoá gốc
   + `filled, solid, tô đặc, đặc`).
6. Số icon: 222 → **241** (4 nét + 15 filled); sửa các test/docs đếm cứng (danh sách ở memory/plan v0.103.0:
   `icons-aliases.test.js`, `icons-search.test.js`, `test/php/td-php.test.js`, `test/php/td-ssr-icon-picker.test.js`,
   `docs/components/icons.md`, `icon-picker.md`, `php/README.md`).

### Khảo sát avatar (08/11, agent chỉ đọc)

**135** (`public/assets/app/base.css:233-241`) đã dùng đúng tên `.td-avatar`: 40px mặc định, `--xs` 22 / `--sm` 32 /
`--lg` 96, tròn, `object-fit: cover` + `aspect-ratio: 1` + `max-width: none; flex: none` (chống bị `img {max-width:100%}`
bóp méo trong ô bảng), vòng = box-shadow kép `0 0 0 2px <nền>, 0 0 0 3px <đường kẻ>` (xs 1.5/2.5px), `--empty` = span
`aria-hidden` chứa chữ cái đầu viết hoa (PHP/JS tính, `?` khi rỗng; đôi khi là `td_icon('image')`), nền kraft, chữ
display 800; 7 chỗ phải tự thêm `display:grid; place-items:center` → kit nên căn giữa sẵn. Override lẻ: 34px, 64px
(mobile lg). **dwp** chưa có `.td-avatar`; nhiều kiểu rời: sidebar / share / compose 32px tròn không vòng; `.dwp-avatar`
(aetv, `--dwp-avatar-size`, vòng 1px, placeholder SVG hình người); `.dwp-ua-avatar` 72px viền 1px, empty = hình người
CSS mask; pen placeholder 48px viền nét đứt; `.dwp-fta-avatar-ph` là khung logo chữ nhật (KHÔNG phải avatar).

Hướng đề xuất (chờ owner chốt UX): mặc định = hình 135 (135 chuyển không đổi gì), cỡ qua `--td-avatar-size` + lớp
`--xs/--sm/--lg`; vòng qua token `--td-avatar-ring` (mặc định vòng kép của 135 theo token nền/đường kẻ của kit;
`none` để bỏ); `--empty` căn giữa sẵn, nội dung do site đưa vào (chữ cái hoặc `td_icon`). Có helper PHP/JS tính chữ
