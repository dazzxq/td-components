## Mục tiêu

1. **Dark chính thức** (bỏ nhãn EXPERIMENTAL): `data-td-theme="light|dark|auto"`; `auto` theo OS bằng CSS thuần, không JS,
   không FOUC. Không đặt attribute = light, **giống từng pixel** hôm nay.
2. **Nối dây ngữ nghĩa**: mọi token component màu suy ra từ một bộ token ngữ nghĩa có tên (hợp đồng theme), để site chỉ cần
   đặt bộ đó là cả kit đi theo — không còn ô nhập / popup trắng cứng trên nền be.
3. **Palette tuỳ biến tự cân tương phản** (R2): site đưa `bg` + `accent` (+ tuỳ chọn surface…), kit sinh file CSS tĩnh với chữ,
   viền, hover, focus, accent, ngữ nghĩa đạt WCAG 2.x AA, hoặc báo lỗi có mã khi về toán học không đạt được.
4. **Theme theo vùng** (R2): `<section data-td-theme="dark">` trong trang light hoạt động bằng token gốc, kể cả popup portal mở
   từ trong vùng.

## Non-goals (cắt — không phải hoãn, trừ khi ghi "R3")

Tự lật theo OS khi không đặt attribute · runtime auto-theming không có consumer (`TdTheme.apply()` = **R3 tuỳ chọn**, không
lên plan chi tiết) · port thuật toán sang PHP · APCA làm gate (chỉ chẩn đoán) · tự giảm sáng ảnh trong dark · công thức hover
cho site tự chỉnh · component `td-theme-toggle` (việc của site) · suy màu bằng CSS hiện đại (kể cả nhánh `@supports
color-mix`) · hứa "mọi màu đều đạt" · theme theo vùng ở R1 · làm mới live popup **đang mở** khi OS đổi theme (mở lại là đúng) ·
sinh lại pastel/alert/badge mặc định của kit bằng thuật toán (giữ hex cũ).

## Hợp đồng theme (`THEME_TOKENS`)

Bộ token **ngữ nghĩa** mà một theme (kit light, kit dark, fixture, file sinh) phải đặt đủ. Token component chỉ được đọc từ bộ
này (hoặc từ token component khác), không literal giả định nền trắng. Danh sách chốt ở R1-M1 sau kiểm kê; khung:

| Nhóm | Token (giữ tên cũ; *nghiêng* = mới ở R1, ứng viên) |
|---|---|
| Bề mặt | `--td-color-bg`, `--td-color-surface`, `--td-color-surface-muted`, *`--td-color-surface-raised`*, `--td-control-bg`, `--td-glass-solid`, `--td-glass-bg`, `--td-glass-bg-strong` |
| Mực | `--td-color-text`, `-text-muted`, `-text-subtle`, `--td-control-fg`, `--td-glass-fg`, *`--td-color-text-label`* (nếu M1 cần giữ gray-700 của label) |
| Cấu trúc | `--td-color-border`, `-border-strong`, `--td-hairline`, `--td-glass-border`, `--td-control-border`, `-border-strong`, `-border-soft`, `-border-hover`, `--td-focus`, `--td-focus-ring` |
| Tương tác / nền phụ | `--td-color-hover`, `-hover-strong`, `-skeleton`, `-sheen`, *`--td-color-fill`* (switch off, secondary, badge neutral, field disabled), *`--td-color-fill-strong`* (chip) |
| Accent | `--td-accent`, `--td-accent-fill`, `--td-accent-contrast` |
| Ngữ nghĩa | `--td-color-{success,warning,error,info}`, `--td-color-on-status`, `--td-pastel-{success,danger,warning,info}-{bg,border,fg}` |
| Nút đặc | `--td-btn-primary-{bg,fg,hover}`, `--td-btn-disabled-{bg,fg,border}` |
| Độ nổi | `--td-shadow-1..3`, `--td-glass-shadow`, `-shadow-lg`, `--td-btn-lift`, `--td-color-overlay`, *`--td-tooltip-bg/-fg/-border`* (đưa lên hợp đồng nếu M1 thấy cần) |

Luật: thêm token mới vào hợp đồng = tăng `THEME_TOKENS_VERSION` + CHANGELOG. Tối đa ~6 token mới ở R1; mỗi token mới mặc định
= đúng hex hiện tại ở light **và** dark.

  mở từ ngoài vùng không bị ảnh hưởng; đóng popup → không còn inline thừa.

## Tương thích ngược + nâng cấp

- Không đặt `data-td-theme` → giống v0.40 (golden + CSP parity). Không có tự lật theo OS.
- Override unlayered `:root { --td-* }` hiện có của site vẫn thắng (kit + file sinh đều trong `@layer td.tokens`).
  `:root[data-td-theme="dark"] { … }` của site giữ nguyên tác dụng (R2 vẫn giữ `:root[data-td-theme="dark"]` trong selector).
- Site đang đặt `--td-control-bg` / `--td-glass-solid` riêng: vẫn thắng alias mới. Site muốn mọi bề mặt nổi đổi cùng lúc: đặt
  `--td-color-surface-raised`.
- Dark đổi giá trị có chủ đích (danh sách delta) — site dark ghi đè giá trị cũ thì xem lại.
- 135 hôm nay (`--td-glass-solid: var(--c-paper-2)` ở roadmap): tiếp tục chạy; R1 đề xuất thay bằng `--td-color-bg` +
  `--td-color-surface` (+ raised), R2 bằng file sinh.
- `dom-utils.js` `contrastRatio` / `getAccessibleTextColor`: giữ API + kết quả.
- R2: token màu override trên `:root` không chảy vào vùng `[data-td-theme]` (ADR 0020) — chỉ ảnh hưởng site **chủ động** đặt
  vùng (opt-in), ghi upgrade note.

## Lệch so với đồng thuận (ghi lại để review)

  scope cả khối (tách 36 file không đáng), ghi upgrade note.

  attribute có thể đổi render native → vi phạm "không đặt = pixel-identical". Giữ không đặt.
