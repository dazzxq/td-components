### 5.2 `icons-search.json` (nguồn soạn, mới)

```json
{ "$schema": "td-icons-search/1", "$comment": "…",
  "icons": { "trash": { "label": "Thùng rác", "keywords": { "en": ["trash", "delete", "bin"], "vi": ["xoá", "thùng rác"] } } } }
```

- Khoá = **đúng** tập tên trong `icons.json.icons` (188; không thiếu, không thừa, không alias, không tên FA).
- Luật mỗi mục (một validator dùng chung, xem 5.3): `label` chuỗi NFC, trim, 1–48 ký tự, không ký tự điều khiển;
  `keywords.en` / `keywords.vi` mảng 1–12 phần tử, mỗi phần tử như label (1–48); không trùng trong cùng mục sau khi
  `fold()` (trùng = **lỗi build**, không tự khử — giữ nguồn sạch); không khoá lạ (`group`, `source`… → lỗi).
- Nội dung: VI lấy từ dsuite `resources/icons/kit-meta.json` (75 icon hiện có, owner soạn) và `font-awesome.json` /
  `dsuite.json` (nhãn VI cho khái niệm tương ứng); EN viết mới + tham khảo `tags.json` của lucide-static (ISC). **Không
  chép danh sách keyword tiếng Anh của Font Awesome** (vệ sinh giấy phép) — chỉ dùng phần VI do dsuite viết.

### 5.3 Build + gate

- Module mới `src/icons/icon-search-schema.js` (thuần, không import): `validateSearchEntry(name, entry)` → bản sạch đóng
  băng hoặc ném `TypeError`. Dùng chung cho script build và `registerIconSearchData()` lúc chạy (một validator, như
  `_validateIconDefinition`). Hằng giới hạn export để PHP test so khớp.
- `scripts/build-icons.mjs` mở rộng (vẫn một lệnh `build:icons` / `check:icons`):
  1. Kiểm mỗi icon có `lucide` **xor** `source === "td"` (lỗi build nếu không).
  2. Đọc `icons-search.json`, kiểm khoá == tập icon, chạy validator từng mục.
  3. Sinh `src/icons/icons-search.js`: header GENERATED + `export default Object.freeze({…})`, **một dòng / icon**, khoá
     sắp theo thứ tự `icons.json`. Ghi qua `scripts/safe-file.mjs` (`writeGenerated` / `readGenerated`), như
     rich-text-policy.

## 6. ADR 0039 — icon owner tự vẽ trong registry core (bổ sung ADR 0010)

- **Context:** 9 glyph bố cục dcms2 do owner vẽ; owner muốn mọi site dùng kit có sẵn (03/11). ADR 0010 nói "dữ liệu Lucide".
- **Decision:** registry core nhận icon **td (owner tự vẽ)**: ghi `"source": "td"` thay `lucide`, được dùng `paint:
  "fill"`; vẫn qua đúng allowlist, khung `0 0 24 24`, tên ngữ nghĩa td. Chỉ owner (hoặc người owner duyệt) thêm loại này;
  icon thương hiệu vẫn cấm. Không mở cửa cho Font Awesome.
- **Consequences:** THIRD_PARTY_NOTICES: thêm đoạn Lucide 0.94.0 (kiểm với 1.66.0, ghi 3 tên canonical đổi + bỏ `fill` ở
  chấm `tags` / `images`) và một câu "icons with `source: \"td\"` are original td artwork, not Lucide" (không thuộc ISC
  Lucide; cùng giấy phép package). ADR 0010 thêm dòng "Amended by 0039". `decisions/README.md` thêm mục.

### 8.3 Hành vi

- **Mở:** click / Enter / Space / ArrowDown / Alt+ArrowDown trên trigger. Panel dựng **mỗi lần mở**, gỡ khi đóng (không
  state cũ; icon site đăng ký sau sẽ có ở lần mở sau). Lưới lấy `listIcons()` (core + site), **sắp theo tên canonical**
  (`localeCompare` với `'en'`, ổn định) — xem Q3.
- **Focus khi mở:** con trỏ mịn → ô tìm. Cảm ứng (`isCoarsePointer()`, như dropdown) → ô đang chọn (hoặc ô đầu), không
  bật bàn phím ảo. Roving tabindex của mỗi lưới đặt ở ô đang chọn nếu có, không thì ô đầu.
- **Vị trí:** `placeFloating(trigger, panel, { list: body, align: 'start' })` — body nhận `max-height` khi thiếu chỗ;
  `watchReference` + `isReferenceHidden` đóng khi trigger cuộn khuất (như color-picker). Bề rộng panel = `cột × ô +
  khe + padding`; cột = `clamp(4, floor((viewport − 16 − padding) / bước ô), --td-icon-picker-columns)`; resize khi mở →
  tính lại cột, dựng lại hàng (giữ node ô + focus).
- **Dựng ô:** mỗi ô một `<button>` + `tdIcon(name)` (createElementNS). Ô được tạo **một lần mỗi lần mở** và giữ trong
  `Map<name, button>`; lọc / xếp hạng chỉ **di chuyển** node vào hàng mới, không tạo lại SVG. Ô ở "Gợi ý" là node riêng
  (cùng tên có thể hiện hai nơi, cả hai `aria-selected`).
- **Không virtualization — lý do:** 188 ô ≈ 190 button + ~550 node SVG; trang dsuite nặng nhất (kit + `ds-*` 77 +
  `ds-fa-*` 192) ≈ 460 ô ≈ 2 000 node — dựng một lần khi mở, cỡ vài ms, cuộn native. Virtualization phá roving focus /
  đếm `aria-rowcount` và thêm code; chỉ xét lại nếu có site > 1 000 icon (test 9.2 khoá 600 icon vẫn mở + lọc đúng).
- **Tìm:** gõ → lọc ngay (không debounce; tập nhỏ). Query rỗng → "Gợi ý" (nếu có) + "Tất cả icon". Query khác rỗng →
  ẩn "Gợi ý", nhóm còn lại đổi tiêu đề "Kết quả", thứ tự theo hạng (8.4). Không kết quả → `__empty`. `__status`
  (role="status") báo "{n} icon" (cập nhật sau 300 ms im gõ để trình đọc không dồn). **Enter** trong ô tìm (query khác
  rỗng, có kết quả) = chọn kết quả đầu. **ArrowDown** trong ô tìm → focus lưới đầu tiên đang hiện.
- **Nạp metadata (D7):** lần mở đầu gọi `loadSearchData()` (promise module-level, dùng chung mọi instance). Trong lúc chờ:
  lưới + tìm theo **tên + alias** chạy được ngay; status "Đang tải từ khoá tìm kiếm…". Xong → dựng chỉ mục (cache
  module-level; **mỗi lần mở** so tập canonical hiện tại của `listIcons()` (+ tập metadata) với tập đã index, khác → dựng lại; alias chỉ index khi không bị một tên canonical đã đăng ký che (đúng luật resolve của registry)), chạy lại query hiện tại, cập nhật `aria-label` ô + caption,
  giữ focus. Lỗi → `promise = null` (lần sau thử lại), status "Không tải được từ khoá — đang tìm theo tên" + nút "Thử
  lại" (bấm → gọi lại loader). Generation guard: kết quả về sau khi panel đã đóng / host gỡ → chỉ cache, không chạm DOM.
- **Chữ trên trigger (Q1 → c):** luôn là **tên canonical**, JS và PHP SSR giống nhau, không phụ thuộc metadata (không nháy
  chữ). Nhãn VI chỉ dùng trong popover (caption, `aria-label` ô).
- **Chọn:** click / Enter / Space trên ô → đặt value, bắn `input` + `change` (nếu khác), đóng, focus về trigger. Ô đang
  chọn chọn lại → chỉ đóng. **Xoá:** nút `__clear` → value `''`, `input` + `change`, focus trigger.
- **Đóng:** Esc (focus về trigger, không đổi giá trị), click ngoài, trigger cuộn khuất, host disabled / readonly / gỡ.
  Tab / Shift+Tab xoay vòng trong panel (`trapTab`, như color-picker): ô tìm → lưới Gợi ý → lưới chính → Thử lại.
- **Caption (tên khi rê / focus):** `pointerover` (chỉ `pointerType` mouse / pen) hoặc focus một ô → caption "{nhãn} ·
  {tên}" (textContent); rời → caption về icon đang chọn. Không dùng td-tooltip (188 tooltip, luật touch 10). Cảm ứng không
  có rê → xem Q4.

### 8.4 Xếp hạng + chuẩn hoá VI

- Chuẩn hoá: `fold()` sẵn có (`src/utils/typeahead.js`: NFD bỏ dấu, `đ → d`, lowercase) + `-`/`_` → khoảng trắng + gộp
  khoảng trắng + trim. Áp cho query và (một lần khi dựng chỉ mục) cho tên, alias (`icons.json.aliases` trỏ về icon), nhãn,
  từ khoá EN + VI.
- Hạng (nhỏ hơn = trước), mỗi icon lấy hạng tốt nhất:
  0. query == tên hoặc alias; 1. query == nhãn hoặc một từ khoá; 2. tên / alias bắt đầu bằng query; 3. nhãn / từ khoá có
  **đầu từ** bắt đầu bằng query; 4. (query ≥ 2 ký tự) **mọi** từ của query là chuỗi con của tên ∪ alias ∪ nhãn ∪ từ khoá.
- Hoà hạng → thứ tự tên canonical. Không khớp → loại. Query bị cắt 64 ký tự, tối đa 8 từ (giới hạn công việc).
- Model thuần: `buildIconIndex({ names, aliases, data })`, `searchIcons(index, query)` → `string[]` — test Node đủ.

### 8.6 A11y

- Trigger: `button` + `aria-haspopup="dialog"` + `aria-expanded` + `aria-controls` (khi mở) + tên = `aria-labelledby`
  (nhãn field hiển thị **hoặc** span ẩn `{host}-name` mang `aria-label` của host khi không có `label`, + chữ giá trị) → đọc "Icon mục, trash". Không label lẫn aria-label → chỉ chữ giá trị + warn dev một lần. Test cả hai trường hợp (label hiển thị / chỉ aria-label), JS và SSR. Lỗi: `aria-invalid` + `aria-errormessage` (base).
- Panel `role="dialog"` có `aria-label`. Mỗi nhóm một `role="grid"` có `aria-labelledby` tiêu đề nhóm; hàng `role="row"`;
  ô `button[role="gridcell"]` (vai được phép trên button), `aria-selected`, `aria-label` = nhãn VI (chưa có metadata → tên).
  `aria-rowcount` / `aria-colcount` không cần (mọi hàng có trong DOM).
- Phím trong lưới: ← → (không vòng qua hàng; đầu / cuối hàng dừng), ↑ ↓ (hàng trên / dưới cùng cột, hàng cuối ngắn → ô
  cuối), Home / End (đầu / cuối hàng), Ctrl+Home / Ctrl+End (ô đầu / cuối lưới), PageUp / PageDown (lùi / tiến số hàng
  vừa body đang hiện), Enter / Space chọn, Esc đóng. ↑ ở hàng đầu lưới đầu → về ô tìm. `focus({ preventScroll: true })`
  + chỉnh `scrollTop` của body để ô vào tầm nhìn (không `scrollIntoView`, luật touch 12).
- Lý do grid chứ không listbox: D10; listbox một chiều khiến trình đọc báo ↑↓ là "trước / sau" lệch với lưới thấy được.

### 8.7 Bảo mật

- Nhãn / từ khoá / tên luôn vào DOM bằng `textContent` / `setAttribute` (aria-label); không `innerHTML` ở đâu trong
  component. SVG chỉ qua `tdIcon()` (allowlist sẵn).
- `registerIconSearchData` / `loadSearchData` hook / PHP `registerIconSearchData`: validator 5.3 (kiểu, độ dài, số phần
  tử, NFC, không ký tự điều khiển, khoá lạ → lỗi). Giới hạn công việc: tối đa 2 000 mục / lần gọi, query ≤ 64 ký tự.
- `suggestions`: chỉ tên khớp `NAME_RE` và đã đăng ký; ≤ 24; chuỗi attribute > 2 KB bị bỏ trước khi tách (như presets
