## A. `td-choice-group variant="tiles"` (R7)

1. `VARIANTS` thêm `'tiles'`. Lưới ô: icon trên (1.75rem), nhãn dưới (căn giữa, tối đa 2 dòng, cắt `…`); `hint` và ghi chú
   `unavailable` chỉ là mô tả cho trình đọc (`td-sr-only`, như segmented). Hành vi radio / bàn phím / form / required /
   unavailable / disabled / SSR: dùng nguyên code chung (radio thật, `_onKeydown` vòng quanh đầu-cuối không phụ thuộc
   variant).
2. `_faceHTML`: nhánh `tiles` cùng dạng segmented (icon slot + text + hint/note sr-only) nhưng **không** `data-label`, không
   `icon-only`. `size` / `icon-only` / `stretch` chỉ của segmented (tiles bỏ qua). Không dùng engine layout segmented.
3. `_variantWarnings`: swatch / image không hiện ở tiles (cảnh báo như segmented); icon giờ hiện ở segmented **và** tiles
   (chữ cảnh báo đổi tương ứng).
4. CSS `.td-choice--tiles`: `.td-choice__options` = grid `repeat(auto-fill, minmax(var(--td-choice-tile-min), 1fr))`, gap
   `--td-choice-gap`; ô **vuông**: `.td-choice__option` lấp ô lưới, `.td-choice__face` `aspect-ratio: 1` + `width: 100%`
   (nội dung căn giữa theo cả hai trục; nhãn dài cắt 2 dòng nên không làm ô cao hơn rộng), padding, viền/nền như variant button (cùng token
   `--td-choice-border`, `--td-choice-selected`, `--td-choice-selected-bg`), chọn = viền accent 2px + nền selected; disabled /
   unavailable mờ như button; focus-visible ring như button. Token mới: `--td-choice-tile-min` (5.5rem),
   `--td-choice-tile-icon` (1.75rem). Rule nhấn `:is(:active,[data-td-pressed])` + hover gate đã chung cho
   `.td-choice__option` → tiles hưởng sẵn (kiểm bằng test touch). Forced colors: viền chọn `Highlight`. Vùng chạm ≥ 40px
   (cạnh ô ≥ 5.5rem).
5. Adapter PHP: `variant` 'tiles' chưa hỗ trợ (rơi về 'button' như mọi giá trị lạ) — ghi trong docs.

## B. `td-chip-input selection-only` + `create-label` (R8)

1. Attribute mới `create-label` (+ property `createLabel` phản chiếu, vào `observedAttributes`, `UPGRADE_PROPS`). Chỉ có
   hiệu lực với `selection-only`; không có `selection-only` → một cảnh báo ("create-label applies only with selection-only;
   use allow-create"). `allow-create` + `selection-only` vẫn bị bỏ qua với cảnh báo cũ (không đổi).
2. Dòng tạo: dòng **cuối** của listbox (sau mọi dòng / nhóm, ngoài nhóm), **ghim đáy** vùng cuộn: listbox
   `.td-chip-input__options` chính là phần tử cuộn, nên dòng tạo `position: sticky; bottom: 0` + nền đặc của popup
   (`--td-chip-input-popup-bg` / nền menu sẵn có) + viền trên — luôn thấy khi danh sách cuộn, không cần đổi cấu trúc
   DOM (test: danh sách tràn, cuộn giữa/cuối, rect dòng tạo nằm trọn trong rect listbox; `scrollIntoView` của dòng active
   không bị dòng ghim che — `scroll-padding-bottom` bằng chiều cao dòng tạo), `role="option"`, `aria-selected="false"`, id
   `{id}-opt-create`, class `td-chip-input__option td-chip-input__option--create`, không dấu tích, không bao giờ locked
   (kể cả khi đầy `max-items`). Chữ: ô gõ rỗng → `create-label`; có chữ → `labels.create` (`Thêm “{text}”`, khoá sẵn có)
   với chữ đã `cleanText`. Chữ qua `textContent` (DOM API, như mọi dòng).
3. Hiện khi danh sách kết quả hiện (`_applySelResults`), kể cả 0 kết quả (dòng "Không tìm thấy" + dòng tạo) và khi chưa
   có option nào (`!leaves.length && !q` không đóng popup nữa nếu có dòng tạo). Không hiện ở trạng thái đang tải / lỗi
   (`_showState`).
4. Kích hoạt (click, Enter khi active): đóng popup, xoá chữ lọc trong ô gõ, focus ở lại ô gõ, rồi phát `create` với
   `detail: { query }` (chữ đã gõ, `cleanText`, `''` nếu rỗng). Không đổi giá trị, không `change`. Site tự tạo bản ghi rồi
   gán `options` + `value`. Phím: dòng tạo là mục cuối của `_nav` → ArrowDown đi tới, ArrowUp từ dòng đầu vòng về nó (wrap sẵn có).
   `Home` / `End` trong ô gõ giữ nguyên là phím con trỏ chữ (không đổi). Select-all không tính dòng tạo.
5. CSS: dòng tạo dùng màu chữ create của dropdown (`--td-dropdown-create-fg` không có ở đây → token mới
   `--td-chip-input-create-fg` = cùng công thức accent đậm 18% / dark pha 45% trắng + fallback), icon `plus` đầu dòng.

## C. `td-dropdown renderOption` (P3 của R1)

1. Property `renderOption(item, { query, selected }) => Node | string | null` (khác hàm → `null`; `UPGRADE_PROPS` thêm).
   Gán → `_renderMenuOptions()` nếu đã render.
2. Kết quả thay **nội dung `.td-dropdown__option-label`** của mỗi dòng option (thường và rich); icon / mô tả / trạng thái /
   meta / dấu tích vẫn dựng từ field như cũ. Node → chèn bằng `replaceChildren` sau khi dựng chuỗi (CSP-safe, không
   innerHTML từ site); chuỗi → `textContent`; `null` / `''` / ném lỗi → nhãn chữ thường (`console.error` khi ném). Không
   áp cho trigger, dòng clear, dòng tạo. Tìm / type-ahead / `aria-*` vẫn theo `label` / `keywords`.
3. Có `renderOption` → listMax luôn đo thật (`measured = true`), vì Node có thể đổi chiều cao.
4. Docs: Node không được chứa phần tử nhận focus (dòng là `option`); site chịu trách nhiệm nội dung Node của mình.
