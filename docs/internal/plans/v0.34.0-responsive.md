# v0.34.0 — Responsive chuẩn toàn kit (mobile → máy gập → tablet dọc → desktop) + `td-table` dạng card

Nguồn (đọc đủ trước khi làm):

- **Owner:** "check 1 lượt toàn bộ components … làm responsive chuẩn cho toàn bộ break point: mobile → máy gập → tablet
  dọc (ipad mini dọc) → desktop". Owner uỷ quyền chốt.
- **dsuite** `dienthoaihay/docs/06-TD-COMPONENTS-REQUESTS.md`: DoD kit có "responsive"; breakpoint < 480 · 480–767 ·
  768–1023 (máy gập mở ~840–884, iPad mini / iPad dọc 744–834) · 1024–1279 · ≥ 1280; ô chạm ≥ 44px khi `pointer: coarse`;
  ưu tiên container query trong component.
- **Roadmap cũ:** v0.34 = "`td-table` card + chọn dòng, viết ADR container-query trước", v0.37 = "responsive toàn kit +
  screenshot 8 độ rộng". Plan này **gộp** hai mục: v0.34.0 = responsive toàn kit + ADR + card + gate; chọn dòng dời sang
  v0.36 (cùng ẩn / hiện cột — cùng vùng code bảng). v0.37 bỏ khỏi roadmap.
- **Audit đo thật 2026-10-04** trên `main` = v0.32.0 (`9a376da`) — mục "Kết quả audit" dưới; dữ liệu máy đọc + ảnh:
  `responsive-audit/` trong scratchpad phiên audit (`findings.json`, `summary.json`, `<engine>-<w>x<h>-<fine|touch>/`
  `sections/*.png` + `ov-*.png`, `sheets/*.png` ghép theo độ rộng, `scripts/` để chạy lại). Script audit là **tiền thân**
  của gate M6 (chép logic, không chép file tạm).
- ADR mới **[0014](../decisions/0014-breakpoints-container-queries.md)** (viết cùng plan): bộ breakpoint có tên + quy ước
  `@container` / `@media` + luật nền.

Không dependency mới; CSP strict (container query là CSS thuần); light DOM; Minimal surfaces (ADR 0011). Branch

Lỗi phụ đo được: `td-button` nhãn dài không xuống dòng (đẩy trang tới 409px ở 360); host `td-datetime-picker` (196px),
`td-tree-select` (179), `td-chip-input` (180), `td-tree` (125) có min-content lớn hơn ô lưới 2 cột → phá lưới của site;
`td-table` mobile: cột cuối bị che không có dấu hiệu cuộn, badge dính số liệu bên cạnh; toast không có
`safe-area-inset-top`; drawer full màn hình không có `safe-area-inset-top`; dropdown / tree-select tự focus ô tìm khi
`innerWidth ≥ 768` → **iPad (cảm ứng, 744–1024) bật bàn phím che popup**. Ô chạm < 44 khi `coarse` (sau khi loại số đo
sai do animation): `td-tree-select__clear` 28×28, ô tìm `td-tree` 36, input `td-tree-select` 34, nút kéo sheet lightbox
(`.td-lightbox__grab`) 36, tick `td-media-grid` / `td-sortable` / tile media picker 24×24 (vùng `::before` 44px **bị

(modal / drawer / menu / dropdown / datetime / pagination / button / toast) **đã đạt 44** — luật `pointer: coarse` hiện có
chạy đúng. Toast: nút đóng ẩn (1×1, chỉ hiện khi focus) — đúng thiết kế (bấm cả toast để đóng), ghi ngoại lệ.

Không lỗi: popup neo (dropdown, chip-input, tree-select, menu, tooltip, hovercard) luôn nằm trong viewport ở mọi độ rộng
(lật lên trên đúng); modal / drawer / lightbox / loading đúng kích thước từ 390 trở lên; media picker ≤ 640 đúng một màn.

## Quyết định đã chốt (owner uỷ quyền — không còn câu hỏi mở)

**Nền (ADR 0014)**

1. **Breakpoint có tên** `xs` < 480 · `sm` 480–719 · `md` 720–1023 · `lg` 1024–1279 · `xl` ≥ 1280 · `short` = chiều cao
   ≤ 500. Ranh giới `sm/md` = **720** (không phải 768 của dsuite) để iPad mini dọc 744 là tablet; báo dsuite lý do.
   `@media` viết `(max-width: 719.98px)` / `(min-width: 720px)` (Chrome 102 chưa có range syntax trong `@media`);
   `@container` viết `(width < 720px)`. Chỉ các số 480 / 720 / 1024 / 1280 / 500 (± `.98`) được phép; ngoại lệ cần
   `/* bp-exception: … */`.
2. **`src/utils/breakpoints.js`** (mới, export subpath `./breakpoints`): `BREAKPOINTS`, `SHORT_MAX`, `mqBelow(name)` →
   chuỗi media, `matchesBelow(name)`, `isCoarsePointer()` (`(hover: none) and (pointer: coarse)`), `isShort()`. Mọi
   `matchMedia` theo kích thước / `innerWidth` trong component đi qua đây. Thay: `td-media-picker.js` `_isNarrow` (640 →
   `matchesBelow('md')`), `td-dropdown.js` L1194 + `td-tree-select.js` L965 (`innerWidth >= 768` → `!isCoarsePointer()`:
   **thiết bị cảm ứng không tự focus ô tìm**, mọi độ rộng).
3. **Gate tĩnh** (lane A): `scripts/build-css.mjs --check` thêm quét `@media` / `@container` trong `src/styles/**/*.css`
   (số ngoài danh sách → lỗi kèm file:dòng); node test `src/utils/breakpoints.test.js` quét `src/**/*.js` (bỏ test /
   stories) cấm `innerWidth`, `matchMedia('(…width…`, `matchMedia('(…height…` ngoài `breakpoints.js`. `floating.js` /
   `scroll-lock.js` / `tooltip` dùng `innerWidth` để **đo**, không làm ngưỡng → allowlist có lý do trong test.
4. **Container hay media** đúng ADR 0014 §3: component trong dòng nội dung → `@container` trên host block-level
   (`container: td-<x> / inline-size`); lớp phủ + điều kiện thiết bị → `@media`. Không có container query → bố cục hiện
   tại (nâng cấp dần). Kit tự đặt phân trang trong flex (header bảng) → `flex: 1 1 auto; min-inline-size: 0`.

**Luật vùng chạm (`pointer: coarse`)**

5. Mọi phần tử tương tác **hiệu dụng ≥ 44 × 44** khi `(pointer: coarse)` — có thể nhỏ hơn về hình (glyph 24px) nếu
   `::before` mở rộng **không bị tổ tiên `overflow` cắt** và không chồng vùng chạm của phần tử khác. Chuột: ≥ 24 × 24.
   Ngoại lệ có danh sách (gate allowlist, mỗi dòng một lý do): nút đóng toast (ẩn, cả toast là vùng bấm), control native
   ẩn bên trong label đã ≥ 44, liên kết trong đoạn văn của site.
6. Sửa theo audit: `.td-tree-select__clear` 28 → `--td-touch-min` (coarse); `.td-tree__search` 36 → 44 (coarse, cùng
   `font-size: max(1rem, 1em)` chống zoom iOS như `field.css`); input `td-tree-select` / `td-chip-input` = chiều cao box
   (44) khi coarse; `.td-lightbox__grab` 36 → 44; tick media-grid / sortable / tile picker: đặt tick cách mép tile ≥ 10px
   **hoặc** tách lớp `overflow: hidden` khỏi lớp chứa tick, để ô 44px nằm trọn trong tile; `th` sort khi coarse
   `min-inline-size: 44px`.

**Component trong dòng nội dung (`@container`)**

8. **`td-pagination`**: `container: td-pagination / inline-size`. Sửa tràn trái: bỏ `justify-content: flex-end` làm tràn
   về trái → `margin-inline-start: auto` cho cụm nút (tràn, nếu có, chỉ sang phải và bị container cắt → gate bắt).
   Mật độ theo container: `≥ 480` như nay (trang đầu / cuối + 2 bên); `< 480` chỉ đầu / hiện tại / cuối + `…` (JS đánh
   `data-rel="current|adjacent|edge|far"` lên từng mục, CSS ẩn `adjacent` + `far`); `< 360` **chế độ gọn**: "‹ 57 / 200 ›"
   (chữ trạng thái là `span`, live region giữ nguyên). Dòng "Hiển thị x–y / n" xuống dòng riêng khi `< 480`.
9. **`td-tabs`**: không bao giờ cắt nhãn. `container: td-tabs / inline-size`; tab `flex: 0 0 auto` khi tổng rộng > container
   (JS đặt `data-overflow` bằng ResizeObserver, không đo mỗi frame); vùng tab cuộn ngang `overflow-x: auto`,
   `scroll-snap-type: x proximity`, ẩn thanh cuộn, mép mờ bằng `mask-image` theo `data-scroll-start/end`; tab active
   `scrollIntoView({ inline: 'nearest' })` khi đổi; indicator đo theo `offsetLeft` trong vùng cuộn (cuộn cùng nội dung).
   Không overflow → `flex: 1 1 0` như nay.
10. **`td-button`**: `max-inline-size: 100%`; nhãn được **xuống dòng** (`white-space: normal`, `text-wrap: balance`,
    `overflow-wrap: anywhere`) — không cắt `…` (nút cắt chữ đổi nghĩa). Nút chỉ icon không đổi.
11. **Form control co theo cha**: host `td-datetime-picker`, `td-tree-select`, `td-chip-input`, `td-dropdown`, `td-tree`,
    `td-number-input`, `td-input-field`, `td-otp-input`, `td-media-field`: `min-inline-size: 0`, chữ giá trị / placeholder cắt
    `…` (có `title` khi bị cắt cho dropdown / tree-select / datetime). Gate: lưới 2 cột `1fr 1fr` ở 360 không tràn.
    `td-otp-input` 6 ô: ô `min(2.75rem, (100% − 5 gap) / 6)`.
12. **`td-repeater`** (`@container` trên hàng `[data-td-row]` không được — markup của site; dùng host): `< 480` cụm công
    cụ (kéo / ↑ / ↓ / xoá) thành một hàng riêng căn cuối dưới các field. **`td-dropzone`** `< 360`: chữ hướng dẫn rút gọn,
    nút chọn file rộng 100%. **`td-empty-state`** / **`td-alert`** `< 480`: nút hành động xếp dọc rộng 100%.
    **`td-media-field`**: khung tỉ lệ `max-inline-size: 100%` (đã có), nút Đổi / Gỡ xuống dòng `< 360`. Media grid giữ
    auto-fill (đạt).
13. **Toast / drawer safe-area**: `top: max(var(--td-toast-top), env(safe-area-inset-top) + 8px)`; header drawer full
    màn hình `padding-top: max(…, env(safe-area-inset-top))`.

**`td-table` dạng card — LÀM trong v0.34.0** (vừa: CSS container query + vài thuộc tính render, không đổi mô hình dữ liệu;
là lỗi nặng nhất audit + dsuite cần — để sang v0.34.x thì "chuẩn toàn bộ breakpoint" không đạt)

14. **Sửa bố cục bảng (mọi chế độ)**: `ellipsis` / `width` không còn bật `table-layout: fixed` cho cả bảng (nguyên nhân chia
    đều cột, "iPh…" ở 1440). `fixed` chỉ khi **mọi** cột có `widthType: 'fixed'`. Cột `ellipsis` cắt bằng
    `max-inline-size` của nội dung ô (`maxWidth` hoặc `--td-table-ellipsis-max: 18rem`). Cột mới `nowrap?: boolean` (mặc
    định `true` cho `align: 'right'` — số tiền không rớt "₫"). Bảng cuộn ngang có **bóng mép** báo còn nội dung
    (`background-attachment: local` + gradient, CSS thuần, CSP an toàn).
15. **`layout="auto|table|cards"`** (mặc định `auto`) + **`card-below="sm|md|lg"`** (mặc định `md`): `auto` → card khi
    **container** `td-table` `< 720px` (`sm` = 480, `lg` = 1024; ba selector cố định vì không có biến trong query). `table`
    = luôn bảng (cuộn ngang, hành vi cũ); `cards` = luôn card. `td-table { container: td-table / inline-size; }`.
16. **Vai trò cột** `card?: 'primary'|'secondary'|'meta'|'actions'|false` (mặc định: cột đầu `primary`, cột có
    `actions` → `actions`, còn lại `secondary`). Card = lưới: **primary** (đậm, rộng hết, một dòng đầu), **secondary**
    (cặp "nhãn: giá trị", 1 cột `< 480`, 2 cột `≥ 480`), **meta** (một dòng chữ phụ, nối bằng " · "), **actions** (chân
    card, căn cuối). `false` = không hiện trên card (vẫn ở DOM bảng, ẩn bằng CSS chế độ card).
17. **Ngữ nghĩa header** (không đổi DOM khi đổi chế độ — chỉ CSS): luôn in `role` tường minh lên `table/thead/tbody/tr/th/td`
    (`table` / `rowgroup` / `row` / `columnheader` / `cell`) vì đổi `display` của phần tử bảng làm WebKit / Chromium bỏ
    ngữ nghĩa bảng; mỗi ô có `span.td-table__cell-label[aria-hidden="true"]` (nhãn cột, chỉ hiện ở card — trình đọc màn
    hình vẫn đọc qua `columnheader`, không đọc trùng). `thead` không `display: none` ở card: chuyển thành **thanh sắp xếp**
    — chỉ `th` có nút sort hiện như chip (cùng `button.td-table__sort`, `aria-sort` giữ), `th` khác `td-sr-only`. Sort
    giữ nguyên focus / sự kiện. Golden contract `test/contracts/table.html` cập nhật (role + cell-label).
18. **Thao tác → menu**: cột mới khai báo `actions: [{ id, label, icon?, variant?, hidden?(row), disabled?(row) }]` +
    sự kiện `row-action { id, row, rowIndex }` (+ `onRowAction`). Chế độ bảng: nút nhỏ inline. Chế độ card: `≤ 2` hành
    động hiện thẳng ở chân card, `> 2` → nút "Thao tác" (`more`) mở `TdMenu` (đã có, APG menu button). Cột `render` tự
    do vẫn được, ở card nằm nguyên trong chân (kit không đổi được node tuỳ ý thành menu — ghi docs).
19. **Giữ nguyên ở card**: phân trang trên / dưới (gọn theo quyết định 8), sort (thanh sắp xếp), loading skeleton
    (skeleton dạng card), empty-state, server mode, `max-height` (cuộn dọc). **Chọn dòng chưa có** → để chỗ
    `td-table__card-select` (trống) trong lưới card; tính năng chọn dòng làm ở v0.36 (cùng ẩn / hiện cột).
20. Zebra tắt ở card (card đã tách nhau bằng viền + khoảng); hover / focus-within giữ. Card `article`? **Không** — giữ
    `tr role=row` (một cây DOM, đọc như bảng); card chỉ là trình bày.

**Không đổi**

21. Popup neo không thành sheet; không thêm component "bottom sheet" chung (YAGNI — modal sheet đã có). Không thêm
    breakpoint tuỳ biến bằng biến CSS (không làm được trong query). Không đổi API công khai cũ ngoài phần additive (`layout`,
    `card-below`, `card`, `nowrap`, `actions`, `row-action`, `./breakpoints`); thay đổi nhìn thấy được ghi "Changed".
