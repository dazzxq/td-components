## Decisions

**Precedence (review ISSUE-11):** this plan is normative. The inventory (§7 class maps, §8 harness/tests, §9
decisions) is reference material; wherever it differs from this plan — D1 validator, D6 manual activation, D7 panel
lifecycle, D10 translucent contrast, D19 default tablist name, the naming helper, contenteditable normalisation,
emulated-media checks in `test/tokens/`, the expanded contract shape, the `field-id` rule — **this plan overrides it**.

Decisions (inventory §9 recommendations, revised where noted):

- **D1** empty-state raw `<svg` string icon: deprecated; rendered only after validation, else `inbox` + one
  `console.warn`. **Shared validator (review ISSUE-7):** `td-icon.js` exports the ONE internal geometry validator
  (`_validateIconDefinition`, already used by `registerIcons`) plus `svgStringToDefinition(str)` (DOMParser
  `image/svg+xml`; root must be `<svg>` with a valid viewBox; `parsererror` → null; children must be the allowlisted
  shapes with allowlisted attributes, else null — no partial rendering). Tests: valid geometry; rejected `script`,
  `foreignObject`, `use`/`href`/`xlink:href`, `on*`, `style`, `url(...)` values, non-svg root, parser errors. New
  trusted escape hatch: JS property `iconNode` (SVGElement, cloned).
- **D2** one error vocabulary: `.td-field-error#{host}-error` (error, base contract) + `.td-field__note#{host}-note`
  (helper) inside `.td-field__footer`.
- **D3** base error contract also merges the error id into `aria-describedby` (keeps `aria-errormessage`); applies
  retroactively to checkbox/switch. Subclass hook `_describedByIds()` for helper/counter ids.
- **D4** floating label + textarea autoresize: deferred (roadmap backlog; autoresize via CSS `field-sizing`).
- **D5** AA field colours: border `--td-control-border-strong` (3.42:1), placeholder gray-600 (5.28:1).
- **D6 (revised, review ISSUE-3)** tabs: **manual activation by default** (Arrow/Home/End move focus; Enter/Space
  select + fire `tab-change`) — td-tabs cannot know whether consumer panels switch without latency. Opt-in
  `activation="auto"` attribute (arrows also select) for locally managed/preloaded panels.
- **D7 (extended, review ISSUE-4)** optional `tab.panel` id → `aria-controls` + td-tabs manages that panel:
  `role="tabpanel"`, `aria-labelledby`, `hidden`, and `tabindex="0"` ONLY when the panel has no focusable content.
  Stable ids: tab ids = `{host-id}-tab-{index}` (host gets an id via the same `_ensureId` pattern as form elements),
  so two idless tab sets never collide. Every attribute td-tabs sets on a panel is recorded (previous value or
  absence) and restored when the panel stops being managed (tabs reassigned without it, or host disconnected).
  Tests: two idless tab sets, reassignment, disconnection restore.
- **D19 (review ISSUE-5)** tablist default accessible name "Các thẻ" when the host has no `aria-label`/
  `aria-labelledby`; host values override.
- **D8** one `input`/`change` per kind (native stopped at the host); input-field `change` only when the value
  changed since focus.
- **D9** counter `data-state="limit"` at `count >= max` (colour only; no red border).
- **D10** pagination current page = solid pill `--td-pagination-active` (default accent) + WCAG auto-contrast fg;
  td-table's hard-coded `#ef4444` default removed. **Translucent `active-color` (review ISSUE-8):** the fg is chosen
  against the colour as actually rendered — composited over the nearest ancestor's opaque computed background
  (walking up; fallback the page `--td-color-bg`) — computed at render; tests with translucent colours in light and
  dark themes.
- **D11** slider width token `--td-slider-w` (200/300/400) + `max-width: 100%`.
- **D12** step marks only when `(max-min)/step <= 50` (else none + warn); labels formatted to the step's decimals.
- **D13** empty-state keeps `title`/`message`; additive `heading-level` (2–6, default 3).
- **D14** slider = hidden native range covering the whole ≥ 24 px control + decorative track/fill/thumb siblings;
  the native thumb width = `--td-slider-thumb` so pointer ↔ value mapping matches; focus ring via
  `:focus-visible ~ .td-slider__thumb`; `[data-dragging]` knob lift (glass only while dragging).
- **D15** harness `_meta.mixed: ["td-table"]` → td-table (legacy) is served Tailwind + td.css in both runs; its 5
  baselines recaptured; td-pagination gets an additive `aria-label` attr (nav name) — td-table passes distinct
  labels for its two instances.
- **D16** slider opts into the error contract; its `attributeChangedCallback` routes `error-text`/`disabled` to super.
- **D17** input-field shows error AND helper together (no text swapping).
- **D18** tabs `icon`: registry name, else deprecated validated class list (batch-1 D8 rule); add `upload`, `link`,
  `image` to `icons.json`.

## Work (per inventory §7 class maps + state contracts)

   `TdFormElement` helper (`_applyAccessibleName(control, hasVisibleLabel)`) used by checkbox, switch, input-field
   and slider: internal label → host `aria-label` → external `this.labels` ids as `aria-labelledby`. Tests per
   component incl. an external `<label for>` on the slider.
1. **Base**: `TdFormElement` error contract → `_mountErrorNote(note)` hook (default append to `_errorHost()`),
   `_describedByIds()` hook, `aria-describedby` merge (own ids tracked so consumer-provided ids are preserved).
   Tests for checkbox/switch describedby.
2. **td-input-field** (`components/field.css`, block `.td-field`): errorContract on (drop own `setError`/`_runtimeError`,
   keep `setHelper`/`_runtimeHelper`), label association always (**control id rule (review ISSUE-12): `controlId = field-id ??
   \`${host.id}-control\``** — an explicit `field-id` is used verbatim, test asserts it; label `for` = controlId; external `<label for=host>` → `aria-labelledby`; host `aria-label` forwarded), `aria-required`, asterisk
   `aria-hidden`, footer (error + note + counter) with `aria-describedby`, in-place updates for value/placeholder/
   helper/error/disabled/readonly/required, one event per kind, methods on the prototype, contenteditable
   placeholder via `:empty::before` + `aria-placeholder` + `aria-multiline="true"` + `aria-readonly`/`aria-disabled`;
   **empty normalisation (review ISSUE-6)**: on `input`/`blur`, when the editable's text is empty (only `<br>`/
   whitespace nodes left by the browser) its children are cleared so `:empty` holds — the placeholder is never text in

   caret fix for word truncation, tokens `--td-field-*` (+ dark), coarse pointer 44 px.
3. **td-slider** (`components/slider.css`): D11/D12/D14/D16 — error contract explicitly (review ISSUE-1): `error-text`

   `error-text`/`disabled` to super; tests for API, attribute, reset, `aria-describedby`, re-render survival — `aria-valuetext`, label → `aria-labelledby`, host
