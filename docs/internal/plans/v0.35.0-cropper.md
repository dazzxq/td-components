## Quyết định đã chốt (owner uỷ quyền — không còn câu hỏi mở)

**Phạm vi + kiến trúc**

1. **Tự viết, không CropperJS.** CropperJS v1 ghi `style="…"` (vỡ CSP strict) và có `getCroppedCanvas` (đúng thứ cần cấm);
   v2 dùng Shadow DOM (cấm, ADR 0001); thêm dependency trái luật kit. Phần cần thiết (khung, 8 tay nắm, zoom, bàn phím)
   nhỏ, hình học tách thuần để test node. Ghi **ADR 0015** (mới).
2. **Không bao giờ tạo pixel**: không `<canvas>`, không `toBlob` / `toDataURL`, không `fetch` ảnh, không upload, không
   thuộc tính `crossorigin` (không đọc pixel → không cần CORS). Kết quả **chỉ là số**. Guard test: `src/form/td-cropper.js`,
   `src/feedback/crop-dialog.js`, `src/utils/crop-geometry.js` không chứa `canvas`, `toBlob`, `toDataURL`, `getImageData`,
   `fetch(`, `createObjectURL`.
3. **File mới**: `src/utils/crop-geometry.js` (thuần) · `src/form/td-cropper.js` (`<td-cropper>`, extends `TdBaseElement`,
   **không** form-associated — giá trị form nằm ở media field; YAGNI) · `src/feedback/crop-dialog.js` (nội bộ: hộp thoại
   cắt dùng chung cho picker + field, `openDialogLayer` + DOM `td-modal` như `media-picker-upload.js`) ·
   `src/styles/components/cropper.css` (+ `manifest.json`). Subpath `./cropper`; `index.js` export `TdCropper`.

**Mô hình toạ độ + làm tròn**

4. **Không gian mô hình** = pixel ảnh gốc theo hướng hiển thị. Kích thước gốc `W × H`: `natural-width` / `natural-height`
   (từ `asset.width/height`) nếu có, không thì `naturalWidth/Height` của `<img>` đã decode. Trạng thái trong là
   `{ x, y, w, h }` float trong không gian này. Hiển thị = ảnh "contain" trong stage, `scale = hiển thị / W`.
5. **Ảnh không rõ kích thước**: chưa decode → `data-state="loading"`, không tương tác, không event. `naturalWidth = 0`
   (SVG không kích thước…) → `error` (`size`). Có `natural-*` **và** tỉ lệ ảnh tải về lệch > 1 % → `error` (`ratio`):
   **fail closed** (ảnh xem trước bị cắt sẵn ⇒ toạ độ sai). Không có `natural-*` → tin ảnh tải về, **`pixels` bị bỏ khỏi
   kết quả** (có thể là bản thu nhỏ). Tức `pixels` chỉ có khi biết kích thước gốc.
6. **EXIF**: giả định ảnh **đã được server chuẩn hoá** (xoay thật + bỏ orientation khi re-encode — security-model §6 đã bắt
   buộc re-encode), `width/height` của asset là kích thước **sau** xoay. CSS đặt `image-orientation: from-image` (mặc định
   trình duyệt) nên nếu server chưa chuẩn hoá, toạ độ vẫn theo ảnh **đang hiển thị**; docs ghi rõ đó là trách nhiệm server.
7. **Làm tròn / kẹp** (một hàm `toOutput()`, node test + fuzz 10 000 ca):
   - kẹp: `minW ≤ w ≤ W`, `0 ≤ x ≤ W − w` (tương tự trục y); không lật khung (kéo qua góc đối diện → dừng ở min);
   - `pixels` = số nguyên: `round` từng giá trị rồi `w = min(w, W − x)`, `h = min(h, H − y)`, `w, h ≥ 1`;
   - `normalized` tính **từ `pixels` nguyên** (cùng một nguồn sự thật): `q(v) = round(v·1e6)/1e6`; nếu `nx + nw > 1` →
     `nw = q(1 − nx)` (lặp lại với −1e-6 nếu float vẫn vượt) ⇒ luôn hợp lệ với `parseCrop` (JS + PHP, `CROP_EPS`);
     toàn ảnh ra đúng `0` / `1`;
   - `aspectRatio` = tỉ lệ khoá (làm tròn 4 chữ số) hoặc `round4(px.w / px.h)` khi tự do;
   - focal: `q()` + kẹp `[0, 1]`.
8. **Toàn ảnh = `null`**: tích hợp (picker / field) đổi kết quả phủ toàn ảnh (`pixels` = `0,0,W,H`, hoặc normalized
   `0,0,1,1`) thành `crop = null` ("không cắt — dùng nguyên ảnh", đúng nghĩa đã chốt ở media-field.md; như dcms2 "dùng ảnh
   gốc"). `<td-cropper>` tự nó luôn trả hình chữ nhật.

**API `<td-cropper>`**

9. Thuộc tính (scalar): `src` (qua `safeMediaUrl`, **không** `blob:` / `data:`; sai → `error` `src`), `alt` (nhãn của
   stage), `natural-width` / `natural-height` (số nguyên 1–100 000), `aspect-ratio` (`W/H` | `W:H` | số — dùng lại
   `parseAspectRatio`; có ⇒ **khoá**, ẩn bộ chọn tỉ lệ), `crop` (JSON v1 — `parseCrop`), `focal-point` (boolean: bật công cụ điểm trọng tâm), `focal` (JSON v1
   `{"v":1,"x","y"}` — `parseFocal`), `disabled`. Property: `crop` (get → `CropValue | null`; set `{ normalized } | null`,
   `null` = mặc định), `focalPoint` (`{x,y} | null`), `presets` (mảng `{ label, ratio: number | null }`, mặc định
   `TdCropper.presets`), `reset()`, `getResult()` → `{ crop, focalPoint }`. Gán bằng code **im lặng** (quy ước kit).
   `TdCropper.presets` mặc định: Tự do, 1:1, 4:3, 3:2, 16:9, 1.91:1. `TdCropper.labels` (tiếng Việt).
   `TdCropper.openDialog(opts)` → `Promise<{ status: 'applied', crop, focalPoint, changed } | { status: 'cancelled' }>`
   (public, vì dsuite cần sửa lại crop của figure trong editor; cùng hàm nội bộ với picker / field).
10. `CropValue = { normalized: {x,y,width,height}, pixels?: {x,y,width,height}, aspectRatio: number }` — đúng
    `UsageDraft.crop` của ADR 0013.
11. **Khung ban đầu**: khoá tỉ lệ → hình lớn nhất đúng tỉ lệ, căn giữa (dcms2 `ready()`); tự do → toàn ảnh. `crop` hợp lệ →
    dùng; khoá mà lệch tỉ lệ > 1 % → thu về hình lớn nhất đúng tỉ lệ **bên trong** nó, cùng tâm; nhỏ hơn min → nới quanh tâm,
    kẹp trong ảnh. **Min chỉ là hằng nội bộ cho tương tác** (review R1 #4 — không có API công khai `min-crop-*` /
    `crop.minWidth/minHeight` ở v0.35): `MIN_PX = 16` px mô hình mỗi cạnh (khoá tỉ lệ: cạnh ngắn ≥ 16), kẹp về khung lớn
    nhất có thể khi ảnh nhỏ hơn; chỉ chặn kéo / zoom / phím, không validate crop đầu vào (crop nhỏ hơn từ server được nới quanh
    tâm khi mở). Site cần trần chất lượng (OG ≥ 1200 × 630) thì kiểm `pixels` ở server.
12. **Đổi preset** (tự do → có tỉ lệ): hình lớn nhất đúng tỉ lệ vừa ảnh, giữ **tâm** khung hiện tại (kẹp). Về "Tự do" →
    giữ khung, mở khoá.
13. **Zoom = đổi cỡ khung quanh một điểm neo** (không có zoom khung nhìn): "Phóng to" thu khung × 0.9 (ảnh ra "gần" hơn),
    "Thu nhỏ" × 1/0.9; neo = tâm khung (phím / nút), con trỏ (wheel), trung điểm hai ngón (pinch). Kẹp `[min, khung lớn nhất
    giữ tỉ lệ hiện tại]`, rồi tịnh tiến vào trong ảnh. Lý do: mọi thao tác đều đổi kết quả (không trạng thái ẩn), hình học
    thuần, test được; độ chính xác đủ cho toạ độ. Phóng đại khung nhìn để chỉnh tinh = non-goal.

**Con trỏ + bàn phím + a11y**

14. **Pointer Events** + `setPointerCapture`; cập nhật gộp theo rAF. Kéo thân khung = di chuyển; kéo tay nắm = đổi cỡ (góc
    đối diện làm neo). **Khoá tỉ lệ ⇒ chỉ 4 góc** (cạnh ẩn); tự do ⇒ 8 tay nắm. Hai con trỏ (cảm ứng) ⇒ pinch; một ngón
    nhấc ⇒ kết thúc cử chỉ. `wheel` trên stage (`passive: false`, `preventDefault`; `ctrlKey` = pinch trackpad, cùng
    đường): hệ số `exp(−deltaY·0.002)` kẹp `[0.8, 1.25]`/sự kiện, `deltaMode` dòng × 16. Escape **trong** lúc kéo → trả khung
    về lúc bắt đầu, nuốt phím (không đóng dialog). Không vẽ khung mới khi kéo ngoài khung (non-goal). `touch-action: none` +
    `user-select: none` trên stage; ảnh `draggable="false"`.
15. **Bàn phím** (toạ độ **vật lý**: ← luôn sang trái kể cả RTL; toolbar vẫn theo RTL):
    - thứ tự Tab: toolbar (nhóm tỉ lệ — **một** tab stop, `role="radiogroup"` roving, mũi tên đổi; −; +; Điểm trọng tâm;
      Đặt lại) → khung → góc trên trái → trên phải → dưới phải → dưới trái → điểm trọng tâm (khi bật). Tay nắm cạnh chỉ
      cho chuột / chạm (`aria-hidden`, không focus) — góc đã đủ chỉnh hai chiều;
    - khung: mũi tên di chuyển 1 % cạnh ảnh theo trục đó (≥ 1 px), Shift × 10; tay nắm góc: mũi tên đổi cỡ góc đó (khoá
      tỉ lệ: trục của phím quyết định, trục kia suy ra); `+` / `=` / NumpadAdd phóng to, `-` / `_` / NumpadSubtract thu nhỏ
      (trên mọi phần của stage); điểm trọng tâm: mũi tên 1 % / Shift 10 %. Ctrl / Meta + phím không bị nuốt.
16. **ARIA**: stage `role="group"` `aria-label="Cắt ảnh: {alt}"`; khung `role="group"` + `aria-roledescription="khung
    cắt"` + `aria-label` + `aria-describedby` (= dòng giá trị hiện tại + hướng dẫn phím, `td-sr-only`); góc: `role="group"`
    + `aria-roledescription="tay nắm"` + nhãn "Góc trên trái"…; điểm: nhãn "Điểm trọng tâm". **Live region** riêng
    (`role="status"`, polite), **debounce 400 ms** sau thay đổi cuối: "Vùng cắt 1200 × 675 px, cách trái 120 px, cách trên
    40 px" (không có `pixels` → theo %), "Điểm trọng tâm 35 %, 60 %", "Đã bỏ điểm trọng tâm"; preset: "Tỉ lệ 16:9". Trạng
    thái tải / lỗi đọc qua cùng live region. Mọi chuỗi (alt, nhãn) gán bằng `textContent` / `setAttribute`.
17. **Điểm trọng tâm** (khi `focal-point`): nút bật/tắt `aria-pressed` = `focalPoint !== null`. Bật → đặt ở tâm khung, phát
    `focal-change`; tắt → `null`. Khi bật: chạm/bấm (di chuyển ≤ 4 px) lên ảnh = đặt điểm; kéo điểm = di chuyển; kéo khung
    vẫn di chuyển khung (điểm nằm trên khung theo z). Toạ độ **chuẩn hoá theo toàn ảnh gốc**, độc lập với crop (server dùng
    khi tự cắt tỉ lệ khác), được phép nằm ngoài khung.

**Sự kiện**

18. `crop-input { crop, source }` (trong lúc kéo / pinch, theo rAF) · `crop-change { crop, source }` (kết thúc cử chỉ có
    thay đổi; mỗi bước phím / nút / wheel; đổi preset; Đặt lại) · `focal-change { focalPoint, source }` · `image-ready
    { naturalWidth, naturalHeight, pixelsKnown }` · `image-error { kind: 'src'|'load'|'size'|'ratio' }`. `source ∈
    'pointer'|'pinch'|'wheel'|'keyboard'|'button'|'preset'|'reset'`. Không event khi gán bằng code.

**CSP + render + responsive**

19. **Chỉ CSSOM**: JS đặt custom property riêng trên host bằng `style.setProperty` — `--_tdc-img-x/y/w/h`,
    `--_tdc-box-x/y/w/h`, `--_tdc-focal-x/y` (px hiển thị); CSS dùng `translate` / `inline-size`. Gỡ hết khi disconnect
    (không đụng thuộc tính inline khác của site). Vùng mờ ngoài khung = `box-shadow` lan rộng của khung trong stage
    `overflow: hidden`. ResizeObserver tính lại `scale` (JS không phụ thuộc container query — ADR 0014 §3).
20. **Vùng chạm**: tay nắm hình 12 px, `::before` 24 px (chuột) / 44 px (`pointer: coarse`); **stage có đệm trong**
    `--_tdc-pad` = 12 px / 22 px (coarse) quanh vùng ảnh để vùng chạm của góc ở mép ảnh **không bị `overflow` cắt** (bài học
    v0.34). Khung hiển thị nhỏ hơn 2 × 44 khi coarse → ẩn tay nắm cạnh, góc vẫn còn; điểm trọng tâm ≥ 44 khi coarse.
21. **Responsive (ADR 0014)**: `<td-cropper>` là component trong dòng ⇒ `container: td-cropper / inline-size` trên host
    `display: block`; `@container td-cropper (width < 480px)`: toolbar xuống hai hàng (nhóm tỉ lệ một hàng riêng, cuộn ngang
    nếu thiếu chỗ), nút − / + chỉ icon (nhãn vẫn ở `aria-label`). Chiều cao stage inline `--td-cropper-h` (mặc định
    `min(60vh, 32rem)`); `td-cropper:not(:defined)` giữ chỗ cùng chiều cao (không CLS). **Hộp thoại cắt** là lớp phủ ⇒
    `@media` như dialog tải lên của picker: hộp `lg` từ 720, **full viewport `< 720`**, `short` (≤ 500 cao): header / footer
    gọn, stage lấp phần còn lại (≥ 200 px), footer luôn trong viewport + `safe-area`.
22. **Bề mặt** (Minimal surfaces): khung = viền 1 px `--td-cropper-line` (trắng) + viền ngoài 1 px
    `--td-cropper-line-contrast` (đen 60 %) để thấy được trên mọi ảnh; tay nắm nền trắng viền tối; vùng mờ
    `--td-cropper-dim` `rgb(0 0 0 / 55%)`; lưới 1/3 khi đang kéo (`data-dragging`); không shadow trang trí, không blur.
    Focus: vòng focus kit trên khung / góc / điểm (`outline-offset` dương). `prefers-contrast: more` / `forced-colors`:
    `Highlight` / `CanvasText`, không vùng mờ bán trong suốt (dùng `CanvasText` 1 px). Reduced motion: không có animation
    nào (không cần nhánh riêng).

**Picker**

23. `crop` option **chạy thật**: `resolveOptions` chuẩn hoá thành `cropResolved = { aspectRatio: number|null,
    allowFocalPoint: boolean } | null` (thay `cropRequested` + cảnh báo "ships in v0.35"). Typedef `crop` **giữ nguyên**
    `{ enabled, aspectRatio?, allowFocalPoint? }` (không thêm key — review R1 #4). `aspectRatio` số hữu hạn `(0, 10000]`,
    sai → cảnh báo một lần + tự do. `selection.mode = 'multiple'` + crop → cảnh báo một lần, bỏ crop (như dcms2: chọn
    nhiều không crop).
24. **Luồng (giống dcms2: sau khi chọn)**: "Chèn" → cổng `_requestFinish('confirm')` (vẫn hỏi bỏ thay đổi metadata trước)
    → nếu `cropResolved` + chế độ đơn + asset `kind === 'image'` ⇒ mở **bước cắt** (hộp thoại lồng, band trên picker) thay vì
    kết thúc. Video / file ⇒ kết thúc ngay, `crop = null`. Bước cắt: tiêu đề "Cắt ảnh" (+ "· 16:9" khi khoá), `src =
    asset.urls.preview` (qua `safeMediaUrl`), `natural-* = asset.width/height`; footer **"Quay lại"** (secondary; Escape /
    × cũng vậy → về picker, giữ lựa chọn, focus về "Chèn") + **"Chèn"** (primary, disabled khi `error` / `loading`). Áp
    dụng ⇒ `_teardown(buildOutcome(model, usageById))` với `usage.crop` (toàn ảnh → `null`) + `usage.focalPoint`. **Không
    có nút "Cắt" trong panel chi tiết**: panel = metadata **của asset**, crop = dữ liệu **của chỗ dùng** (research §4 tách
    hai thứ) — một lối vào duy nhất.
25. Picker đóng bằng code / host bị gỡ khi bước cắt đang mở ⇒ huỷ hộp thoại cắt (trong `_teardown`). `buildOutcome(model,
    usageById?)` thêm tham số tuỳ chọn; picker **không bao giờ** sửa host (ADR 0013 QĐ 3 giữ nguyên).
26. `urls.preview` phải là **ảnh nguyên, không cắt sẵn** (bất kỳ cỡ) khi bật crop — ghi vào hợp đồng adapter; lệch tỉ lệ so
    với `width/height` ⇒ lỗi `ratio` (QĐ 5), nút "Chèn" khoá, chỉ "Quay lại".

**Media field**

27. Thuộc tính mới (chỉ có tác dụng ở chế độ `usage`; thiếu `usage` → cảnh báo một lần, bỏ qua — fail closed vì dạng
