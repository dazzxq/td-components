## Mâu thuẫn với giả định của owner (đã kiểm code)

1. **Phím tắt chọn đã chạy** (v0.33, `select-mode="tick"` mà picker luôn dùng): Ctrl/Cmd+click = bật / tắt, Shift+click =
   chọn dải từ anchor, Space = bật / tắt, Shift+Space = dải (`td-media-grid.js` L565-625, `_userFlip` L664-697). Picker chế
   độ đơn: modifier = như click thường (pre-clear v0.35 L1129-1145). Test hiện có chỉ bắn `MouseEvent` tổng hợp
   (`td-v033-media-grid-select-mode.engines.browser-test.js` L61-108), **chưa** có phím thật. Thiếu thật: (a) Shift+click
   bôi đen chữ trên lưới; (b) lưới mặc định (không `select-mode`): Ctrl/Cmd+click khi chưa chọn gì = `activate`, không bắt
   đầu chọn; (c) macOS: Ctrl+click = menu chuột phải (không có `click`) → chỉ Cmd dùng được — đúng chuẩn mac, ghi docs. dcms2
   **không có** Shift+click: kit đã hơn dcms2. → M2 là "test thật + vá 2 lỗ + docs", không phải tính năng mới.
2. **`td-checkbox` không có indeterminate** (không có thuộc tính / CSS `:indeterminate`; chỉ `td-tree` có tri-state riêng
   `td-tree__check-mixed` "–"). → QĐ 3 thêm `indeterminate` cho `td-checkbox` (cần cho tree + chọn dòng bảng sau này).
3. **Picker không có control "sắp xếp"**; "Chỉ của tôi" chỉ tồn tại nếu adapter khai báo facet `toggle`. Sheet lọc (mục 11)
   chứa **mọi facet adapter khai báo** — không thêm sort mới (non-goal, cần mở rộng adapter).
4. **`td-copy for=` không đọc được `<td-input-field>`**: `_target()` + `_isField()` (`td-copy.js` L150-171) chỉ nhận
   `input / textarea / select` native, còn lại copy `textContent` của host (không chứa giá trị ô). Đổi demo sang
   `<td-input-field>` mà không sửa `td-copy` = copy sai. → QĐ 53.
5. **`td-alert` không dùng pastel** (token riêng `--td-alert-{v}-bg/-border/-heading/-icon`, nền ~50, chữ thân trung tính);
   alert chứa đoạn văn + liên kết + nút hành động → tô đặc cả khung buộc đổi màu mọi control con. → QĐ 26: alert giữ nền nhạt
   cho thân chữ, phần nhận diện (vạch mép, icon, viền, tiêu đề) dùng màu đặc mới. **Lệch có chủ đích** so với "áp dụng đồng
   nhất" — đổi được bằng một token nếu owner muốn đặc hẳn (ghi docs).
6. **Warning đặc + chữ trắng không đạt tương phản** ở bất kỳ sắc vàng / cam nào còn "nhìn ra vàng" (amber-500 2.15:1,
   amber-600 3.19:1; chỉ amber-700 `#b45309` 5.02:1 nhưng là nâu cam). → QĐ 24: warning = amber-500 đặc + **chữ đậm tối**
   (8.25:1), như quy ước Bootstrap / GitHub.
7. **Chạm ≥ 44 bằng vùng `::before` mở rộng cho nút thao tác 32–40 px đặt sát nhau (gap 4 px) sẽ chồng vùng chạm** — trái
   ADR 0014 §5. → QĐ 17: khi `pointer: coarse` nút thao tác **lớn thật** lên 44.

## Quyết định đã chốt (owner uỷ quyền — không còn câu hỏi mở)

**A. Ô tick chung — "mark" của `td-checkbox` (mục 1; ADR 0017)**

1. **Một phần hình duy nhất `.td-check`** (CSS mới `src/styles/components/check.css`, vào `manifest.json` **trước**
   `checkbox.css`) = hộp + dấu ✓ (SVG registry `check`) + vạch indeterminate (vẽ bằng `::after` — không thêm node, CSP an
   toàn) + màu checked `--td-checkbox-color` + viền nghỉ `--td-checkbox-border` + bo `--td-checkbox-radius` + cỡ
   `--td-check-size` (`td-check--sm` 1rem · `--md` 1.25rem · `--lg` 1.5rem = đúng ba cỡ `td-checkbox`) + focus ring
   `--td-focus-ring` + disabled 50 % + forced-colors + reduced-motion. **`td-checkbox` không đổi markup**: CSS chung viết
   `:where(.td-check, .td-checkbox__mark)` / `:where(.td-check__svg, .td-checkbox__svg)` → DOM contract, class map, SSR
   `checkbox@1` + golden PHP **giữ từng byte**; `checkbox.css` chỉ còn layout + input ẩn + nhãn.
2. **Helper markup** `src/utils/check-mark.js` (nội bộ, không subpath): `checkMarkHTML(size)` (chuỗi, `aria-hidden="true"`,
   icon qua `data-td-icon` + `fillIconSlots`) và `createCheckMark(size)` (DOM API, `tdIcon`). Mark **luôn `aria-hidden`** —
   ngữ nghĩa nằm ở phần tử chứa (button `aria-pressed`, `role=option aria-selected`, `menuitemcheckbox aria-checked`,
   `treeitem aria-checked`). **Không bao giờ lồng `<td-checkbox>`** (control tương tác lồng nhau, form-associated → rò
   FormData, hai nguồn trạng thái).
3. **Trạng thái do CSS đọc từ ARIA sẵn có** (không thêm thuộc tính trạng thái trùng): bật =
   `.td-checkbox__input:checked ~ mark`, `:is([aria-pressed="true"], [aria-checked="true"], [aria-selected="true"]) >
   .td-check`, `.td-tree__item[aria-checked="true"] > .td-tree__row > .td-check`; mixed = `.td-checkbox__input:indeterminate
   ~ mark`, `[aria-checked="mixed"] > .td-check`, nhánh tree tương ứng; khoá = `[aria-disabled="true"] > .td-check`,
   `:disabled > .td-check`. Danh sách selector nằm **một chỗ** (`check.css`); consumer mới thêm selector ở đó (ghi
   conventions). **`td-checkbox` thêm `indeterminate`** — vòng đời (review R1-3):
   - **Nguồn**: thuộc tính boolean `indeterminate` (thêm vào `observedAttributes` + `booleanAttributes` của `TdCheckbox`,
     không phải `TdCheckableElement` — `td-toggle` không có) + property `indeterminate` phản chiếu thuộc tính (set →
     `toggleAttribute`). Áp lên control: `input.indeterminate = host.hasAttribute('indeterminate')` trong `afterRender()`
     (sau **mọi** render), trong `hydrate()` sau khi nhận markup, và trong `attributeChangedCallback` (tại chỗ, không render
     lại — focus giữ). Không in thuộc tính / class lên control (indeterminate là property native, HTML không biểu diễn được).
   - **Người dùng bấm**: native tự xoá `input.indeterminate` rồi bắn `change` → `_onUserToggle` của `TdCheckbox` gỡ thuộc
     tính host **trước** khi phát `change` (cờ `_syncingIndeterminate` để `attributeChangedCallback` không áp ngược) → vẫn
     đúng **một** `change { checked }`, không event riêng cho indeterminate. `disabled` → không gì đổi.
   - **Đặt bằng code** (`indeterminate = …`, đổi `checked` bằng code): không event (như `checked` hiện nay); đổi `checked`
     bằng code **không** xoá indeterminate (giống native — app quản lý, vd. "chọn tất cả").
   - **Hydrate `checkbox@1`**: PHP không in indeterminate → markup không đổi, golden giữ từng byte; thuộc tính
     `indeterminate` site đặt trên host SSR được áp sau adopt; `canHydrate` / `canRebind` không đổi (control vẫn phải là
     `input[type=checkbox]` như nay). Re-connect (rebind hoặc render lại) → áp lại.
   - **Reset / restore**: `form.reset()` / `formStateRestoreCallback` **không đổi** thuộc tính host (đúng native; comment
     `_restoreDefaults` L289-292 giữ) và **áp lại** nó lên input sau reset. FormData không đổi (indeterminate không phải giá
     trị).
   - Ngữ nghĩa: input native indeterminate → cây truy cập "mixed"; mark hiện vạch (`:indeterminate` thắng `:checked` trong
     `check.css`).

**B. Phím tắt chọn — media grid / picker (mục 2)**

6. Hành vi chuẩn (giữ v0.33, ghi docs thành bảng): chế độ **nhiều** — click / Enter = xem (`activate`); Cmd (mac) / Ctrl
   (khác)+click = bật / tắt một mục + đặt anchor; Shift+click = **thêm** dải từ anchor tới mục (không bỏ chọn ngoài dải — chọn
   tích luỹ qua nhiều trang của picker; dừng ở `max` + `select-limit`); Space = bật / tắt; Shift+Space = dải. Chế độ **đơn**:
   mọi modifier = click thường (chọn đúng một). Anchor không còn trên trang (đổi trang / lọc) → Shift+click = bật / tắt một.
7. **Vá**: (a) `mousedown` có `shiftKey` trên opener / tick → `preventDefault()` (không bôi đen chữ; focus không đổi — click
   vẫn tới); (b) lưới mặc định: Ctrl/Cmd+click trên opener **`<button>`** = bật / tắt (bắt đầu chọn), opener **`<a href>`**
   giữ hành vi trình duyệt (tab mới) — chỉ Ctrl/Cmd; Shift giữ như v0.33; (c) **không** thêm Ctrl/Cmd+Space (Space đã là
   toggle theo APG listbox; Ctrl+Space = đổi bộ gõ macOS, Cmd+Space = Spotlight) và **không** thêm Ctrl/Cmd+A (picker phân
   trang → "tất cả" mơ hồ) — non-goal có lý do.

**C. `<td-action-button>` (mục 3)**

8. **Element mỏng kế thừa `TdButton`**: `class TdActionButton extends TdButton` (`src/form/td-action-button.js`, tag
   `td-action-button`, subpath `./action-button`, `index.js` export, `sideEffects`). Kế thừa nguyên: `<button>` / link
   (`href`), `disabled`, `loading`, `type`, chuyển tiếp `aria-*`, hydrate. Không phải variant của `td-button` (variant không
   mang được registry preset + tooltip + cỡ vuông riêng mà không phình API `td-button`).
9. **API**: `action` (khoá preset, kebab-case; nhận alias camelCase của dcms `sendToPublish`, `forceRelease`), `label`
   (ghi đè nhãn preset), `icon` (ghi đè; tên registry), `tone` = `standard | warning | danger` (ghi đè), `size` = `sm | md |
   lg` = **32 / 36 / 40 px** vuông (mặc định `md`; khác thang 32 / 40 / 48 của `td-button` — ghi docs), `disabled`,
   `loading`, `href`, `target`. Không có chữ hiển thị. Nhãn → **`aria-label` + `data-tooltip`** trên control trong (TdTooltip:
   tên = nhãn nên mô tả trùng bị bỏ — không đọc hai lần); module import `td-tooltip.js` (tự khởi tạo). Disabled native →
   không tooltip (ghi docs).
10. **Registry preset**: `TdActionButton.presets` (object, site sửa được) + `TdActionButton.registerPreset(name, { icon,
    label, tone })` (validate: `name` kebab-case, `label` chuỗi khác rỗng, `tone` thuộc 3 giá trị, `icon` có trong registry
    sau alias — sai → `TypeError`). Preset không tồn tại và không có `icon` + `label` → cảnh báo **một lần** / tên, host
    không render gì (như dcms2 `''` + warn). Đổi `action` / preset → render lại.

14. **Hợp đồng lớp con** (review R1-1 — không "kế thừa là xong"):
    - **Thuộc tính quan sát** = của `TdButton` **trừ** `variant` / `color` / `text-color` / `icon-position` / `full-width`
      (bỏ qua: control luôn ghost, vuông, chỉ icon) **cộng** `action`, `tone`, `size`; `label` / `icon` đổi nghĩa (ghi đè
      preset, không phải chữ hiển thị). Property `action` / `tone` / `size` / `label` phản chiếu thuộc tính (getter đọc,
      setter set / gỡ); không state ẩn.
    - **Resolve một chỗ** `_resolved()` → `{ icon, label, tone, size } | null`: preset = `TdActionButton.presets[canon(action)]`
      (canon: camelCase dcms → kebab; key chỉ `[a-z0-9-]`; tra `Object.hasOwn` — không đi prototype); `icon` / `label` /
      `tone` host ghi đè; `tone` / `size` ngoài danh sách → mặc định (`standard` / `md`); `null` khi thiếu `icon` hoặc
      `label` (→ không render, cảnh báo một lần / tên). `registerPreset()` / sửa `presets` **không** tự render lại host đang
      có (docs: đăng ký trước khi định nghĩa / in host, hoặc đổi `action`) — registry không giữ danh sách instance.
    - **Render**: `render()` override trả control icon-only (`<button|a class="td-btn td-btn--action td-btn--action-{tone}
      td-btn--action-{size}" aria-label="{label}" data-tooltip="{label}">` + `span.td-btn__icon` + spinner), escape ngữ cảnh
      thuộc tính; link mode / disabled / loading / aria-* đi qua `_syncState()` của `TdButton` (không viết lại). Đổi `action`
      / `tone` / `size` / `icon` = cấu trúc → render lại; đổi `label` = **tại chỗ**: cập nhật `aria-label` + `data-tooltip` của
      control (cùng node, focus giữ; tooltip đang hiện thì ẩn).
    - **`_syncState()` override** (review R2-4 — `TdButton._syncState()` L539-541 **gỡ** `aria-label` của control khi host
      không có `aria-label`, sẽ xoá tên của nút chỉ icon): gọi `super._syncState()` rồi **luôn** đặt lại `aria-label` +
      `data-tooltip` của control = tên đã resolve. Thứ tự ưu tiên tên: **host `aria-label` > thuộc tính `label` > nhãn preset**
      (một hàm `_name()`; tooltip dùng cùng chuỗi). ARIA kế thừa chỉ chuyển tiếp nhóm tương thích `FORWARDED_ARIA`
      (`aria-pressed` / `aria-expanded` / `aria-controls` / `aria-haspopup`) — như `TdButton`; không chuyển tiếp
      `aria-labelledby` (tên luôn là chuỗi trên). Đổi host `aria-label` → cập nhật tại chỗ như `label`.
    - **Hydrate / rebind riêng** `action-button@1` (`SSR_SCHEMA = 1`): `canHydrate()` override (marker khác `button@1`, không
      gọi `TdButton.canHydrate`), dùng chung kiểm cấu trúc — tách `sameControlStructure()` của `td-button.js` thành hàm nội
      bộ nhận allowlist — với **cùng mức cứng hoá** `TdButton`: tag (`button` ⇔ không `href`), class list, `type` /
      `target` / `rel` / `download`, con đúng thứ tự (icon slot cùng tên + cỡ, spinner y hệt, **không** `td-btn__label`),
      allowlist `CONTROL_ATTRS` + `ARIA_DATA_ATTR` (cấm `on*`, `style`, `form*`…); **thoả thuận**: `aria-label` và
      `data-tooltip` của control == `_name()` (cùng thứ tự ưu tiên; PHP áp cùng luật: option `aria_label` > `label` > preset), icon slot == icon đã resolve; không resolve được → không adopt.
      `canRebind()` = cùng kiểm. Lệch → render an toàn.
    - **PHP** `td_action_button(string $action, array $o = [])`: bảng preset **chép trong `td.php`** (`Td::ACTION_PRESETS`) +
      option `label` / `icon` / `tone` / `size` / `disabled` / `href` / `target` / `attrs` (allowlist `Td::ALLOWED_ATTRS`, tên
      kit sở hữu + `data-td-*` bị chặn) / `element` (mặc định `Td::configure ssr_elements`); in host
      `data-td-ssr="action-button@1"` + control đúng `render()` + `td_icon()` SVG. Action lạ thiếu `icon` + `label` → `''` +
      một `E_USER_WARNING`. **Parity** (`test/php/td-action-button.test.js`): preset JS == PHP (tên, icon, nhãn, tone);
      markup PHP == `render()` JS cho mọi preset × 3 tone × 3 size × link / disabled (fixture SSR sinh tự động); XSS nhãn.
      Preset site đăng ký thêm ở JS → PHP phải truyền `icon` / `label` (docs).

**F. Toast — 6 vị trí (mục 8; ADR 0016) — đúng đồng thuận Claude × Codex**

28. **Tên logic**: `top-start`, `top-center`, `top-end`, `bottom-start`, `bottom-center`, `bottom-end`
    (`TdToast.PLACEMENTS`, mảng đóng băng). **Không** `left/right`, không alias vật lý, không `x/y` / toạ độ / object
    `{top,left…}`, không offset theo lần gọi, không `containerId` public, không giới hạn / clear / z-index theo vị trí.
29. **API**: `TdToast.configure({ placement })` (toàn cục; `placement: null` = bỏ cấu hình; giá trị sai → cảnh báo một lần /
    giá trị, bỏ qua) + tham số thứ ba của `show` / `success` / `error` / `warning` / `info` = **`number | { duration?,
    placement? }`** (không thêm tham số thứ tư; mọi call site cũ y nguyên; số / chuỗi số như cũ; object thiếu `duration` →
    mặc định của hàm: 4000, `error()` 5000). Placement sai trong lần gọi → cảnh báo một lần, rơi xuống bậc kế.
30. **Thứ tự ưu tiên**: `options.placement` > `configure()` > **token CSS cũ** (khi JS chưa đặt) > mặc định `top-end`.
    "Token cũ" xác định lúc `show()`: đọc computed 6 token neo `--td-toast-top/-bottom/-inline-start/-inline-end/-shift/
    -align` trên `:root`; **khác giá trị ship** (`5rem`, `auto`, `auto`, `1rem`, `0%`, `flex-end`) ⇒ site đã chỉnh ⇒ toast
    không có placement vào **stack legacy** (định vị bằng token, CSS + thứ tự append y hệt v0.35); trùng giá trị ship ⇒ vào
    stack tên `top-end` (cùng chỗ) — tránh hai stack chồng ở góc phải khi một lần gọi xin `top-end`.
31. **Snapshot**: placement được resolve **đồng bộ trong `show()`** (trước hàng đợi 50 ms), lưu trên request; `configure()`
    sau đó không di chuyển toast đang chờ / đang hiện; handle `close()` không phụ thuộc stack.
32. **DOM**: một portal root `<div id="td-toast-container" class="td-toast-root">` (id giữ, `TdToast.container` = root;
    fixed, `inset: 0`, `pointer-events: none`, `z-index: var(--td-z-toast)`, không transform) > hai lane
    `div.td-toast-lane[data-edge="top|bottom"]` (≥ 480: `display: contents`) > stack lười
    `div.td-toasts[data-placement="…"]` (≥ 480: fixed theo vị trí) + stack legacy `div.td-toasts` (không `data-placement`,
    luật token cũ). Chỉ class / data attribute + CSS tĩnh (+ một custom property CSSOM `--_td-toast-seq` cho lane xs). Breaking
    (DOM): toast không còn là con trực tiếp của `#td-toast-container` — ghi class-map + breaking-changes; class `.td-toasts`
    vẫn là stack (CSS site nhắm `.td-toasts` vẫn trúng).
33. **Toàn cục giữ nguyên**: `MAX_VISIBLE` (5, **toàn hệ thống**, không mỗi stack), FIFO theo **số thứ tự toàn cục** (không
    theo thứ tự DOM), `clear()`, một lần đăng ký layer (root, `includeInTrap`), pause (hover / focus trong **bất kỳ** stack →
    dừng tất cả; tab ẩn → dừng tất cả), trả focus khi toast đang focus đóng (toast kế theo thứ tự toàn cục).
34. **Thứ tự trong stack**: mới nhất **sát mép** — stack `top-*` `prepend`, `bottom-*` `append` (đồng thuận). Stack legacy giữ
    `append` (không đổi gì khi site đang dùng token). Đổi hình cho site mặc định (toast mới nằm trên cùng) → breaking-changes.
35. **Chuyển động** theo vị trí: `*-start` trượt từ mép inline-start, `*-end` từ inline-end, `top-center` từ trên xuống,
    `bottom-center` từ dưới lên; RTL đảo trục inline (luật `:dir(rtl)` riêng — engine thiếu `:dir()` chỉ mất luật đó);
    `prefers-reduced-motion` → chỉ fade (như nay). Bị đẩy ra (FIFO) thoát theo hướng stack của nó.
36. **< 480 (`xs`)**: start / center / end gộp **một lane rộng hết** mỗi mép — lane `top` / `bottom` thành fixed
    (`inset-inline: gutter + safe-area`), stack bên trong `display: contents`, toast xếp theo `order: ±var(--_td-toast-seq)`
    (lane top: mới nhất trên cùng; bottom: mới nhất dưới cùng); vào / ra theo trục dọc. Stack legacy giữ luật xs v0.34.
37. **`short` (≤ 500 cao)**: chỉ **2 toast mới nhất toàn cục** hiện — JS đánh `data-td-toast-older` lên mọi toast trừ 2 số
    thứ tự lớn nhất (cập nhật khi thêm / bớt), CSS `@media (max-height: 500px)` ẩn; thay `:nth-last-child(n + 3)` (sai khi
    nhiều stack). Vẫn trong DOM / đã thông báo.
38. **Safe-area**: mép block cộng `env(safe-area-inset-top|bottom) + 8px` như v0.34; `*-start` / `*-end` cộng inset bên đó;
    `*-center` = `inset-inline: gutter + inset trái / phải` + `align-items: center` (không `translateX(-50%)`, không lệch vì
    một inset). Token offset mới cho stack tên: `--td-toast-offset-top: 5rem`, `--td-toast-offset-bottom: 1rem`,
    `--td-toast-offset-inline: 1rem` (độc lập token neo cũ). Token khoảng cách / màu / motion / z-index dùng chung.
39. **A11y**: không live region mới; mỗi toast giữ `role` + chèn chữ trễ một frame (D12). Placement không đổi mô hình đọc.
    (`role=alert` + `aria-live="assertive"` thừa — VoiceOver iOS có thể đọc hai lần — **ghi non-goal**, audit riêng.)
40. PHP / SSR: không (API client tĩnh). Site CSP / PHP cấu hình qua JS ngoài hoặc tiếp tục dùng token.

**G. OTP — giữ hình ô + cấu hình được (mục 9–10)**

41. **Hình ô theo bề rộng thật** (lỗi: v0.33 cho hộp co `max-width: 100%` nhưng `--td-otp-cell-h` cố định → ô hẹp cao).
    Element / JS mode: các ô **luôn trong flow** (grid `repeat(var(--_td-otp-n), minmax(0, 1fr))`, `gap: min(var(--td-otp-gap),
    3%)`), mỗi ô `aspect-ratio: var(--td-otp-cell-aspect)` (token mới, mặc định `44 / 52` = tỉ lệ cũ) → chiều cao hộp = chiều
    cao ô. Trước `:defined` (SSR element mode đang tải module) ô `visibility: hidden` (vẫn chiếm chỗ) + input phủ `inset: 0`
    hiện như ô nhập thường **trong cùng hộp** → không xê dịch khi upgrade. Native mode PHP (không bao giờ upgrade) giữ input
    cao cố định — là ô nhập chữ, không có "viên". `pointer: coarse`: hộp `min-block-size: var(--td-touch-min)` (ô chỉ cao
    hơn tỉ lệ khi bề rộng ô < 37 px — cột < ~262 px; ghi docs). Không cần container query (tỉ lệ + `%` đủ; không có
    `@container` → không fallback). `--td-otp-cell-h` deprecated (không còn tác dụng ở element mode; site đã đổi nó đặt
    `--td-otp-cell-aspect`) → breaking-changes.
42. **`length`**: số nguyên 1…10, mặc định 6. Giá trị không phải số nguyên trong khoảng → **bỏ qua, dùng 6** + một cảnh báo /
    host (không kẹp: kẹp 12 → 10 tạo mã sai âm thầm). Đổi `length` sau khi chạy → render lại, giá trị cắt theo độ dài mới,
    `complete` re-arm theo luật cũ. `TdOtpInput.LENGTH` giữ = 6 (mặc định, deprecated) + getter `length` trên instance.
43. **`charset`** = `numeric` (mặc định) | `alphanumeric` | `alpha`; **`case`** = `upper` (mặc định, cho bộ có chữ) | `lower`
    | `preserve`. Chuẩn hoá từng ký tự (một hàm thuần `otpNormalize(raw, { length, charset, case })` trong
    `src/utils/otp.js`, thay `otpDigits`; `otpDigits` giữ làm wrapper): chữ số qua `asciiDigit()` (full-width + Ả Rập như
    nay); chữ: `NFKC` từng ký tự (full-width Ａ → A) rồi chỉ nhận `[A-Za-z]`; mọi ký tự khác (khoảng trắng, `-`, dấu tiếng
    Việt `â`, emoji) **bỏ**. Áp dụng khi gõ, dán, kéo thả, autofill.
44. **IME / composition** (bộ có chữ): không chuẩn hoá giữa `compositionstart` … `compositionend` (`e.isComposing`) — chuẩn
    hoá một lần sau `compositionend` + `input` kế tiếp. Telex / VNI có thể biến "aa" → "â" (bị bỏ) → docs khuyên tắt bộ gõ
    tiếng Việt cho mã chữ; test chỉ bảo đảm composition không làm hỏng giá trị / caret.
45. **Thuộc tính input theo bộ**: `numeric` → `inputmode="numeric"`; có chữ → `inputmode="text"`, `autocapitalize=
    "characters"` (khi `upper`), `autocorrect="off"`, `spellcheck="false"`; luôn `autocomplete="one-time-code"`. No-JS / SSR:
    `maxlength = length`, `pattern` = `[0-9]{N}` · `[A-Za-z0-9]{N}` · `[A-Za-z]{N}` (pattern native nhận cả chữ thường — server
    chuẩn hoá hoa / thường, ghi docs). Thông báo `tooShort`: numeric "Mã gồm {length} chữ số.", có chữ
    `messages.tooShortChars` "Mã gồm {length} ký tự.".
46. **SSR `otp-input@1` mở rộng thêm (additive, không @2)**: host có thể mang `length` / `charset` / `case`; wrapper

  - **Luồng**: trang in URL kèm tham số crop → Cloudflare miss → endpoint biến đổi đọc ảnh gốc, cắt / đổi cỡ / đổi định dạng
    → `Cache-Control: public, max-age=31536000, immutable` → CF cache ở edge (lần sau không chạm origin).
  - **Checklist BẮT BUỘC của site**:
    1. **URL ký HMAC-SHA256** trên tham số chuẩn hoá `asset id | crop làm tròn | w | fmt | v [| exp]`; secret trong env
       (không trong repo / HTML); so sánh hằng thời gian (`hash_equals`); sai → **403 trước khi đọc file / biến đổi**; xoay
       khoá (hai khoá hợp lệ trong thời gian chuyển, `kid` trong URL).
    2. **Giới hạn biến thể**: allowlist bề rộng (vd. 320 / 640 / 960 / 1280 / 1600 / 2048), allowlist định dạng (webp / avif /
       jpeg), crop làm tròn **4 chữ số** trước khi ký (chặn vô hạn biến thể gần nhau), ảnh ra ≤ ảnh gốc và ≤ trần cứng
       (vd. 4096 px).
    3. **Cache hai tầng**: CF edge + cache đĩa ở origin, khoá = hash của tham số đã ký.
    4. **Chống lạm dụng**: CF WAF / rate limit trên **cache miss** theo IP; giới hạn đồng thời + timeout cho tác vụ biến đổi
       phía server; kiểm quyền với ảnh gốc riêng tư (URL ký không thay cho phân quyền — `exp` ngắn cho ảnh riêng tư).
  - **Ví dụ**: Cloudflare Image Transformations (`/cdn-cgi/image/…` + Worker ký / verify, hoặc chỉ cho phép qua Worker) và
    endpoint PHP tự host (GD / Imagick) — chỉ văn + đoạn mã, ghi rõ "minh hoạ, không phải thư viện".
  - Không nhắc kit tự tạo pixel; dẫn sang M11 nếu owner duyệt helper.

  ADR 0015 (mục Hệ quả); `docs/internal/security-model.md` mục mới **"Trách nhiệm của site"** (biến đổi ảnh, chữ ký, giới
