- L52-67 link mark:
```js
link: {
  attrs: { href: {} },
  inclusive: false,
  parseDOM: [{ tag: 'a[href]', getAttrs: (dom) => {
      const href = isSafeUrl(dom.getAttribute('href'), { allowHttp: !!allowHttp });
      return href == null ? false : { href }; } }],
  toDOM: (mark) => {
    const attrs = { href: mark.attrs.href, rel };
    if (target !== 'none') attrs.target = target;
    return ['a', attrs, 0]; },
},
```
- So: incoming `target` / `rel` are dropped because parseDOM reads ONLY `href`; output rel is a constant, target is the instance-wide constant. Attribute order in output: href, rel, target.

- Actions semantics (L1026-1075): onClick sync `false` -> stays open; thenable -> busy state; throw -> stays open. So "Áp dụng" with an invalid URL can show an error and `return false`.
