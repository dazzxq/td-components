Trang demo cần chạy qua một web server. Mở bằng file:// thì trình duyệt chặn ES module nên component không hiện. Chạy npm run demo trong thư mục dự án (Vite tự mở trang), hoặc npx vite rồi vào http://localhost:5173/demo.html.

Bề mặt nổi minimal surfaces: nền + viền mảnh + bóng mềm, blur nhẹ cho popup
