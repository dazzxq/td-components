Tạo theme màu

Chọn nền trang và màu nhấn; kit tự tính chữ, viền, hover, focus, màu trạng thái đạt WCAG AA — hoặc báo mã lỗi khi về toán học không đạt được (nền không bao giờ bị đổi). Cùng thuật toán với npx td-theme: cùng hạt giống → cùng file CSS.

Đang tải… (trang này cần một web server tĩnh; mở bằng file:// sẽ không chạy)
